# 06. 플레이 장면으로 보는 게임

이 장에서 정하는 것: 새로 정하는 규칙은 없다. 처음 하는 사람의 첫 판을 오프닝과 장면 13개로 따라가며, 뒤의 장들이 정한 규칙이 화면에서 어떻게 보이는지 미리 보여 준다.

- 등급 1 광산의 첫 판이다. 수치는 01(코어 시스템)과 05(아이템·경제)의 최종값이고, "n"은 그때그때 달라지는 숫자다.
- 조작은 마우스로 한다. 화면에는 키 이름이 나오지 않는다. 따옴표 안의 화면 문구는 02(세계관·문구) 6장의 것이다.
- 화면은 날짜를 "3일째"로, 낼 돈을 "도장"으로 적는다. 이 문서의 Day 3은 화면의 3일째다. 계약금·중도금·잔금은 구 실장의 대사에만 나온다.
- 규칙 칸의 "01 3.1"은 01 문서 3장 1절이다. 낯선 말은 07 용어집에 있다.

한 판은 15일, 50~60분이다. 광산 값을 세 번에 나눠 내고, 한 번이라도 못 내면 그 판은 끝난다.

| 날 | 일어나는 일 | 캔 값 |
|---|---|---|
| Day 1~3 | 규칙을 익힌다. 3일째 밤에 첫 도장 300 | ×1 |
| Day 4~8 | 도구를 모은다. 8일째 밤에 두 번째 도장 2,400 | ×1.5 |
| Day 9~15 | 값이 가장 비싼 구간. 15일째 밤에 마지막 도장 11,000 | ×3 |

v2.2 시험(프로토타입 기본 규칙)에서는 사흘마다 도장을 찍는다. 장면마다 달라지는 곳은 'v2.2 시험에서 달라지는 것' 줄에 적었다(01 문서의 'v2.2 시험' 문단).

| 날 | 일어나는 일 | 캔 값 |
|---|---|---|
| Day 1~3 | 규칙을 익힌다. 3일째 밤에 첫 도장 300 | ×1 |
| Day 4~6 | 첫 도장 선물을 써 본다. 6일째 밤에 두 번째 도장 900 | ×1.5 |
| Day 7~9 | 갱이 한 층 깊어진다. 9일째 밤에 세 번째 도장 1,700 | ×1.5 |

| Day 13~15 | 가장 깊은 갱. 15일째 밤에 마지막 도장 4,800 | ×1.5 |

## 오프닝. 3컷 만화

새 판을 처음 시작하면 만화 세 컷이 나온다. 첫 판에만 자동으로 나오고 건너뛸 수 있다. 규칙은 여기서 가르치지 않는다(02 6.12).

| 컷 | 그림 | 글 |
|---|---|---|
| 1 | 비 오는 골목의 게시판. 매물 전단 가운데 한 장만 값이 한 자리 적다 | 마법 광산을 판대요. 값은 헐값이고, 보름달에만 열린대요. |
| 2 | 달못 중개소 책상. 구 실장이 도장 칸 셋이 빈 권리증을 내민다 | 구 실장: "15일 안에 세 번 나눠 내세요. 낼 때마다 도장을 찍어 드려요. 도장 세 개면 광산은 당신 거예요." |
| 3 | 보름달 아래 갱구. 주인공이 촛불 하나를 들고 들어간다 | 가진 건 촛불 하나와 곡괭이 한 자루예요. |

v2.2 시험에서는 2컷 권리증의 빈 도장 칸이 다섯이고, 구 실장이 "15일 안에 다섯 번 나눠 내세요. 사흘마다 도장을 찍어 드려요. 도장 다섯 개면 광산은 당신 거예요."라고 말한다(02 6.10.2).

## 장면 2. Day 1 지하 1층: 내리자마자 땅이 열린다

| | |
|---|---|
| 화면에 보이는 것 | 바위 판(가로 15 × 세로 11칸) 한가운데에 광부가 서 있다. 0.6초 동안 주변 60칸 안팎이 차례로 열리고 "자갈 +23"이 화면 위 '오늘 주머니'로 날아든다. 열린 땅 가장자리에 숫자가 보인다. 말풍선이 차례로 뜬다. "숫자는 둘레 8칸의 지뢰와 보물을 합친 수예요", "부서진 바위에서 자갈이 나와요. 조금이지만 쌓여요". 판 아래에는 "숫자 = 둘레 8칸의 지뢰 + 보물"이 늘 적혀 있다. 한쪽 바닥에는 은은한 빛이 번져 있다 |
| 플레이어가 하는 것 | 열린 땅을 왼쪽 클릭해 걸어 본다. 걷는 데는 촛불이 들지 않는다. 서 있을 때는 조준 표시가 없고, 마우스를 올린 칸에만 얇은 테두리가 생긴다 |
| 느끼는 것 | 시작하자마자 자갈로 조금 벌었다. 숫자가 지뢰만 세지 않는다는 것을 첫 화면에서 본다 |
| v2.2 시험에서 달라지는 것 | 첫 와르르에 "자갈 +23"이 붙지 않는다. 자갈은 치기나 발파로 8칸 이상이 한꺼번에 열릴 때만 나오고, 그때 말풍선이 "한 번에 많이 열리면 자갈이 나와요. 조금이지만 쌓여요"로 뜬다(01 3.2). 빛 번짐 대신 계단 바위가 처음부터 보인다 |
| 이 장면을 만드는 규칙 | 층 시작 와르르(01 3.1), 자갈(01 3.2), 숫자와 범례(01 3.4), 이동과 조준(01 2.2), 첫 판의 정해진 층과 말풍선(01 16장) |

## 장면 3. 첫 보물, 그리고 노다지 줄

| | |
|---|---|
| 화면에 보이는 것 | 숫자 1 옆에 바위가 하나만 남은 자리가 반짝인다. 옆 벽의 낙서는 "1 옆에 바위가 하나만 남았으면 거기에 뭔가 있어요." 마우스를 올린 바위 옆에는 "바위를 클릭하면 그 옆으로 가요. 한 번 더 클릭하면 캐요". 캐면 한 번에 깨지고 금 알갱이가 나온다. 칸 위에 "+20"이 떴다가 주머니로 날아가고, 화면 위의 "다음 도장까지 n · 3일째"가 줄어든다. 촛불 막대 옆에는 "−1". 옆의 1이 깜박이며 사라지고 그 둘레가 다시 와르르 열린다. 곡괭이 위에 불꽃이 붙고 "다음 보물 ×1.5"가 뜬다 |
| 플레이어가 하는 것 | 바위를 왼쪽 클릭한다. 광부가 옆으로 걸어가고 바위에 조준 테두리가 생긴다. 같은 바위를 한 번 더 클릭해 캔다 |
| 느끼는 것 | 캐면 돈이 들어오고 길이 더 열린다. 다음 보물은 값이 1.5배라 하나 더 캐고 싶다 |
| 이 장면을 만드는 규칙 | 조준과 캐기(01 2.2), 치기의 결과(01 3.3), 값 표시와 목표 표시(01 5.3), 노다지 줄 ×1 → ×1.5 → ×2 → ×2.5 → ×3(01 6장), 금 알갱이 20(05 2.2) |

## 장면 4. 첫 지뢰

| | |
|---|---|
| 화면에 보이는 것 | 계단 가는 길목에 방금과 똑같은 자리가 또 있다. 숫자 1, 바위 하나. 캐자 터진다. 체력이 3에서 2로 줄고 불꽃이 꺼지며 "노다지 줄 ×1.5 → ×1". 그 지뢰를 세던 숫자들이 1초 동안 강조된다. 말풍선 하나. "지뢰를 터뜨리면 체력이 1 줄어요. 노다지 줄은 ×1로 돌아가요". 터진 뒤에야 그 자리 벽에 낙서가 드러난다. "저도 여기서 한 번 데었어요. 곡괭이 불꽃도 같이 꺼졌어요." 캐기 전에는 이 자리가 지뢰라고 알려 주는 표시가 없다 |
| 플레이어가 하는 것 | 조금 전과 같은 모양이라 보물이라고 생각하고 캔다 |
| 느끼는 것 | 숫자는 '뭔가 있다'까지만 알려 준다. 방금 붙은 불꽃이 꺼진 것이 아깝다 |
| 이 장면을 만드는 규칙 | 지뢰의 결과(01 3.3), 체력 3(01 5.1), 줄이 끊기는 조건(01 6장), 지뢰를 길목에 둔 배치와 낙서가 보이는 조건(01 16.2, 16.3) |

## 장면 5. 계단, 갈림길, 짝 광맥

| | |
|---|---|
| 화면에 보이는 것 | 아까 본 빛은 계단 바위에서 새어 나와 둘레 두 칸의 바닥과 바위에 번진 것이다(계단 빛 번짐). 빛의 한가운데는 계단에서 0~1칸 어긋나 있어서 '이 근처'까지만 알려 준다. 기록 창에는 "저쪽 바닥에 빛이 번져 있어요. 계단이 가까이 있어요". 그 안에서 밑줄이 그어진 숫자와 틈으로 빛이 새는 바위를 찾는다. 낙서는 "밑줄 그어진 숫자 옆에 계단이 있어요.", "빛이 새는 바위 밑이 계단이에요." 그 바위를 캐면 계단이 나오고 "계단을 한 번 더 클릭하면 내려가요". 클릭하면 카드 두 장이 뜬다. 한 장은 "맨땅 · 규칙이 없어요. 숫자만 보면 돼요", 다른 한 장은 "짝 광맥 · 보물 바로 옆에 보물이 하나 더 있어요". 카드마다 "보물 n개쯤 · 지뢰 n개쯤"과 덤 한 줄(예: "덤: 도착하면 촛불 +4")이 있고, 내려가는 데 드는 촛불 4가 적혀 있다. 짝 광맥 층에서 보물 하나를 캐면 그 칸의 위·아래·왼쪽·오른쪽에 옅은 테두리가 뜬다. 그중 덮인 칸은 하나뿐이다 |
| 플레이어가 하는 것 | 빛이 번진 쪽으로 가서 빛 새는 바위를 캔다. 광맥, 묻힌 양, 덤을 보고 카드 한 장을 클릭한다. 남은 한 칸을 오른쪽 클릭 두 번으로 O를 긋고 캔다. 짝을 따라 연달아 캔다 |
| 느끼는 것 | 계단을 찾느라 아무 바위나 캐지 않아도 된다. 표지판 덕에 '뭔가 있는 칸'이 '보물인 칸'으로 바뀐다. "20 ×1.5 = 30", "20 ×2 = 40"으로 값이 오르니 줄을 끊고 싶지 않다 |
| v2.2 시험에서 달라지는 것 | 계단 바위가 층에 도착할 때부터 보인다. 빛 번짐, 밑줄 숫자, 계단 낙서는 없고 기록 창에 "계단 자리는 처음부터 보여요. 가는 길을 숫자로 찾아요"가 한 번 뜬다. 플레이어는 계단까지 가는 길만 숫자로 푼다(01 8.1). 머리 줄에는 이 층에 남은 보물과 지뢰 수가 보인다(01 3.4). 갈림길 카드에 덤 줄이 없고 묻힌 양은 "보물 8개 · 지뢰 10개"처럼 정확하다(01 8.2) |
| 이 장면을 만드는 규칙 | 계단, 빛 번짐, 밑줄 숫자(01 8.1), 갈림길(01 8.2), 갈림길 덤(01 8.3, 05 5.4), 통행 촛불 = 2 + 도착 층 번호(01 4.1), 짝 광맥(01 9.2, 9.3), 분필(01 2.3, 3.6) |

## 장면 6. 발파

| | |
|---|---|
| 화면에 보이는 것 | X가 그어진 칸이 처음 곁에 오면 말풍선이 뜬다. "발파 버튼을 누르고 X 칸을 클릭하면 터뜨려요(촛불 4). 지뢰면 길이 열리고, 보물이면 녹아 없어져요". 정해진 층을 따라왔다면 지하 3층(촛불 −5)의 시작 자리 옆, X가 미리 그어진 바위 둘 앞이다. X 칸은 그냥 클릭해도 캐지지 않고 안내만 뜬다. "X 칸이에요. 캐려면 오른쪽 클릭으로 X를 지우고, 터뜨리려면 발파를 쓰세요". 발파 버튼을 누르면 화면 아래에 "터뜨릴 X 칸을 클릭하세요"가 뜨고 X 칸들이 강조된다. 하나를 클릭하면 지뢰 둘이 차례로 터지며 12칸 안팎이 열린다. 체력도 줄 불꽃도 그대로다 |
| 플레이어가 하는 것 | 발파 버튼을 누르고 X 칸을 클릭한다. 그만두려면 오른쪽 클릭이나 버튼을 다시 누른다 |
| 느끼는 것 | 지뢰도 쓸모가 있다. 촛불 4로 열두 칸이면 한 칸씩 캐는 것보다 싸다. 다만 보물에 불을 붙이면 녹으므로 확실할 때만 X를 긋게 된다. X 칸을 실수로 캐서 다칠 일은 없다 |
| v2.2 시험에서 달라지는 것 | X 둘을 그은 숫자 2 위에 서서 그 숫자를 한 번 더 누르면 나머지 덮인 칸이 촛불 1에 한꺼번에 열린다. 마우스를 올리면 "한 번 더 누르면 둘레를 한꺼번에 열어요 · 촛불 −1". X가 틀렸으면 지뢰가 터진다(둘레 한꺼번에 열기, 01 3.3.1). 발파로 8칸 이상 열리면 자갈이 붙는다 |
| 이 장면을 만드는 규칙 | 버튼과 고르기 상태(01 2.4), X 칸 보호(01 3.6), 점화 촛불 4와 불발(01 7.1), 이어 터짐과 그을린 보물 반값(01 7.2), 곡괭이와 불 가운데 고르기(01 7.3), 문구(02 6.7, 6.9) |

## 장면 7. 촛불이 꺼지고, 불씨 다섯 번

| | |
|---|---|
| 화면에 보이는 것 | 촛불이 15가 되면 판 가장자리가 어두워지고 먼 숫자가 흐려진다. 0이 되면 "촛불이 꺼졌어요. 불씨가 다섯 번 남았어요". 숫자가 전부 사라지고 분필 X와 O만 남는다. 촛불 막대 자리에는 "불씨 5 · 숫자는 안 보여요. 분필 표시는 보여요". 말풍선은 "불씨일 때 지뢰를 터뜨리면 체력이 남아 있어도 쓰러져요". 벽에는 O가 그어진 칸과 낙서. "불이 꺼져도 O는 보여요. 미리 그어 두세요." 올라가기 버튼을 누르면 확인 창이 뜬다. "버리는 촛불 n · 금고로 가는 주머니 n"과 버튼 둘(올라가기 / 계속 파기) |
| 플레이어가 하는 것 | O 칸을 불씨로 캔다. 남은 불씨를 표시 없는 칸에 걸지, 올라가기 버튼을 누를지 정한다 |
| 느끼는 것 | 불이 있을 때 O를 그어 둔 칸은 불씨로도 캘 수 있다. 불씨 중에 지뢰를 터뜨리면 체력이 남아도 쓰러지므로 표시 없는 칸은 캐기가 겁난다. 올라가면 무엇을 버리고 무엇을 챙기는지는 누르기 전에 확인 창이 알려 준다 |
| v2.2 시험에서 달라지는 것 | 어두워짐과 불씨가 없다. 촛불이 0이 되는 순간 "촛불이 다 탔어요. 오늘은 여기까지예요"가 뜨고 하루가 끝난다. 주머니는 전부 금고로 간다. 그래서 마지막 촛불 몇 개를 어디에 쓸지가 결정이 된다(01 4장) |
| 이 장면을 만드는 규칙 | 촛불 80과 비용(01 4.1), 어두워짐(01 4.3), 불씨 다섯 번(01 4.4), 올라가기와 확인 창(01 4.5), 쓰러지면 주머니 절반(01 5.2). Day 1은 지하 3층에 계단이 없어 첫날에 불씨를 겪는다(01 16.2). 첫 판 Day 1에는 체력이 1이어도 올라가기를 붉게 강조하지 않는다 |

## 장면 10. Day 2 아침: 게시판과 주문

| | |
|---|---|
| 화면에 보이는 것 | 게시판이 처음 나온다. "도장 0개: 캔 값 ×1 · 금 알갱이 20 · 청록 보석 50 · 유물 120. 도장 1개면 ×1.5예요". "오늘 갱 상태: 벽이 얇은 날 · 두드려 보기를 4번 쓸 수 있어요(평소 2번). 촛불은 그대로 2씩 들어요". 오늘 첫 층은 테두리 광맥이다. 주문서 두 장. 맨 아래에 다음 도장까지 남은 돈 |
| 플레이어가 하는 것 | 주문서 한 장을 클릭해 고른다(예: "발파로 지뢰 4개를 터뜨려 주세요 → 화약 2개"). 지하 1층 표지판은 "보물은 바깥 두 줄에만 있어요"라 판 안쪽 위험 칸 셋은 전부 지뢰다. 오른쪽 클릭으로 X 셋을 긋고 발파 버튼으로 터뜨린다. 지하 2층에서 표지판으로도 못 가르는 두 칸은 두드려 보기 버튼을 누르고 한 칸을 클릭한다(촛불 2). 지뢰가 아니라고 나오면 그 칸은 보물이다 |
| 느끼는 것 | 오늘은 두드려 보기가 네 번이고, 주문 때문에 터뜨릴 지뢰를 찾게 된다. 어제와 다른 하루다. 선물로 받은 도구가 발동하면 판 위에서 아이콘이 튄다 |
| v2.2 시험에서 달라지는 것 | 갱 상태와 주문서가 없다. 게시판에는 권리증 칸(도장 다섯), 캔 값 한 줄, 오늘 첫 층만 있고 '내려가기'를 누른다. 지하 2층의 못 가르는 두 칸 옆 낙서는 "숫자로 못 가르는 두 칸이에요. 걸어 보든지, 다른 쪽부터 풀든지 골라요."다. 청진 망치가 없으면 곡괭이로 걸거나, 다른 쪽을 먼저 풀거나, X를 긋고 발파한다(01 11장, 16.1) |

## 장면 11. Day 3: 큰 덩이와 첫 도장

| | |
|---|---|
| 화면에 보이는 것 | 게시판 맨 위에 오늘이 도장 찍는 날이라는 것과 큰 덩이 예고. "오늘 지하 3층에 큰 덩이가 묻혀 있어요. 네 칸이 네모로 붙어 있어요". 오늘 갱 상태는 '달빛이 고인 날'이라 노다지 줄이 ×1.5에서 시작한다. 지하 3층에 내리면 표지판 아래에 "이 층 어딘가에 큰 덩이가 있어요". 덩이 칸에 닿은 숫자 옆에는 작은 금빛 점이 찍혀 있다. 금빛 점이 붙은 숫자 2·2·1이 몰려 있고 2×2 네모가 들어갈 자리는 하나뿐이다. 첫 칸을 캐면 "벽이 울려요. 광산이 깼어요". 그 뒤로 캘 때마다 "−2". 덩이 위에는 "큰 덩이 2 / 4". 마지막 칸에서 덩이가 통째로 뽑히며 "큰 덩이 60 ×2 = 120"처럼 그때의 줄 배율이 붙는다. 밤에 중개인 구 실장이 온다. 금고에서 300이 빠지고 권리증에 도장이 찍힌다. "계약금 300 받았습니다. 첫 도장 찍습니다." 화면 안내는 "도장 1개: 내일부터 캔 값 ×1.5", "다음은 두 번째 도장 2,400 · 8일째. 그날 변덕은 아래에 있어요" |
| 플레이어가 하는 것 | 위층에서 줄을 올려서 갈지, 촛불을 아껴 덩이로 곧장 갈지 정한다. 네 칸을 다 캐야 값을 받으므로 남은 촛불을 계속 센다 |
| 느끼는 것 | 도장 찍는 날에는 큰 것이 있고, 줄을 살려 오면 더 크다. 도장이 찍히면 내일부터 같은 금 알갱이가 30이다 |
| v2.2 시험에서 달라지는 것 | 지하 3층에 내리면 덩이 자리에 금빛 점선 테두리가 처음부터 보인다. 덩이를 찾는 대신 그 테두리까지 가는 길을 숫자로 푼다. 광산 깨어남이 없어 덩이 칸도 촛불 1이다. 도장이 찍힌 뒤 '도장 선물' 화면이 뜬다. 첫 판은 내기 분필, 배짱 장갑, 긴 도화선 가운데 하나를 고르거나 '금고에 60 받기'를 누른다. 다음 도장은 "두 번째 도장 900 · 6일째"다(01 1.4.1, 12.1) |
| 이 장면을 만드는 규칙 | 큰 덩이와 금빛 점(01 12.1, 값은 05 2.2), 광산 깨어남(01 12.2), 도장 판정(01 1.2), 시세(01 5.4), 문구(02 6.1, 6.7). 덩이는 도장의 조건이 아니다. 도장은 금고로만 판정한다 |

## 장면 12. Day 8: 두 번째 도장과 광산 변덕

| | |
|---|---|
| 화면에 보이는 것 | Day 4부터 게시판은 "도장 1개: 캔 값 ×1.5 · 금 알갱이 30 · 청록 보석 75 · 유물 180. 도장 2개면 ×3이에요"다. Day 8 게시판 맨 위에 붉은 줄. "두 번째 돈, 중도금 2,400 받았습니다. 도장 둘입니다." 화면 안내는 "도장 2개: 내일부터 캔 값 ×3". 모자라면 "계약 해지" 화면에 모자란 금액이 가장 크게 뜨고, 아래에 "4~8일째 수입 n · 두 번째 도장을 찍은 판의 평균 4,500 · 산 도구 n개" 한 줄이 붙는다 |

| 느끼는 것 | 미리 알고 준비했어도 빠듯하다. 봇 측정으로 처음 하는 사람이 두 번째 도장을 찍는 비율은 49.5%다 |
| v2.2 시험에서 달라지는 것 | 두 번째 도장은 Day 6, 900이다. 광산 변덕이 없다. 구 실장은 "1차 중도금 900 받았습니다. 도장 둘입니다."라고 하고, 화면 안내는 "도장 2개: 내일부터 갱이 한 층 깊어져요(지뢰와 보물이 늘어요)"다. 도장 선물을 한 번 더 고른다. | 이 장면을 만드는 규칙 | 광산 변덕과 예고(01 12.3), 첫 판 Day 8 고정 변덕(01 16.1), 통과율(05 3.2), 해지 화면 비교값(05 3.4), 계약 해지(01 1.4, 02 6.2) |

## 장면 13. Day 15: 마지막 도장과 점수

| | |
|---|---|
| 화면에 보이는 것 | Day 9부터 캔 값은 ×3이다. 금 알갱이 60, 청록 보석 150, 유물 360. 그사이 도장 찍는 날이 아닌 하루는 갱 상태가 '쌍둥이 지뢰'인 좋은 날이다(한 판에 한 번). Day 15는 그믐이다. 변덕 두 가지가 겹치고, 지하 5층에 가로 3 × 세로 2칸 큰 덩이가 있다. 캔 값이 붙어 780, 줄 ×3으로 뽑으면 2,340이다. 상점은 없다. 밤에 11,000이 금고에서 빠지면 세 번째 도장. "마지막 돈, 잔금 11,000 받았습니다. 도장 셋입니다. 이제 손님 광산입니다." 금고에 남긴 돈이 이번 판 점수로 뜨고 다음 등급 광산이 열린다(2차 프로토타입에는 등급 1만 있어 같은 광산을 다시 하는 버튼만 나온다) |
| 플레이어가 하는 것 | Day 9~14에는 모은 도구들이 엮여 발동한다(아이콘이 차례로 튀고 주머니 숫자가 단계별로 오른다). Day 15에는 덩이까지 갈지, 얕은 층에서 확실한 것만 캐고 올라올지 정한다 |
| 느끼는 것 | 같은 금 알갱이가 첫날의 세 배 값이라 지뢰 하나로 잃는 돈도 그만큼 크다. 마지막 도장을 찍은 뒤에는 남긴 돈이 기록으로 남아 다음 판에 넘을 숫자가 된다 |

Day 15 큰 덩이는 지하 5층 3×2칸, 값 260에 ×1.5가 붙어 390이다. 노다지 줄은 기본 ×3이고, 늙은 광부 모자가 있으면 ×4, 마지막 패와 체력 1이면 ×5다. 마지막 도장은 4,800이고 구 실장은 "잔금 4,800 받았습니다. 도장 다섯입니다. 이제 손님 광산입니다."라고 한다. 판 끝 통계에 '완벽한 층 n'이 붙고, 등급 1을 처음 완납하면 "달못 4호 갱이 열렸어요"가 뜬다. 마지막 도장까지 찍는 비율은 처음 하는 사람 9%, 익숙한 사람 69~74%다(05 8.12) |
