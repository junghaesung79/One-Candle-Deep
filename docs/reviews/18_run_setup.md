# 18. 판 준비 화면: 깊이와 무게 (2026-11-24)

같은 날 고찰하고 고쳤다(결정 R113, 화면 03 3.4.0).

## 1. 고치기 전 화면의 문제

| 문제 | 무엇이 그랬나 |
|---|---|
| 모든 것이 같은 무게 | 권리증, 규칙 설명 세 줄, '첫 판 안내로 시작', '오늘의 광산', '도감', 시드 칸, 캐릭터 목록, 캐릭터 설명이 한 층에 같은 크기와 같은 단추로 놓였다. 무엇을 먼저 골라야 하는지 화면이 말해 주지 않았다 |
| 다른 층의 일이 섞임 | 도감은 판 밖 기록(타이틀 일), 첫 판 안내는 설정 일, 오늘의 광산은 판의 '종류', 시드는 고급 설정이다. 이것들이 판 하나를 준비하는 고르기와 나란히 있었다 |
| 권리증이 주인공 | 판마다 거의 같은 정보(등급 1이면 늘 같은 도장 다섯)가 가장 큰 자리를 차지했다. 정작 판마다 바뀌는 고르기(누구로)는 오른쪽 좁은 칸이었다 |
| 캐릭터가 늘면 무너짐 | 사람마다 세로 한 줄이라 다섯을 넘으면 화면 밖으로 넘친다. 잠긴 사람도 한 줄씩 자리를 먹었다 |
| 광산 고르기가 숨었다 나타남 | 등급이 열리면 단추 줄이 하나 생기는 식이라, 다음 광산이 있다는 것도, 무엇이 다른지도 보이지 않았다 |

## 2. 크게 팔린 게임들의 판 준비

| 게임 | 구조 |
|---|---|
| Slay the Spire | 타이틀 → 플레이 → (보통 / 오늘의 도전 / 사용자 지정) → 캐릭터 고르기 한 화면. 큰 그림의 고른 캐릭터, 아래 줄에 초상, 오른쪽 아래 '출발'. 승천 단계는 같은 화면의 작은 고르개. 시드는 사용자 지정 쪽 |
| Balatro | 타이틀 → 플레이 → '새 판' 탭: 덱을 좌우 화살표로 넘기고, 판돈 단계도 화살표로 넘긴다. 잠긴 덱과 판돈은 조건과 함께 보인다. 시드는 '시드 판' 켜기로 숨겨 둔다 |
| Vampire Survivors | 캐릭터 격자(수십 명까지 늘어남) → 고른 사람의 큰 설명 → 다음 단계에서 무대 |

공통점: 한 화면이지만 무게가 셋으로 나뉜다. (1) 판마다 고르는 것 하나가 가장 크다(캐릭터나 덱). (2) 가끔 바꾸는 것(난이도·무대)은 작은 고르개. (3) 거의 안 쓰는 것(시드)은 접어 둔다. 기록·도감은 타이틀에 있다.

## 3. 바꾼 구조

깊이: 타이틀 → 판 준비(한 화면) → 하루. 판 준비를 둘로 쪼개지 않는다(한 번 더 누르게 할 만큼 고를 것이 많지 않다). 대신 화면 안의 무게를 셋으로 나눈다.

| 무게 | 자리 | 내용 |
|---|---|---|
| 1 누구로 | 왼쪽, 가장 크게 | 고른 사람의 큰 그림(128px)과 이름, 한 줄 소개, X·O 능력, 장점·약점. 아래에 초상 줄(80px 칸, 줄바꿈되어 열 명이 넘어도 들어간다). 잠긴 사람은 실루엣과 ???이고, 누르면 큰 자리에 여는 조건이 나온다 |
| 2 어느 광산 | 오른쪽 | 권리증 한 장이 곧 광산 고르기다. 머리의 ◀ ▶로 광산을 넘긴다. 광맥 종류와 도장 값 배수, 도장 다섯. 잠긴 광산도 넘겨 볼 수 있고 '달못 1호 갱을 완납하면 열려요'가 나온다 |
| 3 그 밖 | 작게 | 위쪽 탭 '보통 광산 / 오늘의 광산'(판의 종류). 권리증 아래 '시드 넣기'(누르면 칸이 열린다). 왼쪽 위 '타이틀로' |
| 출발 | 오른쪽 아래 | '계약하기'(Enter). 잠긴 사람이나 광산을 보고 있으면 '아직 잠겨 있어요'로 눌리지 않는다 |

뺀 것: '도감'(타이틀에 있다), '첫 판 안내로 시작'(설정 창의 '첫 판 안내로 다시'), 규칙 설명 세 줄(첫 판에서 권리증을 건넬 때 배운다. 권리증 아래 한 줄만 남김), '중개인 구 실장' 서명.

첫 판 안내 판은 이 화면을 거치지 않는다. 만화를 이미 본 사람도 곧장 지하 1층으로 가고 권리증은 첫 밤에 받는다.

## 4. 남은 것

- 사람이 열 명을 넘으면 초상 줄을 두 줄로 두거나 좌우로 넘기는 것을 고른다
- 광산이 넷 이상이 되면 권리증 머리의 이름 옆에 '2 / 5' 같은 자리 표시
- 판 준비에 소리(종이 넘기는 소리, 계약 도장 소리)
