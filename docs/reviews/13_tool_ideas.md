## 0. 요약

| 구분 | 내용 |
|---|---|
| 판단 | 도구 '개수'보다 도구가 돌아가는 '방식'을 늘리는 쪽이 값이 크다. 지금 12종은 모두 "언제나 켜진 조건부 효과" 한 가지 꼴이다 |
| 먼저 해 볼 장치 셋 | (1) 세는 도구: 아이콘에 숫자가 붙고 n번째에 터진다. (2) 실수 전까지: 오늘 첫 실수 전까지만 켜지는 도구. (3) 도장 선물의 단점 도구: 세지만 한 가지를 포기하는 도구 |
| 이 게임만 할 수 있는 것 | 찍기 판정. 숫자로 확실한 칸이 하나도 없을 때를 게임이 알아보고, 그때만 보험이나 상을 준다. 추리를 지키면서 운의 억울함을 줄인다. 층을 만들 때 쓰는 추리 검사가 이미 있어 비용이 작다 |
| 지금 규칙의 빈 곳 | v2.2 시험은 되팔기가 없어 도구 칸 5개가 차면 밤 상점이 죽는다. 합치기(같은 도구를 또 사면 강해짐, 두 도구가 하나로)가 출구가 된다 |
| 열린 결정과 이어지는 것 | '납부 실패 시 1회 유예'를 규칙 대신 도구로 풀 수 있다(외상 장부, 4.7) |
| 피할 것 | 무작위로 답을 알려 주는 도구, 늘 하는 행동에 붙은 셈(사실상 수치 막대), 끝없는 이자, 판을 대신 풀어 주는 도구. 8장 |
| 후보 수 | 도구 장치 13가지, 새 도구 41종(소모품 4 포함) |

## 1. 거르는 기준

조사한 아이디어 140여 개를 아래 기준으로 걸렀다.

| 기준 | 내용 |
|---|---|
| 추리를 지킨다 | 답을 알려 주는 도구는 조건(콤보 단계, 깨끗한 줄, 큰 숫자)이나 횟수(층마다 한 번)로 묶는다. 값이나 콤보를 바꾸는 도구가 정보를 주는 도구보다 안전하다. Dicey Dungeons 만든 사람의 말대로 "계획할 수 있는 장비 + 굴림"이 공정하게 느껴진다 |
| 수치 막대 금지 | 원칙(05 4.1)을 지킨다. "바위 15번마다 촛불 +3"은 바위를 늘 깨므로 사실상 촛불 +20%다. 이런 꼴은 뺐다 |
| 고리 | 효과가 다른 축의 방아쇠를 당긴다. 축이 아닌 것(주머니, 빚, 깊이)도 고리의 끝이 될 수 있다 |
| 마우스만 | 도구를 쓰는 동작은 쓰는 칸 버튼 → 칸 누르기. 숫자를 한 번 더 누르는 동작은 이미 '둘레 한꺼번에 열기'라서 다른 뜻을 겹치지 않는다 |
| 셈이 보인다 | 세는 값, 남은 횟수, 쌓인 값은 도구 아이콘에 숫자로 붙인다(Slay the Spire의 펜촉, Balatro의 "지금 +12") |
| 지금 규칙 기준 | v2.2 시험 규칙 위에서 생각했다. 콤보는 곡괭이로 지뢰를 칠 때만 끊긴다(발파·불발·빈 칸은 끊지 않는다). 올라가기는 언제든 공짜다. 불씨와 어두워짐은 없다 |

## 2. 도구 장치 13가지

추천은 셋 단계다. 셋: 먼저 넣어 본다. 둘: 그다음. 하나: 정식 범위에서 고민한다.

### 2.1 세는 도구 (추천 셋)

| 항목 | 내용 |
|---|---|
| 빌려 온 곳 | Slay the Spire 펜촉(공격 10번째마다 피해 두 배), 쌍절곤(공격 10번마다 에너지 +1), 쿠나이(한 턴에 공격 셋이면 민첩). Balatro 단골 카드(6번째 손마다 ×4) |
| 어떻게 | 도구 아이콘에 숫자가 붙어 하나씩 오르고, n번째에 터진다. 날이 바뀌어도 이어 센다(도구마다 적는다) |
| 왜 재밌나 | 보상이 예측돼서 계획이 생긴다. "다음이 열 번째니까 큰 보석에 O를 그어 두고 아껴 두자." 같은 행동이 쌓여 한 방이 된다 |
| 우리 판 | 열 번째 곡괭이, 도화선 묶음, 계단 표(3장) |
| 위험 | 셈 부담. 숫자는 반드시 아이콘에 보인다. 늘 하는 행동(바위 깨기)을 세면 수치 막대가 된다 |

### 2.2 실수 전까지 (추천 셋)

| 항목 | 내용 |
|---|---|
| 빌려 온 곳 | DemonCrawl 말발굽(다음 실수까지 전리품 두 배), 신성한 커피(실수 전까지 4 이상 숫자를 열면 목숨 회복), 부의 탐구(실수 없이 n칸이면 돈) |
| 어떻게 | 판 전체에 '깨끗한 줄' 상태 하나를 둔다. 실수는 두 가지다: 곡괭이로 지뢰를 침, 불을 붙인 칸이 보물이라 녹음. 하루가 시작되면 깨끗한 줄이 켜지고 첫 실수에 꺼진다. 여러 도구가 이 상태를 읽는다 |
| 왜 재밌나 | 이 게임의 가장 좋은 플레이(확실할 때만 친다)에 바로 상을 준다. 완벽한 층(01 14.3)과 결이 같다. 실수가 둘이라 도구 설계 자리가 두 배다 |
| 우리 판 | 말발굽, 장인 앞치마, 깨끗한 손(3장) |
| 화면 | 촛불 줄 옆에 작은 표시 하나. 꺼질 때 "깨끗한 줄이 끊겼어요"를 기록 창에 |
| 위험 | 실수를 겁내 아무것도 안 하는 플레이. 그래서 '걸기'(위험한 줄 아는 칸을 치기)는 맞히면 실수가 아니고, 틀릴 때만 실수다 |

### 2.3 찍기 판정 (추천 셋, 이 게임만 할 수 있음)

| 항목 | 내용 |
|---|---|
| 빌려 온 곳 | DemonCrawl의 "찍어야 할 때"(If you have to guess). 통 속의 뇌(찍어야 하는지 알려 줌), 반짝 하수인(찍어야 할 때마다 칸 하나를 풀어 줌), 초보 숙련(어쩔 수 없는 찍기를 틀리면 피해 1만) |
| 어떻게 | 행동이 끝날 때마다 지금 층에 숫자와 표지판으로 확실한 칸(안전, 보물 확실, 지뢰 확실)이 하나라도 남았는지 본다. 하나도 없으면 '찍을 때'다. 화면 힌트가 이미 쓰는 추리 검사를 그대로 쓴다 |
| 왜 재밌나 | 추리를 대신하지 않고 운의 억울함만 덜어 준다. 확실한 칸이 남았는데 찍은 사람은 보호받지 못하니 추리를 더 하게 만든다. 지뢰찾기 게임의 가장 큰 불만(마지막에 50:50)을 정면으로 다룬다 |
| 우리 판 | 셈 등불, 운 보험, 배짱 표(3장) |
| 위험 | 확실한 칸이 남았는지 '알려 주는' 것 자체가 정보다. 셈 등불은 싸고 약하게 둔다. 봇과 사람 모두 같은 검사를 쓰니 측정이 쉽다 |

| 왜 재밌나 | 단점이 퍼즐이 된다. "내 빌드는 이걸 안 써도 돼" 하고 알아보는 것이 실력이다. 도장 선물이 Slay the Spire의 보스 상자 같은 큰 순간이 된다 |

### 2.5 합치기와 겹쳐 사기 (추천 둘)

| 항목 | 내용 |
|---|---|
| 빌려 온 곳 | Ball x Pit(레벨 3인 둘이 하나의 새 도구로 진화하며 칸이 빔), Necrosweeper(같은 것 셋이면 더 센 하나), Binding of Isaac 변신(같은 계열 셋이면 변신) |
| 어떻게 | 두 가지를 쓴다. (1) 겹쳐 사기: 이미 가진 도구를 또 사면 칸을 쓰지 않고 2단계가 된다(긴 도화선 두 걸음 → 세 걸음). 최대 2단계, 값은 원래 값 그대로. (2) 합치기: 정해진 두 도구를 가진 채 도장을 찍으면 도장 선물 하나로 '합치기'가 뜬다. 둘이 하나가 되고 칸이 하나 빈다 |
| 왜 재밌나 | v2.2는 되팔기가 없어 칸이 차면 상점이 죽는다. 합치기가 출구가 된다. 진열에 겹친 도구가 떠도 헛것이 아니다. 숨은 조합을 찾는 재미가 있다 |
| 예 | 긴 도화선 + 설익이 정제기 → 큰 줄 도화선: 이어 터진 지뢰가 3개 이상이면 마지막 자리에 큰 금덩이(금 알갱이 대신 청록 보석 하나). 감정 렌즈 + 내기 분필 → 노름꾼 눈: 감정 렌즈가 콤보 ×1에서도 켜지고, 내기 분필의 지뢰 피해 +1이 없어져요 |
| 위험 | 정답 빌드 하나로 몰릴 수 있다. 합치기 목록은 한 번 찾으면 도감에 남긴다 |

## 5. 먼저 해 볼 묶음

프로토타입에 넣어 보기 좋은 순서다. 처음 묶음은 장치 셋을 하나씩 보여 주는 도구로 고른다.

| 순서 | 넣을 것 | 이유 | 구현 비용 |
|---|---|---|---|
| 1 | 아이콘 숫자 + 열 번째 곡괭이, 도화선 묶음 | 세는 도구 장치를 가장 싸게 시험한다. 도구 아이콘에 숫자를 붙이는 화면 하나면 된다 | 작음 |
| 2 | 깨끗한 줄 + 말발굽, 깨끗한 손 | 실수 전까지 장치. 완벽한 층과 함께 '깨끗하게 캐기'를 목표로 만든다 | 작음 |
| 3 | 도장 선물 넷째 칸 + 곽 씨 인장, 유리 곡괭이, 두건 등불 | 도장 선물이 큰 순간이 된다. 도장 선물 화면은 이미 있다 | 작음 |
| 4 | 찍기 판정 + 운 보험, 셈 등불 | 이 게임만 할 수 있는 장치. 추리 검사를 행동마다 한 번 더 부르는 비용을 잰다 | 중간 |
| 5 | 외상 장부 | 1회 유예 결정을 도구로 시험한다 | 작음 |
| 6 | 겹쳐 사기 | 칸이 찬 뒤 상점이 죽는 문제를 푼다 | 중간 |

잴 것은 Slay the Spire 만든 이들이 쓴 방식을 따른다(GDC 2019 "지표로 하는 설계와 균형"): 도구마다 봇이 고른 비율과, 가졌을 때 마지막 도장 통과율의 변화. 한 번도 안 골리는 도구와 통과율을 10%p 넘게 올리는 도구를 표시한다. 봇이 새 도구를 고르는 기준(정책)도 같이 고쳐야 한다.

## 6. 화면에서 지킬 것

| 항목 | 내용 |
|---|---|
| 아이콘 숫자 | 세는 값, 쌓인 값, 남은 횟수, 남은 날은 아이콘 오른쪽 아래에 작은 숫자로. Slay the Spire와 Balatro가 같은 방법을 쓴다 |
| 발동 연출 | 지금 규칙(01 15.5)대로 발동한 도구 아이콘이 차례로 튄다. 세는 도구는 숫자가 오를 때도 작게 튄다 |
| 설명 칸 | 도구에 마우스를 올리면 설명 칸에 상점 문장과 지금 값("지금 7 / 10")을 함께 |
| 깨끗한 줄 | 촛불 줄 옆 작은 표시 하나. 실수 순간 꺼지는 연출 |
| 찍을 때 | 셈 등불이 없으면 화면에 따로 보이지 않는다. 운 보험이 발동한 순간에만 "확실한 칸이 없었어요. 운 보험이 막았어요"를 기록 창에 |

## 7. 이미 있는 것과 겹침

|---|---|---|

| 저녁 교대 | 빠진 어두워짐 | 어두워짐을 되살리지 않고 분위기만 가져온다 |
