# 20. 처음부터 끝, 그리고 끝 너머 (러프, 2026-11-25)

v2.2 시험 규칙(프로토타입 기본)으로, 처음 켠 사람이 게임을 만나 떠나기까지를 거칠게 적었다. 자세한 규칙은 01, 장면 묘사는 06, 문구는 02가 기준이다. 뒤쪽 '아직 없는 것'은 기획서와 프로토타입 코드를 맞대어 본 결과다.

## 1. 처음: 켜서 첫 도장까지 (첫 판, 약 15분)

1. **타이틀.** ONE CANDLE DEEP. 처음이면 '시작하기' 하나가 크다.
2. **오프닝 만화 세 컷.** 비 오는 골목의 헐값 광산 전단 → 중개소 책상의 구 실장 → 보름달 아래 촛불 하나 들고 갱구로. 규칙은 가르치지 않는다.
3. **곧장 판으로.** 첫 판은 광부로만 한다. 권리증도 선물도 없이 지하 1층에 선다. 시작하자마자 둘레가 와르르 열리고, 판 아래에 "숫자 = 둘레 8칸의 지뢰 + 보물" 한 줄.
4. **Day 1 지하 1~3층(손으로 놓은 층).** 첫 보물(+20, 콤보가 붙음) → 같은 모양인데 지뢰(체력 −1, 콤보 끊김) → 계단은 처음부터 보이고, 가는 길을 숫자로 푼다 → 갈림길 카드 두 장에서 광맥을 고른다(짝 / 테두리 / 외톨이) → X를 긋고 발파 → 촛불이 다 타면 하루 끝.
5. **Day 1 밤.** 정산(주머니가 금고로) → 구 실장이 잊었던 권리증을 건넨다. "첫 도장은 사흘째 밤, 300입니다." → 상점(청진 망치, 감정 렌즈, 곽 씨 부적).
6. **Day 2~3.** 오늘의 광맥이 주는 추리, 바랜 분필 자국은 없다(첫 판 층). Day 3은 지하 3층에 큰 덩이 자리가 금빛 점선으로 보인다.
7. **첫 도장.** 금고에서 300이 빠지고 도장 하나. 모자라면 첫 판만 한 번 기다려 준다(모자란 만큼 두 번째 도장에 얹음). 여기서부터 **도장 선물**, **옛 연장함**, **유물**이 열린다.

여기까지 느끼는 것: 숫자가 '뭔가 있다'까지만 말해 주고, 광맥이 그것을 '보물이다'로 바꿔 준다. 캐면 돈과 길이 같이 열린다.

## 2. 가운데: 한 판의 리듬 (15일, 50~60분)

### 하루 (3~4분)
- 아침 게시판은 건너뛰고 바로 내려간다. 촛불 80.
- 층마다: 계단 자리는 보이고, 남은 보물·지뢰 수가 머리 줄에. 숫자 추리 → 분필(X·O) → 캐기(촛불 1) / 발파(4) / 숫자를 한 번 더 눌러 둘레 한꺼번에 열기(1).
- 콤보는 보물을 이어 캐면 ×1 → ×3(도구로 ×4·×5). 지뢰를 밟으면 ×1.
- 지하 2층부터 가끔 옛 연장함이 보물 칸에 묻혀 있다(촛불이 흔들림). 캐면 도구 둘 중 하나, 넷에 하나는 유물.
- 층마다 바랜 분필 자국 0~3개. 늘 맞는 남의 표시가 추리의 발판이 된다.
- 계단 → 갈림길 두 장 → 내려가면 촛불 2 + 층 번호. 깊을수록 보물이 많고 비싸다.
- 끝나는 세 가지: 촛불이 다 탐, 올라가기, 쓰러짐(주머니 절반을 곽 씨가 가져감). 층을 떠날 때마다 덮인 칸의 답을 한 줄씩 보여 준다.

### 밤
- 정산: 층마다 번 돈, 완벽한 층 표시, 다음 도장까지의 진척.
- 상점(심 씨): 도구 셋, 다시 보기 20, 팔기 50%. 도구 칸 8.

### 도장 찍는 날 (3·6·9·12·15일째)
- 그날은 깊은 층에 큰 덩이(자리가 보임). 콤보를 살려 가면 값이 크다.
- 밤에 300 / 900 / 1,900 / 3,400 / 5,500. 도장마다(마지막 빼고) 도장 선물: 도구 셋 중 하나 또는 금고 돈.
- 도장 2·3·4개째에 갱이 한 층씩 깊어진다(지뢰와 보물이 는다). 캔 값은 ×1.5에서 멈춘다.
- 도장을 찍은 밤, 연장함에서 나온 도구와 짝이 맞으면 곽 씨가 둘을 합쳐 준다(합친 도구 3종).
- 모자라면 그 밤에 도구를 팔거나 심 씨 외상(한 판 한 번, 다음 도장 1.5배). 그래도 모자라면 **계약 해지**로 판이 끝난다. 해지 화면은 모자란 돈을 가장 크게, 아래에 비교 한 줄.

판의 뼈대: 도장 사이 사흘마다 '돈을 도구에 쓸까, 금고에 둘까'를 정하고, 하루마다 '마지막 촛불 몇 개를 어디에 쓸까'를 정한다.

## 3. 끝: 마지막 도장 (15일째 밤)

- 5,500을 내면 도장 다섯. "이제 손님 광산입니다." 금고에 남은 돈이 점수이고 가장 크게 뜬다.
- 권리증 뒷면 작은 글씨: "본 매물은 전체 중 왼쪽 새끼발가락에 해당함." 구 실장: "다음 매물은 복사뼈입니다. 훨씬 큽니다." 광산이 잠든 거대한 무언가의 몸이었고, 보름 동안 판 것이 발가락 하나였다는 반전. Day 3부터 덩이를 캘 때마다 벽이 울렸던 것이 복선이다.
- 다음 등급(달못 4호 갱)이 열리고, 조건을 채운 캐릭터가 열린다.
- 진 판도 끝이다. 계약 해지 화면 → '같은 광산 다시'. 진 판에서도 열리는 것이 있다(측량사는 첫 판을 끝내기만 하면 열린다).

## 4. 끝 너머

### 4.1 같은 판의 너머: 끝없는 갱
마지막 도장 뒤 "더 파시겠습니까?" → '끝없는 갱으로'. 16일째부터 사흘마다 직전 도장의 1.5배(8,300 → 12,500 → 18,800 …), 도장마다 층에 지뢰 +1(최대 8), 외상은 없다. 못 내면 "끝없는 갱 n일째에서 멈췄습니다". 버틴 날이 기록이다.

### 4.2 다음 판들: 다시 할 이유
| 이유 | 내용 |
|---|---|
| 사람 다섯 | 광부 → 측량사(첫 판을 마치면) → 해체공(첫 완납) → 노름꾼(한 판에 도장 셋) → 폭파공(등급 2 완납). X·O 칸을 누를 때의 행동이 다르다 |
| 광산 셋 | 달못 1호 → 4호(+눈금, 값 ×1.3) → 9호(+지뢰 짝, ×1.8). 등급마다 최고 점수 |
| 도구 14 + 합친 도구 3 + 유물 12 | 판마다 다른 조합. 도감이 채워진다(처음엔 '이름 모를 연장') |
| 오늘의 광산 | 날짜로 정한 같은 판. 이 브라우저 최고 점수 |
| 시드 | 6자리 코드로 같은 판을 친구와 나눈다 |
| 완벽한 층 | 보물을 다 캐고 지뢰를 한 번도 안 밟은 층. 보너스 없는 자랑 |
| 통계 | 판 수, 완납 비율, 연속 완납 |

### 4.3 이야기의 너머 (등급 4~7, 정식 출시 범위)
등급이 오를 때마다 권리증 뒷면의 부위가 커지고 무언가가 드러난다. 복사뼈(보석과 설익이가 같은 재료) → 무릎(낙서 일부는 구 실장 글씨, 그도 광부였다) → 배꼽(곽 씨의 광산은 닫히지 않는다) → 쇄골(중개소 장부) → 귀(광산이 처음부터 듣고 있었다, 광산의 대사 한 줄) → 정수리(미정).

### 4.4 제품의 너머
웹 프로토타입 → 사람 5명 플레이테스트 → Godot 본 개발 → 데모와 스팀 넥스트 페스트 → 앞서 해보기(등급 1~3, $9.99) → 정식(등급 4~6, $12.99).

### 5.3 기획 자체가 비어 있는 것

- **이긴 뒤의 이야기.** 프로토타입의 끝은 등급 3이고, 등급 7 반전은 '미정'이다. 끝없는 갱은 끝도 이야기도 없이 버틴 날만 남는다. 게임 전체의 '마지막 장면'이 정해지지 않았다.
- **판 밖 진행의 폭.** v2.2에는 캐릭터 열림, 등급, 오늘의 광산, 통계뿐이다. 01 14.1의 업적, 도구 해금, 시작 키트, 꾸밈을 v2.2에 둘지 정하지 않았다. 05는 아직 v2.1 기준(업적 16, 도구 32)이다.
- **개발 범위와 공수.** 04는 v2.1 기준이라 캐릭터, 유물, 끝없는 갱, 시드, 연장함이 빠져 있다. v2.2를 채택하면 다시 재야 한다.
- **열린 결정.** 처음 하는 사람의 통과율과 첫 판 할인, 심 씨 외상, v2.2 채택, 촛불 양, 둘레 한꺼번에 열기, 상표.
