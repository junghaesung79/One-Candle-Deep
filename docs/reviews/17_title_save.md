# 17. 켤 때 지나가는 화면들: 스플래시, 타이틀, 오프닝, 이어하기 (2026-11-24)

같은 날 고찰하고 타이틀과 이어하기를 만들었다(결정 R112, 화면 03 3.3.0, 저장 01 18.3).

## 1. 말 정리

| 이름 | 뜻 | 원 캔들 딥 |
|---|---|---|
| 스플래시 | 켜자마자 잠깐 뜨는 회사·엔진 로고 | 두지 않는다 |
| 타이틀(메인 메뉴) | 게임 이름과 '새 게임 / 이어하기 / 설정'을 고르는 첫 화면 | 만들었다 |
| 오프닝(인트로) | 시작 때 나오는 짧은 이야기 | 3컷 만화(첫 판만 자동) |
| 튜토리얼 | 조작과 규칙을 익히는 첫 판 | 첫 판 안내 |
| FTUE·온보딩 | 처음 켰을 때부터 몇 판 동안의 경험 전체 | reviews/16 |

## 2. 고찰 전 상태

- 타이틀이 없었다. 켜면 바로 판이 시작됐다(처음이면 만화 → 지하 1층, 두 번째부터 권리증).
- 판 저장이 없었다. 새로고침하거나 탭을 닫으면 진행 중인 판이 사라졌다. 15일짜리 판에서 가장 큰 구멍이었고, 플레이테스트 도중 탭을 닫으면 기록도 끊겼다.
- 03의 화면 흐름 표(타이틀 → 광산 선택 → 시작 키트 → 만화 → 권리증)는 옛 설계였다. 실제로는 권리증 하나가 등급, 캐릭터, 시드, 오늘의 광산을 맡고 있었다.

## 3. 판단

| 무엇 | 판단 | 이유 |
|---|---|---|
| 스플래시 | 안 만든다 | 1인 개발이라 보일 회사 로고가 없다. Balatro도 켜면 곧바로 타이틀이다. Godot 기본 부팅 화면도 끈다 |
| 타이틀 | 작게 만든다 | 이어하기가 들어갈 자리. 웹에서는 사람이 한 번 눌러야 소리가 나므로 '시작하기' 한 번이 소리를 여는 열쇠가 된다. 나중에 스팀 데모의 '찜하기' 단추 자리 |
| 오프닝 만화 | 그대로 | 짧고, 건너뛸 수 있고, 첫 판에만 나온다. 타이틀에 '오프닝 다시 보기'만 더한다 |
| 판 준비 화면 | 권리증이 맡는다 | Slay the Spire의 캐릭터 고르기처럼 이야기 속 물건 하나로. 광산 선택·시작 키트 화면을 따로 두지 않는다(덜어내기) |
| 판 저장·이어하기 | 가장 먼저 | 판 상태가 함수 없는 자료(한 판 최대 약 50KB)라 통째로 적으면 된다 |
| 프로필 여럿, 언어, 크레딧 | 나중(Godot) | 지금은 필요 없다 |

## 4. 타이틀의 모양

- 그림이 이름이 된다: 밤의 갱구와 촛불 하나만 흔들린다. 판을 하며 열린 사람이 갱구 앞에 하나씩 선다(화면이 조금씩 변하는 즐거움을 싸게 낸다).
- 메뉴는 쓸 일이 생길 때 하나씩 는다(reviews/16과 같은 원칙). 처음에는 '시작하기' 하나, 판이 있으면 맨 위에 '이어하기'와 그 판의 한 줄, 한 판 뒤 '도감'.
- '아무 키나 누르세요'는 두지 않는다. 마우스 게임이고 한 번 누르는 것이 곧 시작이다.
- 판이 끝나면 '다시 계약하기'로 타이틀을 거치지 않고 권리증으로 간다. 다시 하기가 빨라야 로그라이트가 굴러간다. 타이틀은 켤 때만 지나간다.

## 5. 흐름

- 처음 켰을 때: 타이틀(시작하기) → 오프닝 만화 → 지하 1층 → 첫 밤에 권리증
- 다시 켰을 때: 타이틀 → 이어하기(그 날, 그 층으로) 또는 새로 하기(권리증)
- 판 끝: 판 끝 화면 → 다시 계약하기(권리증). 타이틀은 설정 창의 '타이틀로'

## 6. 남은 것

- 설정을 타이틀에서도 열 수 있게(소리가 들어오면 필요)
- 스팀 데모 빌드의 '찜하기' 단추
- 연출 도중의 상태(갈림길 창, 말풍선 줄)는 저장하지 않는다. 이어하면 계단을 다시 누르면 된다
