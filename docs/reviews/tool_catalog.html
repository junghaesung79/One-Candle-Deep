캐릭터는 X 칸이나 O 칸을 누를 때 하는 일 하나만 바꾸고, 좋고 나쁜 점은 그 행동 안에 담습니다. '이번에 고침' 딱지는 밸런스를 맞춘 다섯 명입니다(해체공, 폭파공, 광맥꾼, 갱 반장, 화약 장수). 그래서 해체 집게, 내기 분필, 긴 도화선은 도구에서 빼고 캐릭터만의 스킬로 두었습니다. 점선 테두리는 새 캐릭터(안)입니다. '바뀜' 딱지는 이번에 재료를 바꾸거나 새로 넣은 합친 도구입니다. 콤보는 0단계(×1)부터 한 단계 +0.25, 기본 상한 8단계(×3)입니다. '누름' 딱지는 눌러서 쓰는 도구입니다.
