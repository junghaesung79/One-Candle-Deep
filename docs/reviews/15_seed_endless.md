# 시드와 끝없는 갱 설계안 (2026-11-24)

이 문서는 설계안이다. 2026-11-24에 1~4단계를 구현했다(01 15.10·15.11, 결정 R109·R110). 바뀐 점: 시드 코드는 7자리가 아니라 6자리(30^6)로 했다. 7자리는 32비트를 넘는 코드가 생겨 넣은 코드와 보이는 코드가 달라졌다. 판본이 다른 시드를 알아보는 경고는 아직 없다(판본 숫자만 보인다). 5단계(행동 기록)는 아직이다.

## 1. 목표

| 목표 | 뜻 |
|---|---|
| 같은 시드, 같은 선택이면 같은 판 | 친구에게 시드를 주면 같은 광산을 판다. 고른 길(갈림길 광맥)이 같으면 층도 같다 |
| 시드가 내 플레이에 덜 흔들림 | 어떤 층에서 쓰러졌는지, 낙서를 몇 번 봤는지 같은 것이 상점 진열이나 다음 날 광산을 바꾸지 않는다 |
| 버그를 다시 볼 수 있음 | 시드와 행동 기록만 있으면 그 판을 처음부터 다시 돌린다 |
| Godot으로 옮겨도 같은 결과 | 자바스크립트에서 만든 시드가 Godot에서도 같은 광산을 만든다 |
| 엔딩 없이 계속 | 마지막 도장 뒤에도 '끝없는 갱'으로 날이 이어지고, 광산은 시드로 끝없이 만들어진다 |

## 2. 지금 상태

- 판마다 32비트 숫자 시드 하나. 무작위 시드는 시각에서 만든다. 오늘의 광산은 날짜에서 만든다.
- 층은 '시드, 날, 오늘 몇 번째 층, 고른 광맥'을 섞은 값으로 만든다. 같은 시드에 같은 길을 고르면 같은 층이 나온다. 좋다.
- 문제: 상점 진열, 광산 변덕 계획, 낙서, 쓰러질 때 대사가 '하나의 이어지는 무작위 흐름'을 나눠 쓴다. 그래서 낙서가 한 번 더 나오면 그날 밤 상점 진열이 바뀐다. 같은 시드인데 상점이 다르다.
- 시드를 넣는 화면이 없다. 판 끝에 숫자로만 보인다.
- 규칙이나 수치를 바꾸면 같은 시드라도 광산이 달라진다. 판본 표시가 없다.

## 3. 시드 모양

| 항목 | 제안 |
|---|---|
| 보이는 꼴 | 7글자 코드, 가운데 줄표. 예: `K7Q-M2XP`. 헷갈리는 글자(0, O, 1, I, L, U)를 뺀 32글자만 쓴다. 7글자면 32비트를 다 담는다 |
| 아무 글이나 | 코드 꼴이 아니면 글을 그대로 해시해서 시드로 쓴다. "엄마생일"도 시드가 된다(마인크래프트 방식) |
| 비우면 | 무작위 |
| 판본 | 시드 옆에 규칙 판본을 붙여 보인다. 예: `K7Q-M2XP · 2.2`. 다른 판본의 시드를 넣으면 "다른 판본의 시드라 광산이 다를 수 있어요"라고 알린다 |
| 오늘의 광산 | 날짜에서 만든 시드. 코드로도 보여서 친구에게 줄 수 있다 |

## 4. 무작위 흐름 나누기(핵심)

원칙: 모든 무작위는 '시드 + 용도 + 그때를 가리키는 번호'를 섞어 그 자리에서 새로 만든다. 여러 곳이 순서대로 꺼내 쓰는 공용 흐름은 쓰지 않는다. 그래야 한 곳에서 무작위를 한 번 더 쓰거나 덜 써도 다른 곳이 흔들리지 않는다.

| 용도 | 섞는 값 | 지금 | 바꿀 것 |
|---|---|---|---|
| 판 계획(도장 선물 계획, 변덕 등) | 시드, '계획' | 일부 공용 흐름 | 따로 |
| 층 모양 | 시드, 날, 깊이, 지나온 갈림길 | 날, 오늘 몇 번째 층, 광맥 | '몇 번째'를 '깊이'로. 갈림길 고른 순서를 함께 섞는다 |
| 옛 연장함 자리, 안에 든 것 | 시드, 날, 깊이, '연장함' | 따로 | 깊이로 |
| 바랜 분필 자국 | 시드, 날, 깊이, '분필' | 따로 | 깊이로 |
| 도장 선물 | 시드, 날, '선물' | 따로 | 그대로 |
| 상점 진열 | 시드, 날, '상점', 다시 보기 횟수 | 공용 흐름 | 따로. 다시 보기 n번째 진열도 늘 같다 |
| 낙서, 인물 대사 | 시드, 날, 깊이, '말' | 공용 흐름 | 따로(화면용이지만 같이 정리) |

- 갖고 있는 도구에 따라 후보가 줄어드는 곳(연장함, 선물, 상점은 가진 도구를 빼고 뽑는다)은 같은 시드라도 결과가 달라진다. "같은 선택이면 같다"는 약속 안이라 괜찮다.
- 층 모양은 한 번 만들면 그날 안에서는 저장해 두고 다시 만들지 않는다.

## 5. 층 만들기의 결정성

- 층을 만들 때 후보를 여러 번 만들어 보고 숫자로 풀 수 있는 것을 고른다. 시도 횟수에 위아래를 정해 두고, 끝까지 못 찾으면 '가장 잘 풀리는 후보'를 고르는 규칙도 무작위 없이 정한다.
- 정렬할 때 값이 같으면 칸 번호로 순서를 정한다. 언어마다 같은 값의 정렬 순서가 다를 수 있어서다.
- 무작위 수는 정수 연산만으로 만든다(지금 쓰는 방식이 그렇다). '0~1 사이 수 < 확률' 꼴로만 쓴다. Godot에서도 같은 수가 나온다.

## 6. Godot으로 옮길 때: 기준 데이터

- 자바스크립트 쪽에서 '기준 데이터'를 뽑는다. 시드 20개 × 15일 × 깊이 1~6 × 정해진 갈림길 선택으로 만든 층마다 지뢰·보물·계단 자리를 짧은 지문(해시)으로 남긴다. 상점 진열, 선물, 연장함 내용도 같이 남긴다.
- Godot 쪽 시험이 같은 시드로 같은 지문을 내면 이식이 맞은 것이다. 하나라도 다르면 어디서 갈렸는지 바로 보인다.
- 봇 한 판을 행동 기록째 남겨 두면, Godot에서 그 기록을 다시 돌려 같은 점수가 나오는지도 볼 수 있다.

## 7. 끝없는 갱(엔딩 대신)

마지막 도장을 찍으면 구 실장이 묻는다. "광산은 이제 손님 겁니다. 더 파시겠습니까?" 고르면 날이 이어진다. Balatro가 8단계를 깬 뒤 끝없는 모드로 넘어가는 것과 같은 자리다.

| 항목 | 제안 |
|---|---|
| 날 | 16일째부터 끝이 없다. 머리 줄은 "16일째 · 끝없는 갱" |
| 도장 | 3일마다 한 번. 금액은 직전 도장의 1.5배(5,500 → 8,300 → 12,400 …). 못 내면 거기서 판이 끝난다(계약 해지가 아니라 '여기까지') |
| 갱 | 도장마다 시작 깊이가 한 층씩 내려가고, 바닥 깊이에 닿은 뒤로는 층마다 지뢰가 하나씩 는다 |
| 판 계획 | 15일 치를 미리 정하는 대신, 16일째부터는 그날그날 '시드, 날'로 만든다. 그래서 끝없이 만들어진다 |
| 점수 | 버틴 날 수가 먼저, 같으면 금고. 오늘의 광산 순위표에도 이 순서로 |
| 기록 | 판 끝 화면에 "끝없는 갱 22일째까지"와 시드 코드 |

- 끝없는 갱은 처음 하는 사람의 목표(마지막 도장)를 건드리지 않는다. 완납한 사람에게만 열리는 덤이다.
- 1.5배 곡선은 봇으로 재서 "보통 봇이 평균 몇 날 더 버티는지"를 보고 맞춘다.

## 8. 시드 화면

| 곳 | 내용 |
|---|---|
| 권리증 화면 | '시드' 칸 하나. 비우면 무작위. 넣으면 위의 판본 확인 |
| 판 끝 화면, 설정 창 | 지금 시드 코드와 '복사' 단추 |
| 시드를 넣은 판 | 오늘의 광산 기록에는 넣지 않는다. 판 끝 화면에 '시드 판'이라고 작게 |

## 9. 저장과 이어하기

- 판 중간 저장은 그 순간의 상태를 통째로 남긴다(가장 단순하고 판본이 바뀌어도 이어진다).
- 따로 행동 기록(시드, 캐릭터, 클릭한 칸과 고른 것의 목록)을 남긴다. 버그 신고 때 이것만 받으면 다시 돌릴 수 있다.
