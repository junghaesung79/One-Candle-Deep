# 19. 화면 전체 점검: 기준과 고친 것 (2026-11-24)

의뢰인 지적(흔들리는 화면, 중복 정보, 알아보기 힘든 아이콘, 한 화면에 다 놓인 설정, 낡은 갈림길 화면)을 받아, 화면 하나하나를 짚는 대신 기준을 세워 모든 화면 코드(ui.js, index.html, 규칙 모듈의 화면 문구, 그림)를 점검했다. 결정 R114~R116.

원칙: 완벽은 더할 게 없는 상태가 아니라 덜어낼 게 없는 상태다.

## 1. 점검 기준

| 번호 | 기준 | 뜻 |
|---|---|---|
| 1 | 흔들림 없음 | 내용이 생기고 사라져도 자리가 움직이지 않는다. 나타났다 사라지는 줄은 자리를 미리 잡아 두고, 세로로 늘어선 칸은 높이를 같게 한다 |
| 2 | 한 번만 말하기 | 같은 사실을 한 화면에 두 번 보이지 않는다. 늘 보이는 오른쪽 칸에 있는 것을 창에서 되풀이하지 않는다 |
| 3 | 한 번 배운 것은 다시 가르치지 않기 | 매번 똑같이 나오는 풀이 글은 첫 판이나 처음 볼 때만 |
| 4 | 한눈에 읽히는 그림 | 그림만으로 뜻이 서지 않으면 고치거나 글자를 붙인다. 서로 닮은 그림, 다른 뜻에 같은 그림을 쓰지 않는다 |
| 5 | 무게의 순서 | 화면마다 주인공 하나, 주 단추 하나. 가장 중요한 숫자가 가장 크다 |
| 6 | 낡은 것 걷어내기 | v2.2에서 꺼진 장치의 글자와 단추가 남아 있지 않다(v2.1 프리셋에서만 쓰는 것은 그 프리셋에만) |
| 7 | 판 위는 판만 | 판 바닥에 설명 글을 쓰지 않는다 |
| 8 | 말투 | 설명 문구는 합니다체, 인물 대사만 인물 말투 |

## 3. 말과 이름

- 설명 문구를 모두 합니다체로 바꿨다. 인물 대사만 인물 말투(구 실장 합니다체, 곽 씨 하게체, 심 씨 반말).
- 옛 연장함에서 나오는 영구 물건을 '유품'에서 '유물'로 부른다. 더 익숙한 말이다. 그래서 가장 비싼 보물 등급의 이름을 '유물'에서 '금잔'으로 바꿨다(그림이 금빛 잔이다).

## 4. 갈림길

고를 때 두 장이 다른 것만 남겼다.

| 남김 | 뺌 |
|---|---|
| 제목 "지하 N층으로 내려갑니다", 촛불 −N(지금 → 뒤) | "깊을수록 보물이 많고…" 풀이(매번 같다) |
| 카드: 광맥 그림·이름·표지판 한 줄·도면, 보물·지뢰 수, 덤, 큰 덩이. 2026-11-26에 같은 줄에 '다 캐면 약 N'을 더했다(R119): 등급 비율은 두 장이 같아도 깊이에 따른 값은 화면 어디에도 없었다 | 보물 등급 비율(두 장이 늘 같다), 아래 "지금: 콤보·체력·주머니"(오른쪽 칸에 있다) |
| 이 브라우저에서 처음 보는 광맥에만 풀이 한 줄(자리는 늘 같다) | 이미 본 광맥의 풀이, '처음' 표시(판마다 다시 붙어 고르는 데 도움이 안 된다) |

카드를 누르면 고르기만 하고, '내려가기'로 정한다. 선물·연장함과 같은 방식이다.

## 5. 일시 정지와 설정

크게 팔린 게임들(Slay the Spire, Balatro, Hades II, Celeste)은 멈춤 메뉴에는 할 일만 두고, 고르는 값은 탭으로 나눈 설정 창에 둔다. 판 포기에는 확인을 받고, 타이틀로 가기는 판을 지운다는 뜻이 아니다.

| 창 | 내용 |
|---|---|
| 일시 정지(Esc, 톱니) | 계속하기 · 설정 · 도감 · 판 포기 · 타이틀로(판은 남는다) |
| 설정 '게임' | 첫 판 안내 다시 하기(첫 판 중이면 건너뛰기), 이번 판의 캐릭터·시드·규칙과 시드 복사 |
| 설정 '화면' | 화면 흔들림, 지뢰 플래시, 전체 화면 |
| 설정 '소리' | 전체 음량, 음악, 효과음(10 단위 막대, 바꾸면 짧게 한 번 울린다), 창이 뒤에 있으면 소리 끄기. 소리가 들어오기 전까지는 흐리게 막고 '소리는 아직 없습니다'를 얹는다(2026-11-25) |
| 설정 '조작' | 조준, 키보드 한 표 |
| 설정 '기록' | 판 수·완납·최고 점수, 플레이 기록 내려받기·지우기, 오프닝 만화 다시 보기 |

설정 창은 탭을 바꿔도 크기가 같다. 타이틀에서도 연다.

## 6. 도감의 못 얻은 칸

다른 게임들은 못 얻은 칸마다 문장을 쓰지 않는다. Vampire Survivors는 물음표, Balatro는 잠김과 못 찾음을 나눠 잠긴 것에만 마우스를 올리면 조건을 보인다. 공통은 머리에 개수(12 / 40)를 두는 것이다.

그래서 못 얻은 칸은 검은 실루엣과 ???만 두고, 얻는 법은 머리에 한 줄(상점, 옛 연장함, 도장 선물), 칸에 마우스를 올리면 그 칸의 얻는 법(합친 도구는 합치는 조건)을 보인다. 칸 높이는 얻었든 못 얻었든 같다.
