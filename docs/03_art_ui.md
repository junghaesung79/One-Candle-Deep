## 1. 아트 방향

이 장에서 정하는 것: 1차에서 유지하는 시각 원칙, 시야 2단계를 그리는 방법, 금지 사항.

### 1.1 유지하는 원칙(시안 A)

| 항목 | 규칙 |
|---|---|
| 타일 원본 | 16×16 px |
| 표시 배율 | 3배(48 px). 정수 배율만, 최근접 보간 |
| 시점 | 탑다운. 그림자는 오른쪽 아래 1 px |
| 기준 해상도 | 1280×720 픽셀 퍼펙트. 판 15×11칸(720×528 px) + 오른쪽 정보창. 1080p는 타일 4배(64 px) + 정보창 재배치 |
| 분위기 | 어두운 동굴. 배경 #14121a. 빛은 헤드램프와 촛불에서만 나온다 |
| 어둠 | 계단식 단계 어둠(부드러운 그라데이션 금지). 2차에서는 단계 수가 줄었다(1.2) |
| 폰트 | 숫자·영문 Press Start 2P, 한글 픽셀 폰트(갈무리 계열) 1종 |

### 1.2 시야 2단계

1차의 시야 4단계(반경 5 / 3.5 / 2.5 / 1.5)는 폐기했다. 2차는 평소 전체가 보이고, 촛불이 15 이하로 내려가면 캐릭터 주변 반경 2.5칸만 밝다.

| 상태 | 조건 | 어둠 | 숫자 | 지형·분필·두드려 보기 결과 |
|---|---|---|---|---|
| 평소 | 촛불 16 이상 | 없음 | 전부 보임 | 보임 |
| 좁은 빛 · 안쪽 | 촛불 15 이하, 칸 중심까지 거리 2.5 이하 | 불투명도 0 | 선명 | 보임 |
| 좁은 빛 · 경계 | 거리 2.5 초과 3.5 이하 | 0.45 | 흐린 숫자 | 보임 |
| 좁은 빛 · 바깥 | 거리 3.5 초과 | 0.75 | 흐린 숫자 | 보임 |
| 불씨 다섯 번 | 촛불 0 | 판 전체 0.55 | 전부 가림(흐린 숫자 포함) | 분필은 어둠 위에 원래 밝기로 그림 |

- 거리는 칸 중심 사이 직선거리. 반경 2.5면 캐릭터 둘레 5×5에서 네 귀퉁이를 뺀 21칸이 밝다.
- 흐린 숫자: 이미 한 번 선명하게 본 숫자만 남긴다. 원래 색을 어둠 위 바탕색에 60% 섞어 그리고(숫자 5만 65%) 그림자를 뺀다. 실측 대비는 바위 위 3.0~4.9, 흙 위 3.0~5.1로 읽을 수는 있되 선명한 숫자와 구분된다.
- 흐린 숫자가 보여 주는 값은 마지막으로 본 값이 아니라 현재 값으로 제안한다. 어둠 속 숫자는 플레이어 자신의 행동(보물 캐기, 발파)으로만 바뀌므로 새 정보가 새지 않는다. 마지막 값을 고정하면 발파 뒤 틀린 숫자가 남는다(10장 확인 필요 3번).
- 어둠 밖에서 처음 열린 칸(발파·연쇄로 열린 먼 칸)은 숫자 자리를 비워 둔다. 반경 안에 한 번 들어오면 그때부터 흐린 숫자로 남는다.
- 촛불 막대의 15 위치에 눈금을 상시 그려 좁아질 시점을 미리 보여 준다.
- 16에서 15로 넘어가는 순간의 연출은 6.2.

### 1.3 하지 말 것

| 금지 | 이유 |
|---|---|
| 정수가 아닌 배율, 회전, 자유 크기 조절 | 픽셀이 뭉개짐 |
| 안티앨리어싱 외곽선, 블러, 부드러운 광원 | 단계 어둠과 충돌 |
| 16×16 격자와 어긋난 오브젝트 배치(이펙트 제외) | 판 읽기가 흐려짐 |
| 숫자 칸 위에 팝업·아이콘을 300 ms 넘게 겹치기 | 핵심 정보 가림. 값 팝업은 300 ms 안에 숫자에서 비켜난다 |
| 숫자 1~5 색을 다른 용도(콤보 불꽃, 버튼, 도구 등급)에 재사용 | 숫자 색의 뜻이 흐려짐 |
| 숫자 색을 바꿔서 정보 전달 | 색만으로 구분하는 표시 금지. 테두리·밑줄·작은 그림으로 |
| 현금(금고)과 보물을 같은 그림·같은 색으로 그리기 | 1차 감사에서 "보석이 곧 돈인가" 오해(4장 28번) |
| 오늘 주머니와 금고를 같은 테두리로 그리기 | 잃을 수 있는 돈과 안전한 돈이 섞여 보인다. 주머니는 점선, 금고는 실선 |
| 같은 화면에서 한글 폰트 2종 이상 | 시안 A의 Noto Sans KR은 시안용 |
| 순수 검정 #000000, 순수 흰색 #ffffff | 팔레트 밖. #0b0a10, #f1ece2 사용 |
| 화면 전체 플래시 100 ms 초과, 초당 3회 이상 깜빡임 | 광과민 위험. 광산 깨어남 맥동도 이 기준 안에서 |

## 3. 화면

이 장에서 정하는 것: 2차 화면 흐름, 화면마다 보여 줄 정보 순서, 와이어프레임, 마우스 조작 표시, 폐기한 화면.

예시 수치는 한 상황으로 맞췄다: 등급 1 달못 1호 갱, 첫 판 Day 4(첫 도장 300을 받아 도장 1개, 시세 ×1.5), 다음 도장 2,400(Day 8), 아침 금고 440, 장착 도구 2개(긴 도화선, 연쇄 장부), 소모품 칸에 화약 2개. 금액과 값은 01·05 최신본을 따랐다. 화면 문구는 02 6장·7장이 기준이고, 이 문서의 예시 문구는 의뢰인 피드백에 따라 해요체로 적었다(인물 대사는 인물 말투). 02 개정본이 나오면 그 문구로 바꾼다.

### 3.4 권리증 받기

첫 20초 안에 "무엇을 위해 얼마를 언제까지"를 보여 준다(4장 1번, 3번).

```
+--------------------------------------------------------------+
|                    [권리증 160×100 ×3]                        |
|                    달못 1호 갱 권리증 (가)                       |
|     광산 값은 15일 안에 세 번 나눠 내요.                           |
|       [도장 칸]  첫 도장         300   3일째                     |
|       [도장 칸]  두 번째 도장   2,400   8일째                     |
|       [도장 칸]  마지막 도장   11,000   15일째                    |
|     낼 때마다 도장을 하나 찍어요. 도장이 찍히면 캔 값이 올라가요.     |
|     그날 밤 금고가 모자라면 계약이 끝나요.                          |
|     마지막 도장을 받고 남긴 돈이 이번 판 점수예요.                    |
|                               중개인 구 실장 [이름표]              |
|                                              [내려가기]         |
+--------------------------------------------------------------+
```

### 3.6 채굴 본 화면

1280×720 기준 배치. 판 크기와 위치는 1차와 거의 같다. 판 아래에 상시 범례 한 줄을 둔다. 화면에 키보드 안내는 두지 않는다.

머리 줄(판 위)은 지금 층에 대한 것만 싣는다: 층 이름, 표지판, 남은 보물·지뢰 수, 계단 상태. 날짜는 판 전체에 대한 것이라 오른쪽 정보창 맨 위로 옮겼고, 달 그림은 뺐다.

오른쪽 정보창은 위에서 아래로 "판 → 오늘 버틸 힘 → 콤보 → 돈이 흐르는 길 → 도구 → 설명" 순서다. 칸마다 있는 이유가 있다.

| 칸 | 있는 이유 |
|---|---|
| 날짜 줄 | 오늘이 며칠째이고 며칠 남았는지는 판 전체의 시간이다. 달력과 설정은 판 바깥 일이라 같은 줄 오른쪽에 단추로 둔다 |

계단 빛 번짐(판 위, 층 도착 때부터)

| 항목 | 값 |
|---|---|
| 범위 | 계단 바위를 가운데로 둘레 2칸(가로·세로·대각선 모두, 5×5에서 가운데를 뺀 24칸). 바닥과 바위 모두에 번진다 |
| 단계 | 1칸 고리(8칸) 불투명도 0.16, 2칸 고리(16칸) 0.08. 계단식 두 단계로 칠하고 부드러운 그라데이션은 쓰지 않는다(1.3) |

#### 3.6.7 올라가기 확인 창

올라가기 버튼(또는 단축키 R)을 누르면 판 위에 확인 창이 뜬다. 1차·2차 초판의 'R 길게 누르기 게이지'는 삭제했다.

```
+-------------------- 오늘은 여기까지 할까요? --------------------+
|                                                              |
|   버리는 촛불 64                                               |
|   [주머니] 금고로 가는 주머니 200                                 |
|                                                              |
|          [ 올라가기 ]              [ 계속 파기 ]                  |
+--------------------------------------------------------------+
```
| 상황 | 표시 |
|---|---|
| 기본 | 두 줄: "버리는 촛불 64" / "금고로 가는 주머니 200". 숫자 뒤에 조사를 붙이지 않는다(5.1) |
| 불씨 상태 | 첫 줄을 "남은 불씨 3도 끝나요"로 바꾼다 |
| 기본 버튼 | "계속 파기"에 처음 초점(실수로 하루를 끝내지 않게). 창 밖을 클릭하거나 오른쪽 클릭하면 "계속 파기"와 같다 |
| 첫 판 Day 1 | 체력 1이어도 올라가기 버튼을 붉게 강조하지 않는다. 확인 창 위에 한 줄 "지하 3층까지 가 보세요"(발파·불씨 교육을 놓치지 않게) |
| 크기 | 9분할 패널, 480×200, 판 가운데. 판은 불투명도 0.5로 어둡게 |

#### 3.6.8 마우스 조작과 고르기 상태

조작은 마우스가 기본이다. 키보드 단축키는 늘 켜져 있고(끄는 설정 없음), 판 화면에는 키 안내를 띄우지 않는다. 키 목록은 설정 창에만 적는다.

| 입력 | 결과 | 화면 표시 |
|---|---|---|
| 마우스 올림 | 아무 일 없음 | 그 칸에 귀퉁이 꺾쇠(3.6.4). 커서 모양으로 클릭 결과를 미리 알림(아래 표) |
| 왼쪽 클릭: 열린 땅 | 그 칸까지 걸어간다 | 발자국 커서. 가는 길이 없으면 커서가 흔들리고 "가는 길이 없어요" |
| 왼쪽 클릭: 바위(처음) | 그 바위 옆으로 걸어가 조준 | 조준 테두리. 다른 바위를 클릭하면 조준이 그쪽으로 옮겨 간다 |
| 왼쪽 클릭: 조준한 바위 | 캔다 | 곡괭이 커서, 치기 연출(6.1) |
| 왼쪽 클릭: X 칸 | 발파 | 한 번에 (떨어져 있으면 걸어가서) 발파. 조준을 켰으면 먼저 주황 꺾쇠로 조준 |
| 왼쪽 클릭: 찾은 계단 | 그 칸으로 가서 갈림길을 연다 | 계단 커서 |

고르기 상태(두드려 보기·발파·소모품)

| 단계 | 화면 |

| 들어감 | 행동 버튼을 누른다. 버튼이 눌린 모양(1 px 내려앉음 + 테두리 #ffd25a)으로 남고, 커서가 도구 커서로 바뀐다(두드려 보기 망치, 발파 성냥, 화약 화약 봉지) |

#### 3.6.9 달력

날짜 줄의 달력 단추(작은 달력 그림)를 누르면 화면 안에 달력 창이 뜬다. Esc, 닫기, 바깥 클릭으로 닫는다. 채굴 중에만 열린다.

| 항목 | 규칙 |
|---|---|
| 짜임 | 한 줄이 도장 하나까지의 날들이다. v2.2 시험은 3일씩 다섯 줄이라 도장 날이 늘 줄 끝에 온다. v2.1은 3·5·7일 세 줄 |
| 날 칸 | 46×46. 지난날은 어둡게 하고 그날 번 돈("+120")을 적는다. 쓰러진 날은 붉은 "쓰러짐". 오늘은 금빛 테두리와 "오늘" |
| 도장 날 | 동그란 점선 칸. 도장을 찍었으면 붉은 실선 동그라미(권리증 도장과 같은 색) |

### 3.7 갈림길

찾은 계단을 클릭하면 뜬다. 1차 계단 확인 창(계단 종류 7가지)을 대신한다. 두 카드 모두 고를 수 있다(4장 16번). 카드마다 광맥 말고도 덤 하나와 보물·지뢰 개수 어림이 붙어 고를 이유가 화면에 보인다(2차 검수 7번).

### 3.9 불씨 다섯 번

촛불이 0이 되면 바로 하루가 끝나지 않고 이 상태로 들어간다. 판 구성은 채굴 화면과 같고 아래만 바뀐다.

```
          +-----------------------------------------+ +---------------------------------+
          | 지하 3층  [표지판] 외톨이 광맥 ...            | | [주머니] 오늘 주머니         450   |
          +-----------------------------------------+ |  다음 도장까지 1,510 ...          |
          |                                         | +---------------------------------+
          |   판 전체 어둠 0.55                       | | [꺼진 심지] 불씨                   |
          |   숫자 전부 가림 (흐린 숫자 포함)            | |  [●][●][●][○][○]                  |
          |   분필 X·O는 원래 밝기                      | |  불씨 3 · 숫자는 안 보여요.          |
          |   계단 바위와 빛 번짐, 큰 덩이 단면,         | |  분필 표시는 보여요                 |
          |   두드려 보기 결과는 보임                    | +---------------------------------+
          |   캐릭터 헤드램프 반경 1칸만 살짝 밝음       | | 콤보 ×3  | 체력 [■][■][□]    |
          |                                         | +---------------------------------+
          +-----------------------------------------+ |        [ 올라가기 ] (강조)        |
          | 촛불이 꺼졌어요. 불씨가 다섯 번 남았어요.       | +---------------------------------+
```
| 항목 | 규칙 |
|---|---|
| 불씨 표시 | 촛불 막대 자리에 불씨 5개(16 px)와 "불씨 n · 숫자는 안 보여요. 분필 표시는 보여요". 치면 하나씩 꺼진다. 갱 상태 '불씨가 오래감'인 날은 7개 |
| 쓸 수 있는 행동 | 캐기와 이동만. 두드려 보기·발파 버튼과 계단은 회색(누르면 "불씨로는 못 해요"). X 칸은 평소처럼 캐지지 않는다 |
| 성냥 묶음 | 소모품 칸에 있으면 그 버튼 테두리를 강조한다. 누르면(고르기 없이 바로) 촛불 +10으로 다시 불이 붙고 숫자가 돌아온다(6.11 거꾸로, 600 ms) |
| 위험 표시 | 판 아래 범례 줄이 "불씨일 때 지뢰를 치면 체력이 남아 있어도 쓰러져요"로 바뀐다. 주머니 블록에 경고 배지 "쓰러지면 절반 잃어요"를 늘 띄운다 |
| 끝 | 불씨를 다 쓰면 안내 "불씨가 다했어요." → 하루 끝(3.10). 올라가기 확인 창을 거쳐도 같다 |

### 3.10 하루 끝(주머니 → 금고)

1차 정산표를 2초 연출 화면으로 바꿨다. 연출 순서는 6.12. 아래 예시는 시세 ×1.5인 Day 4다.

```
+--------------------------------------------------------------+
|  4일째 끝 · 불씨까지 다 쓰고 올라왔어요                          |
|  층별 수입 (도장 1개: 캔 값 ×1.5)                               |
|    지하 1층 (맨땅) ............. 34                            |
|    지하 2층 (짝 광맥) .......... 160    최고 콤보 ×2.5             |
|    지하 3층 (외톨이 광맥) ...... 256    발파 2 · 불발 1           |
|    그중 자갈 ................... 118                           |
|                                                              |
|   [주머니] 오늘 주머니 450  ────▶  [금고] 440 → 890              |
|                                                              |
|  중개인 구 실장: 오늘 450 넣으셨습니다. 다음 도장까지 1,510 남았습니다. |
|  주문 A 발파로 지뢰 4개: 달성 → 화약 2개 받았어요                  |
|                                              [상점으로]        |
+--------------------------------------------------------------+
```
| 경우 | 제목 | 주머니 줄 |
|---|---|---|
| 불씨까지 다 씀 | "불씨까지 다 쓰고 올라왔어요" | 그대로 |
| 올라가기 | "일찍 올라왔어요 · 버린 촛불 64" | 그대로 |
| 쓰러짐 | "쓰러졌어요 · 구조꾼 곽 씨가 업고 나왔어요" + 곽 씨 한 줄(02 6.10, 예: "또 자네군. 주머니는 반만 받겠네.") | "오늘 주머니 450 → 225 (절반은 곽 씨 수고비)". 층별 수입은 캔 금액으로 두고 마지막 줄에서 절반을 뺀다. 갱 상태 '곽 씨가 한가함'인 날은 4분의 1 |

- 구 실장 한 줄은 02 6.10 '하루 끝 한 줄'에서 고른다. 구 실장 대사 안에서는 "중도금"처럼 인물의 말을 그대로 둘 수 있지만, 금액 안내 부분은 "다음 도장"으로 맞추도록 02에 요청한다(10장).
- 층별 줄은 그 층의 광맥 이름을 괄호로 붙인다. 층별 금액에는 보물과 자갈이 함께 들어가고, 그 아래 "그중 자갈" 한 줄로 자갈 합계를 따로 보인다(감사 23번, 2차 검수 1번). 금액은 시세가 붙은 값이다.
- 주문을 못 이룬 날은 "주문 A: 3/4 · 못 이뤘어요"만 적고 벌칙은 없다.
- (없앰) 첫 판 Day 1 끝의 '바로 캐기' 안내. 조준은 기본 꺼짐이다.

## 5. UI 문구 원칙

이 장에서 정하는 것: 화면 글자의 표기 규칙, 용어 고정표, 문장 형식, 쓰지 않는 말. 용어와 실제 문구는 02 7장 '화면 용어 정리표'와 02 6장 샘플이 기준이고, 이 장은 그 문구를 화면에 어떻게 놓는지를 정한다. 둘이 어긋나면 02를 따른다.

### 5.3 문장 형식

| 대상 | 형식 | 예 |
|---|---|---|
| 말투 | 게임 안 설명 문구(표지판, 벽 낙서, 말풍선, 로그, 기록 창, 도구·상점 설명, 게시판·주문, 갱 상태·변덕 설명, 확인 창, 설정 설명)는 모두 해요체. '~음', '~함', '~다'로 끝내지 않는다. 인물이 직접 하는 대사(구 실장, 곽 씨, 심 씨)만 인물 말투 | 보물 둘레 8칸에 다른 보물이 없어요 |
| 로그 | 결과 + 이유, 해요체. 한 줄 40자 이내 | 펑. 체력 -1. 위의 2가 이 지뢰를 세고 있었어요. |
| 도구 효과 | "언제 → 무엇이" 두 칸, 해요체. 단점은 세 번째 줄 | 언제: 한 번 발파로 지뢰가 3개 넘게 터지면 / 무엇이: 터진 자리마다 금 알갱이가 남아요(콤보는 오르지 않아요) |
| 버튼 | 동사 + 결과. 버튼 글자에 키 이름을 붙이지 않는다 | 내려가기 (촛불 -6) |
| 확인 창 | 질문 제목 + 결과 두 콤보 + 버튼 두 개(하는 쪽 / 안 하는 쪽) | 오늘은 여기까지 할까요? |

| 표지판 | 이름 + 해요체 한 문장, 누르면 보조 한 줄. 문구는 02 6.5 개정본 | 외톨이 광맥 · 보물 둘레 8칸에 다른 보물이 없어요 |

## 6. 피드백·연출(게임 필)

이 장에서 정하는 것: 행동마다 화면과 소리가 어떻게 반응하는지, 각 연출의 시간(ms)과 대응하는 소리. 연쇄 개방 연출 수치는 이 장이 기준이다.

### 6.0 공통 규칙

| 규칙 | 내용 |
|---|---|
| 판을 막지 않음 | 계산 연출, 값 팝업, 주머니 비행은 판 입력을 막지 않는다. 막는 연출은 히트스톱(최대 200 ms), 화면 전환, 하루 끝, 도장, 확인 창뿐이다 |
| 건너뛰기 | 계산 연출·시작 연쇄·하루 끝·도장은 클릭(또는 아무 키)을 받으면 남은 단계를 최종값으로 즉시 놓는다. 판 위 연출 중 들어온 이동·조준·캐기 클릭은 건너뛴 뒤 그대로 실행한다(10장 8번) |
| 입력 버퍼 | 120 ms |
| 겹침 순서 | 히트스톱 → 폭발·깨짐 → 값 팝업 → 계산 연출 → 주머니 비행. 같은 프레임에 둘 이상이면 이 순서 |
| 흔들림 상한 | 여러 흔들림이 겹쳐도 합이 6 px을 넘지 않는다 |
| 플래시 | 판 영역만, 1회 33 ms. 연쇄 폭발 중에는 첫 폭발만 |
| 연출 속도 설정 | 보통(표의 값) / 빠름(50%) / 즉시(최종 상태만, 소리는 마지막 한 번) |
| 소리 | 같은 소리 연속 재생 시 피치 ±5% 무작위. 단계가 오르는 소리(콤보, 연쇄, 계산)는 정해진 반음씩 올린다 |

### 6.1 치기(바위 1타)

| 상황 | 값 | 소리 |
|---|---|---|
| 입력 → 타격 프레임 | 60 ms(치기 3프레임 중 2번째) | |
| 빈 바위 깨짐 | 히트스톱 70 ms, 흔들림 2 px 120 ms 선형 감쇠, 파편 5프레임 × 50 ms | 바위 깨짐(변형 3) |
| 이동 1칸 | 100 ms | 발소리(변형 2) |
| 치기 반복(길게 누름) | 180 ms 간격. 칸이 깨지면 반복 중단 | |

1차의 '금 갈 때' 단계(히트스톱 40 ms, 흔들림 1 px)와 굳은 바위 단계는 삭제했다.

### 6.2 촛불 감소 표시와 좁은 빛

| 상황 | 값 | 소리 |
|---|---|---|
| 행동마다 감소량 | 숫자 오른쪽에 "-1" 등장, 12 px 위로 400 ms 이동하며 페이드. 막대는 120 ms에 걸쳐 줄어듦 | 없음(-1은 너무 잦음) |
| 계단 통행 | "-6"을 24 px 크기로, 600 ms | 심지 타는 짧은 소리 |
| 발파·두드려 보기 | "-4", "-2" 기본 크기 | 각 행동 소리에 포함 |
| 광산 깨어남 중 치기 | "-2"를 본문색 글자 + #c4432b 1 px 외곽선으로 | 낮은 울림(6.10) |
| 증가(촛불 손질, 연쇄 장부 등) | "+3"이 아래에서 위로, 막대가 120 ms에 늘어난다 | 작은 불꽃 소리 |
| 16 → 15 | 촛불 그림이 짧은 초로 바뀌며 1 px 내려앉음 150 ms. 어둠이 판 가장자리에서 캐릭터 쪽으로 링 단위로 좁혀 옴 300 ms. 이미 본 숫자는 그 사이 흐린 숫자로 바뀐다 | 낮은 바람 소리 1회, 광산 음악에 저역 통과 필터 |
| 촛불 1 | 설명 칸에 "마지막 1이에요. 다음은 불씨 다섯 번이에요" | 짧은 경고 1회 |
| 계단 빛 번짐: 층 도착 | 시작 연쇄(6.3)가 끝나면 빛 번짐이 2칸 고리부터 1칸 고리 순으로 200 ms씩 켜진다(계단을 아직 못 찾아도 보임). 그 뒤 1,600 ms 주기의 두 단계 밝기 변화(3.6.6) | 없음 |
| 계단 빛 번짐: 계단 찾음 | 계단 바위가 깨지는 순간 2칸 고리가 300 ms에 꺼지고 1칸 고리가 0.10으로 남는다 | 계단 발견 |

### 6.3 시작 연쇄(층 진입)

| 순서 | 시점(ms) | 화면 | 소리 |
|---|---|---|---|
| 1 | 0 | 갈림길 페이드 아웃 250 ms 후 새 층 페이드 인 | 내려가기 |
| 2 | 250 | 캐릭터 착지 100 ms | 발소리 |
| 3 | 350 | 연쇄가 캐릭터 칸에서 링 단위로 퍼진다. 총 600 ms(링 간격 자동, 최소 15 ms) | 무너짐 럼블 600 ms + 링마다 틱(피치 +1 반음, 최대 +7) |
| 4 | 950 | 열린 땅 가운데 위에 "자갈 +24"(자갈 묶음 아이콘과 함께) 300 ms 유지 | 자갈 묶음 |
| 5 | 1,250 | "자갈 +24"가 주머니로 350 ms 비행, 주머니 숫자 300 ms 카운트업 | 동전 한 번 |
| 6 | 1,600 | 로그 "입구 주변이 무너져 112칸이 열렸어요. 자갈 24개를 주웠어요". 첫 판 첫 층은 이어서 말풍선 1, 말풍선 7 | |
| 7 | 1,900 | 계단 빛 번짐 켜짐(6.2) | 없음 |

- 연쇄 중 입력이 들어오면 3~5를 최종 상태로 놓는다.
- 숫자가 "+24"처럼 홀로 뜨지 않게 늘 "자갈"을 앞에 붙인다(2차 결정 자갈 표기).

### 6.4 연쇄 개방(층 안)

| 항목 | 값 | 소리 |
|---|---|---|
| 퍼짐 | 시작 칸 기준 거리 링 단위, 같은 링 동시 | |
| 링 간격 | 35 ms, 총 600 ms 상한(자동 축소, 최소 15 ms) | 링마다 틱 피치 +1 반음, 최대 +7 |
| 칸 열림 | 먼지 4프레임 × 30 ms | |
| 숫자 등장 | 열림 시작 후 60 ms, 2 px 위에서 내려앉으며 90 ms. 좁은 빛 바깥 칸은 숫자 자리를 비움(1.2) | 숫자 등장 틱(작게) |
| 자갈 | 연쇄가 끝난 칸 중앙에 묶음 팝업 하나 "자갈 +7", 300 ms 후 주머니로 350 ms. 로그에는 "자갈 7개"를 함께 적는다 | 자갈 묶음 |
| 숫자 감소로 생긴 연쇄 | 0이 된 칸이 먼저 80 ms 반짝 후 같은 규칙 | |
| 입력 | 연쇄 중에도 이동·치기 가능 | |

1차의 '자원 아이콘 개당 25 ms 비행, 최대 20개'는 묶음 하나로 줄였다(감사 23번, F5).

### 6.5 보물 획득과 값 팝업

| 순서 | 시점(ms) | 화면 | 소리 |
|---|---|---|---|
| 1 | 0 | 깨짐 히트스톱 120 ms | 바위 깨짐 |
| 2 | 120 | 캔 칸에서 보물 그림이 칸보다 크게(칸의 1.75배) 160 ms 동안 솟아오르고, 보물 색 빛무리를 두른 채 650 ms 머문 뒤 200 ms에 사라진다. 무엇을 캤는지 한눈에 보이게 한다 | 보물 단계별 획득음(1단계·2단계·3단계 징글) |
| 3 | 120 | 팝업에 보물 그림(44 px), 보물 이름(청록 보석은 청록, 유물은 붉은 빛 글자), 시세가 붙은 값 "금 알갱이 30"(시세 ×1.5). 시세 ×1인 날은 "20". 큰 덩이와 발파로 얻은 값은 이름 없이 그대로 | |
| 4 | 240 | "×2"가 오른쪽에 붙음(콤보가 ×1이면 생략) | 배율 '칭' 1회, 콤보 단계마다 +2 반음 |
| 5 | 360 | "= 60" 붙음 | |
| 6 | 360 | 둘레 숫자 중 바뀐 것 80 ms × 2회 깜박 | 숫자 틱 |
| 7 | 900 | 팝업이 주머니로 350 ms 비행. 숫자 칸을 가리면 120 ms 안에 위로 비켜 뜬다 | |
| 8 | 1,250 | 주머니 숫자 300 ms 카운트업, 블록 테두리 1회 깜박, "다음 도장까지 n" 갱신 | 동전 짤랑 |
| 9 | 1,250 | 콤보 상승 연출(6.6) | 콤보 '칭' |

- 앞 숫자에 시세가 이미 들어가 있으므로 팝업에는 시세 배율을 따로 적지 않는다. 시세가 오른 다음 날 첫 보물 팝업만 앞 숫자 아래에 작게 "시세 ×1.5"를 600 ms 붙인다.
- 3단계(유물)는 2번에 흔들림 1 px 100 ms를 더한다.
- 체력 수정은 1차처럼 하트로 날아가 빈 하트를 채운다(300 ms). 가득이면 금 알갱이로 바뀌어 위 순서를 따른다.

### 6.6 콤보 상승·끊김

| 상황 | 화면 | 시간 | 소리 |
|---|---|---|---|
| 상승(×1 → ×1.5 → ... → ×2.5) | 콤보 칸 숫자 1 px 위로 튀었다 복귀, 새 단계 칸이 채워짐, 곡괭이 불꽃이 한 단계 커지며 1프레임 밝게 | 펀치 80 ms, 밝음 60 ms | '칭'. ×1.5 기준음, ×2 +3, ×2.5 +5 반음 |
| 상한 도달(×3) | 위와 같고 불꽃에 불티 4프레임 루프가 붙는다. 콤보 칸 테두리 #ffd25a 2회 깜박 | 펀치 80 ms, 깜박 100 ms × 2 | '칭' +7 반음 + 작은 종 |
| 끊김(지뢰를 밟음) | 폭발 연출이 끝난 뒤 200 ms 대기. 곡괭이 불꽃이 연기로 꺼짐 4프레임 × 60 ms. 콤보 칸 "×3 → ×1"이 회색으로 2회 깜박. 로그 "콤보가 끊겼어요 (×3 → ×1)" | 240 ms + 깜박 2 × 120 ms | '툭' 하강음 + 짧은 하강 3음 |
| 버팀(도구로 한 단계만 내려감) | 불꽃이 꺼지려다 한 단계 작은 크기로 남는다. 도구 아이콘이 튐(6.7) | 240 ms | '툭' 뒤에 '칭' 한 번(한 단계 아래 음) |
| 발파로 지뢰가 터짐 | 불꽃이 좌우로 1 px 흔들렸다 원래 크기로. 콤보 유지가 눈에 보이게 | 120 ms | 없음(발파 소리에 묻힘) |
| 하루 끝에 사라짐 | 하루 끝 연출 직전 불꽃이 조용히 작아져 꺼진다. 손실 표시 없음 | 300 ms | 없음 |

### 6.7 계산 연출(도구 연쇄 발동)

| 규칙 | 값 |
|---|---|
| 시작 | 원인 행동(발파, 보물, 연쇄)의 첫 결과가 보인 직후 |
| 한 단계 | 발동한 도구의 장착 칸 아이콘이 1 px 위로 튀며 테두리 #ffd25a(150 ms). 동시에 판 위 발동 칸에 같은 아이콘 16 px가 떠올랐다 사라짐(300 ms). 그 단계의 값 변화(주머니, 촛불, 줄)가 바로 반영 |
| 단계 간격 | 기본 150 ms. 원인 연출을 포함한 전체가 1,200 ms를 넘으면 간격을 줄임(최소 60 ms) |
| 단계가 많을 때 | 60 ms로도 넘치면 같은 도구의 연속 단계를 하나로 합쳐 합계만 보인다 |
| 값 표시 | 주머니 숫자는 단계마다 그 단계 값만큼 카운트업(단계 간격 안에서). 마지막 단계에서 합계 "+480"을 주머니 옆에 400 ms |
| 건너뛰기 | 아무 입력 → 남은 단계 즉시 반영, 합계 표시만 남김(6.0) |
| 소리 | 단계마다 틱, 피치 +1 반음씩 올린다. 마지막 단계 합계 짤랑 |
| 로그 | 연출이 끝난 뒤 한 줄로 요약 "정제기 4 · 장부 촛불 +3 · 달빛 체 2칸" |

### 6.8 발파와 불발

발파는 행동 버튼 [발파]를 눌러 고르기 상태로 들어간 뒤 X 칸을 클릭해서 한다(3.6.8). X 칸을 그냥 클릭하면 캐지지도, 불이 붙지도 않는다. 캐릭터는 고른 X 칸 옆으로 걸어가 불을 붙인다. 비용은 촛불 4(갱 상태 '마른 갱'인 날 3, 소모품 화약으로 붙이면 0). 결과는 칸 안에 무엇이 있었는지에 따라 네 갈래다(01 7.1).

| 순서 | 시점(ms) | 화면 | 소리 |
|---|---|---|---|
| 0 | 고르기 상태 | [발파] 버튼이 눌린 모양, 커서는 성냥, X 칸만 밝게 강조. 강조된 X 칸에 마우스를 올리면 칸 위에 "발파 −4" 미리보기. 촛불이 4보다 적으면 버튼이 회색이고 눌러도 고르기 상태에 들어가지 않는다 | 버튼 '딸깍' |
| 1 | 0 | X 칸 클릭(필요하면 먼저 그 옆으로 걸어감). 캐릭터 점화 2프레임 × 60 ms. X 칸에 불붙은 심지. 촛불 "-4". 고르기 상태가 끝나고 버튼이 올라온다 | 성냥 긋기 |
| 2 | 0~150 | 도화선 불꽃이 캐릭터에서 X 칸까지 이동. 붙어 있는 칸이라 기본 150 ms. 긴 도화선으로 두 걸음 안 X 칸에 함께 붙으면 1칸당 +20 ms, 최대 300 ms | 도화선 치직 |
| 3a(지뢰) | 150 | 히트스톱 80 ms, 판 영역 플래시 33 ms, 발파 폭발 6프레임 × 50 ms(둥근 흙먼지), 흔들림 4 px 250 ms | 발파 폭발(둔하고 낮은 '퍽') |
| 4a | 230 | 둘레 8칸 열림(와르르 규칙). 열린 칸에서 0이 생기면 이어서 퍼진다 | 연쇄 틱 |
| 5a | 230 + 120×n | 범위 안 지뢰가 차례로 터진다. 간격 120 ms(4개 이상이면 100 ms). 흔들림은 누적해도 6 px 상한 | 발파 폭발, 회마다 +1 반음 |
| 6a | 각 폭발 뒤 | 범위 안 보물은 그을린 그림으로 바뀌고 값 팝업 "30 ½ ×2 = 30"(시세 ×1.5 금 알갱이 예) | 보물 획득음을 한 옥타브 낮게 |

- 불발은 콤보를 끊지 않는다(보물이 녹아도 콤보는 그대로). 곡괭이 불꽃은 6.6 '발파로 지뢰가 터짐' 행처럼 흔들렸다 원래 크기로 돌아온다.
- 녹는 보물(3b)과 그을린 보물(6a)은 그림이 다르다. 녹은 자리에는 보물이 남지 않고, 그을린 보물은 그을음이 덮인 채 반값으로 남는다.
- 연쇄 폭발 전체는 1,500 ms 상한. 넘으면 간격을 60 ms까지 줄인다.
- 밟은 지뢰와 발파 지뢰를 소리와 모양으로 구분한다. 밟은 지뢰는 날카로운 폭발 + 귀 울림 + 붉은 피격, 발파는 낮은 '퍽' + 흙먼지. 발파 중에는 피격 연출이 없다.
- 불씨 중에는 발파 버튼이 회색이다. X 칸을 클릭하면 평소처럼 흔들리고 안내만 뜬다.
