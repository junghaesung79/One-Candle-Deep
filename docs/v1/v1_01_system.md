## 1. 핵심 루프

### 1.1 루프 구조

```
판 (광산 1개, Day 1~30)
 └ 하루 (초 1자루)
    ├ 아침: 체력·초 회복, 지형 새로 생성, 1층 시작 칸에 도착
    ├ 채굴 단계
    │   └ 층 (15×11 판 1장)
    │       ├ 행동: 이동 / 치기 / 표시 / 두드려 보기
    │       ├ 결과: 금 감 → 깨짐 → (안전: 숫자·자원, 연쇄 개방) (지뢰: 피해) (보물: 획득) (계단: 발견)
    │       └ 계단 선택 → 다음 층 (성격은 계단 종류가 결정)
    ├ 종료 사유: 초 소진(무사 귀환) / 조기 귀환(무사) / 쓰러짐(손실)
    └ 지상 단계: 정산 → 상점 → 다음 날
 └ Day 30 최종 정산: 보유 현금 ≥ 목표 금액이면 다음 등급 광산 해금
판 밖: 해금(도구 풀, 광산 등급, 시작 키트, 계단 종류)
```

### 1.2 돔 키퍼와의 대응

| 돔 키퍼 | 본 게임 | 차이 |
|---|---|---|
| 지하 채굴 | 층 채굴 | 숫자 추리가 채굴 경로를 정함 |
| 자원 운반·귀환 | 초 소진 시 자동 귀환 | 운반 과정 없음. 캔 즉시 가방에 들어감 |
| 웨이브 방어(시간 압박) | 초 길이 + 30일 목표 금액 | 전투 없음 |
| 돔·장비 강화 | 지상 상점에서 도구 구매 | 수치 강화보다 규칙 변경 도구 위주 |
| 유물 탐색 | 계단 탐색과 층 성격 선택 | 매 층 갈림길 |
| 판 종료 후 해금 | 30일 정산 후 해금 | 동일 구조 |

돔 키퍼의 "초반 채굴 느림"은 1층의 넓은 연쇄 개방(평균 98칸, 4.4 참조)으로 대응한다.

## 2. 조작 확정안 (PC)

키보드와 마우스를 동시에 받는다. 설정 전환 없음. 기본 배치 통합표와 게임패드 제안은 14장.

### 2.1 공통 규칙

| 항목 | 결정 | 근거 |
|---|---|---|
| 인접 판정 | 주변 8칸. 이동·치기·표시 모두 동일 | 숫자 힌트가 8칸 기준이다. 치기만 4방향이면 대각선의 확정 안전 칸을 못 쳐서 추리와 무관한 억지 채굴이 생김 |
| 이동과 치기 구분 | 방향 입력은 이동 또는 조준만 한다. 치기는 별도 입력 | 오입력 한 번이 지뢰로 이어지는 게임이라 "밀면 캐짐" 방식은 쓰지 않음 |
| 진행 방식 | 턴제. 플레이어가 행동할 때만 상태가 바뀜. 실시간 초 소모 없음 | 추리 시간 보장, 구현 단순 |
| 치기 반복 | 입력 1회 = 치기 1회. 길게 누르면 0.18초 간격 반복, 칸이 깨지면 반복 중단 | 바위당 2타의 손 피로 완화. 다음 칸으로 넘어가지 않음 |
| X 표시 칸 | 치기 잠금. 표시를 지워야 칠 수 있음 | 원작 깃발과 동일 |
| 계단 | 계단 칸에 올라서도 자동으로 내려가지 않음. 밟은 계단 1개에 대한 확인 창에서 확정(D23) | 되돌아올 수 없는 선택 |

### 2.2 키보드

| 입력 | 동작 |
|---|---|
| W A S D / 방향키 | 상하좌우. 대상 칸이 걸을 수 있으면 이동, 바위면 그 칸을 조준(제자리에서 방향만 전환) |
| Q E Z C / 넘패드 7 9 1 3 | 대각선. 규칙은 위와 동일 |
| Space | 조준한 칸 치기 |
| F | 조준한 칸에 분필 표시 순환: 없음 → X → O → 없음 |
| 1 ~ 4 | 능동 도구 슬롯. 1번은 기본 "두드려 보기" |
| Enter | 계단 위에서 내려가기 확인 |
| R 길게(0.8초) | 조기 귀환 |
| Tab | 가방·보유 도구 보기 |
| Esc | 일시정지 메뉴 |

### 2.3 마우스

| 입력 | 동작 |
|---|---|
| 좌클릭: 인접 바위 | 치기 1회 |
| 좌클릭: 파낸 땅·계단 | 그 칸으로 이동(8방향 최단 경로, BFS) |
| 좌클릭: 떨어진 바위 | 그 바위에 인접한 가장 가까운 열린 칸까지 이동만 함. 치지 않음 |
| 우클릭: 보이는 바위 | 분필 표시 순환. 거리 제한 없음 |
| 마우스 올림 | 칸 강조. 인접 바위는 테두리로 "칠 수 있음" 표시 |
| HUD 버튼 | 능동 도구, 조기 귀환, 계단 확인 |

도구 칸은 패시브 5칸 + 능동 4칸이다(D20). 능동 1번은 두드려 보기 고정, 2~4번은 능동 도구와 소모품이 함께 쓴다.

## 3. 판(그리드) 규칙

### 3.1 크기와 시작

| 항목 | 값 |
|---|---|
| 층당 그리드 | 15열 × 11행 = 165칸. 화면 고정, 스크롤 없음. 모든 광산 등급에서 동일 |
| 판 바깥 | 칸이 없는 것으로 취급(숫자 계산에 0으로 반영) |
| 1층 시작 위치 | 판 중앙 (8열, 6행) |
| 2층 이후 시작 위치 | 직전 층에서 탄 계단과 같은 좌표 |
| 시작 안전 구역 | 시작 칸 + 주변 8칸(3×3)에는 지뢰·보물 없음 |
| 첫 타 안전 | 도착 즉시 시작 칸이 열린 상태로 시작하고 연쇄 개방이 발동. 치기 소모 없음 |

### 3.3 상태 전이

| 현재 | 사건 | 다음 | 부가 처리 |
|---|---|---|---|
| 바위 | 치기 | 금 간 바위 | 초 1 소모. 정보 변화 없음 |
| 금 간 바위 | 치기 | 내용물 판정 | 초 1 소모 |
| (판정) 안전 | - | 파낸 땅 | 자원 있으면 획득. 숫자 계산 후 0이면 연쇄 |
| (판정) 지뢰류 | - | 그을음 땅 | 피해 적용. 주변 숫자 1 감소 |
| (판정) 보물 | - | 파낸 땅 | 가방에 획득. 주변 숫자 1 감소 |
| (판정) 계단 | - | 계단 칸 | 종류 공개 |
| 바위·금 간 바위·굳은 바위 | 연쇄 개방 | 파낸 땅 | 초 소모 없음. 분필 표시는 자동 제거. 계단 칸은 연쇄로 열리지 않음(D18) |
| 열린 칸(숫자 n) | 인접 위험 칸 제거 | 숫자 n-1 | 0이 되면 그 칸에서 연쇄 개방 발동 |

### 3.4 숫자 힌트

| 규칙 | 결정 |
|---|---|
| 정의 | 주변 8칸 중 아직 깨지지 않은 지뢰류 + 보물류의 개수 |
| 터진 지뢰 | 계산에서 빠진다. 주변 열린 칸의 숫자가 즉시 1 줄어듦 |
| 획득한 보물 | 계산에서 빠진다. 위와 동일 |
| 계단·자원·암반 | 처음부터 세지 않음 |
| 숫자 상한 | 5. 생성 단계에서 6 이상이 나오는 배치는 거부(팔레트의 숫자 색 5종과 일치) |
| 계단 인접 표시 | 아직 못 찾은 계단과 인접한 열린 칸은 숫자 아래 밑줄 + 칸 왼쪽 아래 작은 계단 무늬(D24, 03 8장). 숫자가 0인 칸은 무늬만 표시. 계단 종류는 알려주지 않음 |

"남은 것만 센다"로 정한 이유(D2): 보물을 캐거나 지뢰를 밟을 때마다 주변 숫자가 줄어 추가 정보가 생기고, 0이 되면 연쇄가 터진다. 플레이어가 터진 칸을 직접 빼서 계산할 필요가 없다. 구현은 변경된 칸의 주변 8칸만 재계산하면 된다 [하].

### 3.5 연쇄 개방

| 규칙 | 결정 |
|---|---|
| 발동 조건 | 열린 칸의 숫자가 0일 때(처음 열릴 때, 또는 줄어서 0이 될 때) |
| 범위·대상 | 주변 8칸의 바위·금 간 바위·굳은 바위. 새로 열린 칸이 0이면 반복(BFS). 암반과 계단 칸 제외 — 계단은 항상 직접 깨야 드러난다(팀장 결정 D18) |
| 비용·자원 | 초 소모 없음. 열린 칸의 저가치 자원은 전부 자동 획득 |
| 분필 표시 | 무시하고 연다(안전이 확정된 칸이므로) |
| 시야·연출 | 시야 밖에서도 논리적으로 열림(숫자만 안 보임). 연출 수치는 03 6.2를 따름 |
| 계단과의 관계 | 숫자 0인 칸 옆에 덮인 채 남은 바위는 계단이다. 플레이어가 알아챌 수 있는 단서로 두며, 드러내려면 2타가 든다 |

### 3.6 분필 표시

X(지뢰 의심)는 치기를 잠근다. O(보물 의심)는 메모용이며 효과가 없다. 둘 다 초 소모가 없고 시야 밖에서도 보인다.

- 13층 이상: 12층 값을 유지하고 큰 지뢰 비율만 층당 +5%p(최대 80%).
- 큰 지뢰 비율에 더해지는 모든 변형(붉은 계단, 등급 4, 도구)은 7층 이상에서만 적용한다(D27).
- 하트 수정: 3층 이상에서 층마다 30% 확률로 보물 1개를 하트 수정으로 바꿈.
- 층당 지뢰+보물 합 상한은 40(24.2%). 층 성격 배수로 넘으면 지뢰부터 줄임.
- 참고: 원작 지뢰찾기 초급 12.3%, 중급 15.6%, 고급 20.6%.

### 4.2 보물 배치 편향

| 규칙 | 값 |
|---|---|
| 지뢰 인접 배치 | 보물의 60%는 지뢰와 인접한 칸에 둠 |
| T3 | 인접 지뢰 2개 이상인 칸에만 둠 |

### 4.3 계단

### 4.4 생성 순서

1. 시드 = hash(판 시드, 스트림 ID, Day, 층 순번, 탄 계단 종류 ID). 단순 합산은 쓰지 않는다(Day 1의 2층과 Day 2의 1층이 겹침). 규약은 4.7. 층은 내려가는 시점에 생성.
2. 시작 3×3 안전 구역 예약.
3. 계단 배치(4.3).
4. 암반·굳은 바위 배치(등급 2 이상).
5. 지뢰·보물 배치(4.1 × 층 성격 배수, 4.2 편향).
6. 제약 검사. 실패하면 5번부터 재시도(최대 30회). 30회를 넘기면 4.6의 폴백 순서를 따른다.
   - 숫자 6 이상 없음
   - 계단 접근성 충족
   - 시작 연쇄 개방 12칸 이상
   - 보장 계단까지 안전 칸으로 이어진 길 존재
   - 풀이기 검증(4.5의 3번, 도입 시)
7. 저가치 자원, 보물 등급, 큰 지뢰 여부 굴림.

간이 시뮬 결과(풀이기 검증 제외): 평균 재시도 횟수는 1층 1.05회, 6층 1.2회, 12층 1.8회. 시작 연쇄 평균은 1층 98칸, 6층 40칸, 12층 25칸.
프로토타입 측정(풀이기 제외, 조건당 2,000회): 시도 횟수 평균 1.2~2.7회, 최대 26회(붉은 계단 9층). 30회를 넘긴 경우는 16,000회 중 0건.

### 4.5 찍기 상황을 줄이는 장치

단순 추리(숫자 = 남은 칸 수, 숫자 소진, 포함 관계 비교)만으로 보장 계단까지 도달하는 비율은 1층 98%, 6층 83%, 9층 60%, 12층 39%로 측정됐다(간이 시뮬). 깊은 층에서는 보정이 필요하다. D18 이후에도 추리로 닿을 수 있는지 여부는 같고, 계단 칸을 깨는 2타가 더 든다.

| 번호 | 장치 | 내용 | 구현 난이도 | 도입 |
|---|---|---|---|---|
| 1 | 첫 타 안전 + 시작 연쇄 보장 | 3×3 안전 구역, 시작 연쇄 12칸 미만이면 재생성 | 하 | 프로토타입 |
| 2 | 피해 완충 + 조기 귀환 | 지뢰는 체력만 깎음. 언제든 무사 귀환 가능 → 찍기가 강제되지 않음 | 하 | 프로토타입 |
| 3 | 풀이기 검증 | 지뢰와 보물을 구분하지 않는 풀이기로 "찍지 않고 보장 계단까지 열 수 있는지" 확인, 불가면 재생성. 평균 재시도 6층 1.4회, 9층 2.4회, 12층 4.9회. 165칸이라 연산 부담 없음. 풀이기 본체는 50줄 내외 | 중 | 프로토타입 직후 |
| 4 | 두드려 보기(기본 능동) | 인접 바위 1칸이 지뢰인지 아닌지만 알려줌. 하루 2회, 사용 시 초 2눈금. 결과는 칸에 자동 표시 | 하 | 프로토타입 |
| 5 | 숫자 감소 연쇄 | 위험 칸을 하나 제거하면 주변 숫자가 줄어 막힌 추리가 다시 풀림(3.4) | 하 | 프로토타입 |
| 6 | 숫자 상한 5 | 숫자 6 이상 배치 거부. 읽기 어려운 밀집 구역 제거 | 하 | 프로토타입 |

장치 3은 "어느 칸이 위험한지"까지만 보장한다. 위험 칸이 지뢰인지 보물인지는 의도적으로 남겨 둔다. 그 구분이 이 게임의 도박 요소이며 장치 4와 도구가 맡는다.

### 4.6 생성 실패 폴백과 시간 예산 (검수 N2)

단계 전환은 시도 횟수로만 판정한다. 경과 시간으로 끊으면 기기마다 결과가 달라져 같은 시드의 재현이 깨진다.

| 단계 | 조건 | 처리 | 시도 상한 |
|---|---|---|---|
| 0 | 기본 | 지뢰·보물만 재배치(4.4의 5번부터) | 30회 |
| 1 | 0단계 실패 | 계단부터 재배치(3번부터). 계단 배치 1벌당 지뢰·보물 재배치 30회 | 계단 3벌 × 30회 |
| 2 | 1단계 실패 | 밀도 하향: 지뢰·보물 수만 4.1 표의 한 층 위 행 값으로(등급·가치·큰 지뢰 비율은 원래 층). 계단부터 재배치 | 30회 |
| 3 | 2단계 실패 | 풀이기 검증 생략. 나머지 제약은 유지. 밀도는 2단계 값 | 30회 |
| 4 | 3단계 실패 | 무작위 배치 1회 후 위반을 직접 고침: 계단 인접 위험 칸을 지워 접근성을 맞추고, 숫자 6 이상인 칸의 인접 지뢰를 하나씩 지움. 시작 연쇄·경로 조건은 보지 않음 | 1회(반드시 종료) |

- 1단계 이상에 들어간 층은 로그에 남긴다(판 시드, Day, 층 순번, 도달 단계). 출시 전 10만 층 일괄 생성으로 단계별 빈도를 잰다.
- 폴백으로 밀도가 내려간 층도 보물 등급과 자원 가치는 원래 깊이 값을 쓴다.

| 시간 예산 | 값 | 비고 |
|---|---|---|
| 층 1개 생성 목표 | 평균 20ms 이하, 최악 150ms 이하 | 계단 전환 연출(페이드) 안에서 한 프레임 멈춤으로 처리 |
| 프로토타입 실측(JS, 풀이기 제외) | 평균 0.4~1.1ms, 최대 13ms | GDScript는 이보다 수십 배 느릴 수 있어 실측 전에는 미확인 |
| 초과 시 조치 | 칸 배열을 PackedByteArray로, 풀이기 제약 목록을 경계 칸으로 한정 | 그래도 넘으면 생성만 스레드로 분리 [중] |

이동이 무료라 숫자는 다가가면 다시 볼 수 있다. 시야 축소의 실제 비용은 여러 숫자를 한 화면에서 비교하지 못하는 것이다. 초가 줄기 전에 분필로 적어 두는 플레이를 유도한다.

### 5.4 초 소진

| 상황 | 처리 |
|---|---|
| 마지막 눈금을 쓴 행동 | 결과를 끝까지 처리(연쇄, 보물 획득, 폭발 포함) |
| 처리 후 체력 1 이상 | 무사 귀환. 가방 전부 보존 |
| 처리 후 체력 0 | 쓰러짐이 우선 |
| 조기 귀환 | 가방 전부 보존. 남은 초는 소멸 |

남은 초가 1일 때 새 바위를 치면 금만 가고 끝나므로 HUD에서 미리 경고한다.

### 5.5 비용이 남은 초보다 클 때 (검수 21)

기준: 플레이어가 고른 행동은 초가 모자라면 실행하지 않는다. 강제로 깎이는 초는 남은 만큼만 깎고 0으로 처리한다.

| 행동·효과 | 비용 | 실행 조건 | 모자랄 때 |
|---|---|---|---|
| 치기 | 1 | 남은 초 1 이상 | 해당 없음(0이면 이미 하루 종료) |
| 두드려 보기 | 2 | 남은 초가 비용보다 많음 | 불가. 버튼 비활성, 횟수 차감 없음 |
| 계단 통행(일반·금테·붉은 10, 등불·샘 20, 도구 가산 포함) | 10~ | 남은 초가 비용보다 많음 | 불가. 확인 창에 "초 부족"과 필요 눈금 표시 |
| 초를 쓰는 능동 도구·소모품(예: 05 I23 15) | 도구별 | 남은 초가 비용보다 많음 | 불가. 사용 횟수·개수 차감 없음 |
| 피해를 초로 대신 내는 패시브(예: 05 I12 15·25) | 도구별 | 남은 초가 비용보다 많음 | 발동하지 않음. 원래 피해를 그대로 받음 |
| 강제 소실(가스 주머니 12, 폭발 시 초 감소 변형) | 효과별 | 항상 적용 | 남은 만큼만 깎고 0. 초 소진 처리로 넘어감 |
| 초 획득(샘 +15, 소모품, 상인 방 서비스) | - | 남은 초 1 이상 | 0에서는 쓸 수 없음. 하루 합계 상한 220을 넘는 분은 버려짐 |

"비용보다 많음"은 쓰고 나서 1눈금 이상 남는다는 뜻이다. 치기만 마지막 눈금을 쓸 수 있다.

한 행동 안의 처리 순서: 행동 결과(깨짐, 연쇄, 획득) → 강제 소실 → 체력 판정(0이면 쓰러짐) → 초 판정(0이면 on_candle_out, 되살아나지 않으면 무사 귀환).

초 0 상태와 특수 방:

| 상황 | 처리 |
|---|---|
| 초 0으로 상인 방·샘에 들어가는 경우 | 생기지 않는다. 통행 후 1눈금 이상 남아야 내려갈 수 있다 |
| 방 안 | 초가 줄지 않는다. 방 안에서 초 소진으로 하루가 끝나는 경우는 없다 |
| 샘에서 초 +15, 상인 방에서 초를 늘리는 구매 | 즉시 적용. 나간 뒤 다음 층에서 채굴을 계속한다 |
| 방에서 조기 귀환 | 가능. 채굴 중 조기 귀환과 같은 처리 |

| 항목 | 값 |
|---|---|

## 8. 판 밖 진행

### 8.1 해금 구조

메타 화폐와 영구 강화 상점은 두지 않는다. 조건을 달성하면 열리는 업적형으로 한다.

| 범주 | 내용 | 조건 예시 |
|---|---|---|
| 도구 풀 | 상점 진열 후보에 새 도구 추가 | "하루에 연쇄 개방 60칸 이상" |
| 광산 등급 | 다음 등급 매입 가능 | 직전 등급 목표 달성 |
| 시작 키트 | 판 시작 조건 변형(장단점이 함께 있는 형태). 예: 탐침 +1회, 최대 체력 -1 | "한 판에서 두드려 보기 40회 사용" |
| 계단 종류 | 새 층 성격 추가. 예: 수직갱(깊이 +2) | "하루에 7층 도달" |
| 변형 규칙 | 일일 시드 도전, 특수 광산 | 등급 3 달성 |
| 기록·꾸밈 | 도감, 통계, 헬멧 색 | 각종 누적 |

원칙: 해금은 선택지를 늘린다. 시작 체력이나 초 길이 같은 기본 수치를 영구적으로 올리는 해금은 만들지 않는다.

### 8.2 광산 등급 사다리

변형은 누적된다(등급 3은 등급 2의 변형을 포함). 등급 이름은 중개소 매물명(02 5.2, 팀장 결정 D12).
