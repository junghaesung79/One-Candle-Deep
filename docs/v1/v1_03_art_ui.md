|---|---|
| 타일 원본 | 16×16 px |
| 표시 배율 | 3배(48 px). 정수 배율만 사용, 보간은 최근접(nearest) |

| 분위기 | 어두운 동굴. 배경 #14121a, 빛은 헤드램프·초 한 곳에서만 나옴 |
| 어둠 | 캐릭터 기준 거리별 단계 어둠(원형). 부드러운 그라데이션 대신 계단식 단계 |
| 폰트 | 숫자·영문 Press Start 2P. 한글 픽셀 폰트(갈무리 계열) 1종 |

### 1.2 거리별 어둠 단계

어둠 레이어는 #0b0a10 단색을 칸 위에 덮고 불투명도만 바꾼다(불투명도는 시안 A 실측값, D5). 시야 반경 R은 01 5.2 값(5.0 / 3.5 / 2.5 / 1.5)을 따른다.

| 단계 | 칸 중심까지 거리 d | 불투명도 | 숫자·계단 인접 표시 | 지형·분필·두드려 보기 결과 |
|---|---|---|---|---|
| 0 | d ≤ R | 0 | 표시 | 표시 |
| 1 | R < d ≤ R+1 | 0.30 | 숨김 | 표시 |
| 2 | R+1 < d ≤ R+2 | 0.55 | 숨김 | 표시 |
| 3 | R+2 < d ≤ R+3 | 0.78 | 숨김 | 표시 |
| 4 | 그 바깥 | 0.90 | 숨김 | 표시 |

- 숫자는 단계 0에서만 보인다(D22). 단계 1 이상은 지형 윤곽만 보인다.
- 거리는 원형(유클리드)으로 판정해 시안 A의 둥근 빛 모양을 유지한다.
- R이 바뀌면 어둠 경계가 200 ms 페이드로 한 번에 옮겨 간다.

### 1.3 하지 말 것

| 금지 | 이유 |
|---|---|
| 정수가 아닌 배율(1.5배 등), 회전·자유 크기 조절 | 픽셀이 뭉개짐 |
| 안티앨리어싱 외곽선, 블러, 부드러운 그라데이션 광원 | 시안 A의 단계 어둠과 충돌 |
| 16×16 격자와 어긋난 오브젝트 배치(이펙트 제외) | 판 읽기가 흐려짐 |
| 숫자 칸 위에 이펙트·아이콘 장시간 겹치기 | 핵심 정보 가림. 이펙트는 300 ms 안에 숫자에서 비켜남 |
| 숫자 색을 다른 용도(아이템 등급, 버튼)에 재사용 | 숫자 1~5 색의 의미가 흐려짐 |
| 숫자 색을 바꿔 정보 전달(렌즈, 계단 인접) | 색만으로 구분하는 표시는 금지. 테두리·밑줄·무늬로 표시(D14, D24) |
| 같은 화면에서 한글 폰트 2종 이상 | 시안 A의 Noto Sans KR은 시안용 |
| 순수 검정 #000000, 순수 흰색 #ffffff | 팔레트 밖. 각각 #0b0a10, #f1ece2 사용 |
| 화면 전체 플래시를 100 ms 넘게 | 광과민 위험 |

### 3.4 광산 선택(등급)

판 밖 화폐와 매입가는 없다(D8). 카드에는 목표 금액과 등급 규칙만 표시한다.

```

| |[일러]   | |[일러]   | | (잠김)  | | (잠김)  | | (잠김)  | | (잠김)  | |  ???   |   |
| |달못 1호 | |달못 4호 | |달못 9호 | |달못 13호| |달못 21호| |달못 특호| |        |   |

```
- 카드 7장, 장당 160 px 폭, 간격 12 px. 일러 64×48 원본을 2배(128×96)로 표시.
- 목표: 11,500 / 18,400 / 27,600 / 40,300 / 57,500 / 80,500 / 115,000(05 1.5 v0.2). 등급 7(달못 0호 갱)은 예비라 해금 전에는 "???"로만 표시.
- 잠긴 카드도 이름과 목표는 보여 준다. 일러는 실루엣.
- 위험도는 칸 채움 막대(■□)라 색에 의존하지 않음. 클리어는 글자로 표시.

| 결과 | 하트 1 깨짐 | 하트 2 차례로 깨짐 | 초 12 줄어드는 HUD 카운트다운 400 ms | 주변 바위 깨짐 처리 |

- 피격 후 캐릭터 피격 2프레임 × 80 ms + 깜빡 600 ms. 폭발이 끝나면 그을음 타일로 교체, 주변 숫자는 1씩 줄어드는 카운트(칸마다 60 ms).

### 6.5 기타

| 상황 | 값 |
|---|---|
| 분필 긋기(X, O) | 3프레임 × 40 ms |
| 두드려 보기 | 울림 3프레임 × 60 ms 후 결과 표시 |
| 계단 발견 | 빛 4프레임 × 70 ms, 로그 [계단] 8초 유지 |
| 계단 통행 | 확인 후 페이드 아웃 250 ms → 새 층 시작 연쇄 |
| 초 꺼짐 | 불꽃 축소 600 ms → 연기 5프레임 × 100 ms → 어둠이 캐릭터 쪽으로 링 단위로 덮임 800 ms → 정산 페이드 400 ms |
| 쓰러짐 | 쓰러짐 4프레임 × 120 ms → 정지 500 ms → 어둠 페이드 600 ms |
| 화면 전환 | 기본 페이드 250 ms. Day 시작 화면만 600 ms |
| 권리증 뒤집기 | 가로 축소 150 ms → 뒷면 확대 150 ms |
