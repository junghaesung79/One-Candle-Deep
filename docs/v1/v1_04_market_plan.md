시사점
- 지뢰찾기 + 채굴 + 로그라이트 빌드를 한 작품에 넣은 상업작은 이번 조사에서 확인하지 못함. 스팀 전수 조사가 아니므로 유일성은 주장하지 않는다.
- 지뢰찾기 파생작은 무료 웹게임이 많다(드래곤스위퍼, 마모노 스위퍼). 유료 판매 근거는 빌드·해금·판 반복 쪽에 둔다.

## 2. 포지셔닝

### 2-1. 셀링 포인트(한 문장)
숫자 하나에 지뢰와 보물이 함께 숨은 마법 광산을 30일 동안 파 내려가며, 도구 조합으로 위험을 돈으로 바꾸는 지뢰찾기 채굴 로그라이트.

영문 초안(One Candle Deep): A minesweeper mining roguelite where every number hides both mines and treasure. Build tool combos and dig deeper for 30 days to afford a bigger mine.

### 2-2. 스팀 태그 후보 10개

| 순위 | 태그(영문) | 선정 이유 |
|---|---|---|
| 1 | Roguelite | 판 초기화 + 해금 구조 |
| 2 | Puzzle | 숫자 추리가 핵심 |
| 3 | Mining | 채굴 반복 루프 |
| 4 | Logic | 지뢰찾기식 추론 |
| 5 | Pixel Graphics | 16×16 픽셀 아트 |
| 6 | Top-Down | 시점 |
| 7 | Procedural Generation | 매일 바뀌는 지형 |
| 8 | Turn-Based | 턴제(D3) |
| 9 | Resource Management | 초(빛)·체력·현금 관리 |
| 10 | Replay Value | 등급 사다리 반복 |

- "Minesweeper"는 스팀 공식 태그 존재 여부 미확인. 없으면 짧은 설명문 첫 줄에 넣어 검색 노출 확보.
- 태그 이름의 실제 존재 여부는 스팀웍스 태그 목록에서 등록 시 확인(미확인).
