# 02. 세계관·내러티브 설계서 (2차)

| 항목 | 내용 |
|---|---|
| 작성 | 내러티브 파트 |
| 기준 문서 | 2차 브리프, 2차 팀장 결정(추가분 포함, 이 문서보다 우선), 재미 재설계안(11장), 코어 시스템 설계서 v0.3, 아이템·경제 설계서 v0.3 |
| 가제 | 「초 한 자루」 / One Candle Deep |

## 1. 가제

이 장에서 정하는 것: 게임 제목(가제)과 스토어에 적을 이름, 피할 단어.

「초 한 자루」 / One Candle Deep을 유지한다. 하루가 촛불 하나로 끝난다는 규칙은 2차에서도 같다.

| 항목 | 내용 |
|---|---|
| 스토어 표기 | "One Candle Deep: A Minesweeper Mining Roguelite". 제목에 장르어가 없어 부제와 태그로 검색을 받는다 |
| 피할 단어 | Keeper(Dome Keeper, Core Keeper), Sweeper 단독, Dig(SteamWorld Dig) |
| 폐기한 후보 | "서른 밤 광산 / Thirty Nights Below". 한 판이 15일이 되어 맞지 않는다 |
| 검증 상태 | 스팀 스토어 직접 검색과 상표 조회는 아직 하지 않았다. 스팀 페이지 공개 전에 필요하다 |
| 영문 소개 문장 | 1차의 "dig deeper for 30 days to afford a bigger mine"은 쓸 수 없다. 2차 초안: "Pay for your magic mine in three payments before the moon goes dark." 시장 파트 문서에 반영이 필요하다 |

## 2. 톤

이 장에서 정하는 것: 글 전체의 말맛(씁쓸하지만 웃긴 7, 아기자기 3)과 문체 규칙.

씁쓸하지만 웃긴 7 : 아기자기 3. 1차와 같다.

| 근거 | 내용 |
|---|---|
| 규칙과 맞음 | 납부일에 돈이 모자라면 계약이 해지되고 낸 돈은 돌려받지 못한다. 귀여운 말투로 덮으면 규칙과 따로 논다 |
| 전달 수단 | 컷신 없이 한두 줄 텍스트만 쓴다. 건조한 농담은 한 줄에 들어간다 |
| 아기자기 3의 역할 | 아무도 죽지 않는다. 인물들은 얄밉지만 악의가 없다. 플레이어를 놀리지 않는다 |

말투 규칙(2차 결정)

| 글의 종류 | 말투 | 예 |
|---|---|---|
| 게임 안 설명 문구 전부: 표지판, 벽 낙서, 강조 말풍선, 기록 창, 게시판(갱 상태·주문·변덕 공지), 발파·불발·불씨 안내, 확인 창, 도구·상점 설명, 도움말(용어 설명) | 해요체 | "규칙이 없어요. 숫자만 보면 돼요" |
| 인물이 직접 말하는 대사 | 인물 말투 그대로. 구 실장은 합니다체, 곽 씨는 하게체, 심지는 반말 | "도장 하나 찍습니다." |
| 벽 낙서 | 곽 씨가 뒤에 올 사람에게 남긴 존댓말 메모. 곽 씨가 입으로 말할 때만 하게체다 | "저도 여기서 한 번 데었어요." |
| 숫자·식만 있는 표기 | 그대로 둔다 | "자갈 +24", "불발 · 촛불 -4" |

설명 문구는 '~음', '~함', '~다'로 끝내지 않는다. 광산의 반응도 기록 창에 뜨므로 해요체로 쓴다.

문체 규칙: 한 문구 2문장 이내. 느낌표 금지. 교훈·격려 금지. 말장난 금지(번역이 안 된다). 숫자는 실제 값을 그대로 말한다. 화면에 뜨는 글에서는 "초" 대신 "촛불"로 쓴다.

## 3. 설정

이 장에서 정하는 것: 마법 광산이 무엇이고 왜 보름 동안 세 번 돈을 내는지. 설정 하나하나가 어느 규칙과 이어지는지.

플레이어에게 처음 알려 주는 것은 권리증 한 장이다. "마법 광산을 계약했다. 도장 자리가 셋 비어 있다." 나머지는 낙서와 대사로 조금씩 드러난다.

| 항목 | 설정 | 연결되는 규칙 |
|---|---|---|
| 마법 광산 | 땅속에 누워 자는 아주 큰 무언가의 몸. 달못 중개소는 이것을 부위별로 쪼개 "광산"으로 판다. 사는 사람은 모르고 산다 | 광산 등급 |
| 보름에 열리고 그믐에 닫힘 | 그것은 보름달에 한 번 크게 돌아눕는다. 그때 벌어진 틈이 달이 기우는 동안 좁아지다가 그믐에 닫힌다 | 한 판 15일 |
| 분납 계약 | 중개소는 갱이 열려 있는 보름 동안 캐서 값을 치르는 조건으로 판다. 계약금, 중도금, 잔금. 이자도 대출도 없다. 낼 때마다 구 실장이 권리증에 도장을 찍는다 | Day 3·8·15 납부 |
| 시세 | 그믐이 가까울수록 굳은 달빛이 단단해져 중개소가 값을 더 쳐 준다. 중개소는 도장 찍은 손님 물건만 그 값에 받는다 | 도장 0개 ×1, 1개 ×1.5, 2개 ×3 |
| 계약 해지 | 납부일 밤에 금고가 모자라면 중개소가 갱구를 잠근다. 낸 돈은 돌려주지 않는다. 같은 갱이 다음 보름에 같은 값으로 다시 나온다 | 납부 실패 시 판 종료 |
| 밤마다 바뀌는 지형 | 매일 밤 조금씩 뒤척인다 | 층 자동 생성 |
| 보물 | 그것이 자면서 삼킨 달빛이 다 삭아서 굳은 것 | 금 알갱이, 청록 보석, 유물 |
| 지뢰 | 덜 삭은 달빛. 광부들은 "설익이"라 부른다. 치면 터진다. 죽지는 않고 크게 덴다. 불을 붙여도 터진다 | 지뢰는 체력만 깎음, 발파 |
| 숫자 | 벽에 밴 달빛 냄새의 세기. 굳은 것과 설익은 것은 냄새가 같다 | 숫자 = 지뢰 + 보물 |
| 광맥 | 달빛이 삭는 방식은 자리마다 버릇이 있다. 중개소 측량 기사가 층 입구에 표지판으로 적어 둔다 | 층마다 광맥 규칙 1개 |
| 노다지 줄 | 굳은 달빛을 연달아 캐면 곡괭이 날에 달빛이 묻어 다음 것이 더 곱게 떨어진다. 설익이가 터지면 다 날아간다 | 연속 보물 배율 |
| 촛불 | 광산은 불 켜진 촛불을 든 사람만 손님으로 참아 준다. 바위를 칠 때마다 광산이 한숨을 쉬어서 촛불이 탄다 | 치면 촛불 1 |
| 불씨 | 촛불이 꺼져도 심지에 불씨가 남아 있는 동안은 광산이 잠깐 봐준다. 냄새(숫자)는 맡을 수 없다 | 불씨 다섯 번 |
| 큰 덩이 | 삼킨 달빛이 쪼개지지 않고 한데 뭉쳐 굳은 것. 그것의 살에 박혀 있다. 중개소는 덩이가 얕게 올라오는 날을 납부일로 잡았다. 구 실장은 우연이라고 한다 | 납부일의 큰 덩이 |
| 광산 깨어남 | 덩이를 건드리면 그것의 잠이 얕아진다. 한숨이 거칠어져 촛불이 두 배로 탄다 | 그 층에서 치기 한 번에 촛불 2 |
| 광산 변덕 | 덩이를 한 번 건드린 뒤로는 잠버릇이 는다. 중도금 날에 하나, 잔금 날에 둘 | 광산 변덕 4종 |
| 쓰러졌을 때 | 옆 광산 주인 곽 씨가 끌어낸다. 수고비로 그날 주머니의 절반을 가져간다. 금고는 건드리지 않는다 | 쓰러지면 주머니 절반 손실 |
| 판이 끝날 때 도구 | 갱이 닫히면 안에 둔 것은 못 꺼낸다 | 판마다 도구 초기화 |

설명하지 않는 것: 샘과 상인 방이 왜 땅속에 있는지, 도구가 왜 그런 효과를 내는지, 금이 왜 달빛에서 생기는지. 물으면 인물들이 "원래 그렇다"고 답한다.

삭제한 1차 설정: 30일 주기, "광산을 이미 제값에 샀고 목표 금액은 다음 매물 값", 보물 전부와 자원 절반을 가져가는 곽 씨, 계단 종류(금테·붉은·등불·샘 계단)와 숨은 계단 여러 개, 조기 매입, 높은 등급의 3회 쓰러짐 폐쇄, 시야가 네 단계로 줄어드는 지문.

## 4. 등장인물

이 장에서 정하는 것: 화면에 나오는 인물이 누구이고 각자 어느 화면에서 어떤 말투로 말하는지.

대사가 있는 인물은 셋, 대사 없이 반응만 하는 광산까지 넷.

| 이름 | 정체 | 게임에서 하는 일 | 말투 |
|---|---|---|---|
| 구 실장 | 달못 중개소 실장. 광산을 판 사람 | 아침 게시판(갱 상태, 다음 납부까지 남은 금액), 납부일 밤 수금과 도장, 다음 납부일의 광산 변덕 예고, 계약 해지 통보, 잔금 뒤 권리증 | 공문체 존댓말. 불리한 내용은 짧게 덧붙인다 |
| 심지 | 촛불과 도구를 파는 상인 | 하루 끝 상점, 갈림길에 가끔 나오는 상인 방, 게시판에 주문서를 붙이는 사람 | 반말. 물건의 단점도 말한다 |
| 곽 씨 | 옆 광산 주인. 몇 년째 못 팔고 있다 | 쓰러진 플레이어를 끌어내고 주머니 절반을 받는다. 광산 벽의 낙서는 그가 뒤에 올 사람에게 남긴 메모다 | 말할 때는 하게체, 느리고 짧다. 낙서는 존댓말 메모다 |

## 5. 이야기가 나오는 곳

이 장에서 정하는 것: 글이 화면의 어디에 얼마나 나오는지, 광산 등급이 오를 때 무엇이 드러나는지.

### 5.1 텍스트 위치

| 위치 | 언제 | 화자 | 길이 | 용도 |
|---|---|---|---|---|
| 오프닝 만화 | 새 판 첫 시작(첫 판만 자동, 건너뛸 수 있다) | 자막, 구 실장 | 3컷, 컷마다 2줄 이내 | 광산을 사게 된 사정. 규칙은 가르치지 않는다(6.12) |
| 권리증(시작) | 만화 다음 | 문서 | 4줄 | 도장 칸 셋: "첫 도장 300 · 3일째", "두 번째 도장 2,400 · 8일째", "마지막 도장 11,000 · 15일째". 아래 줄: "낼 때마다 도장을 하나 찍어요. 도장이 찍히면 캔 값이 올라가요" |
| 중개소 선물 | 권리증 다음 | 구 실장 | 3~4줄 | 도구 셋 중 하나를 그냥 받는다(6.11) |
| 게시판 | 매일 아침(첫 판은 Day 2부터) | 구 실장, 심지 | 갱 상태 1줄, 주문 2장, 시세 1줄, 납부 안내 1줄 | 오늘 달라지는 규칙과 할 일 |
| 표지판 | 층에 들어설 때, 갈림길 | 중개소 측량 표지 | 1줄 | 그 층의 광맥 규칙 |
| 벽 낙서 | 층마다 0~1개. 첫 판 Day 1~3은 정해진 자리 | 곽 씨(존댓말 메모) | 1~2문장 | 요령, 설정 조각, 농담 |
| 광산 지문 | 촛불 15 이하, 촛불 꺼짐, 큰 덩이, 변덕 | 기록 창(해요체) | 1문장 | 상태가 바뀐 순간 알림 |
| 쓰러짐 문구 | 체력 0, 불씨 중 지뢰 | 곽 씨 | 1문장 | 주머니 절반 손실 통보 |
| 하루 끝 한 줄 | 주머니가 금고로 넘어갈 때 | 구 실장 | 1문장 | 오늘 번 돈과 다음 도장까지 남은 금액 |
| 상인 대사 | 상점·상인 방 입장, 구매, 구경만 하고 나갈 때 | 심지 | 1문장 | 도구 설명 보조 |
| 납부일 대사 | Day 3·8·15 밤 | 구 실장 | 1~2문장 | 수금, 도장, 다음 납부와 변덕 예고 |
| 계약 해지 화면 | 납부 실패 | 문서 + 구 실장 | 2~3줄 | 판 종료 통보 |
| 권리증(완성) | 잔금 납부 뒤 | 문서 + 구 실장 | 5줄 | 등급별 반전 공개 |

플레이를 멈추는 텍스트는 오프닝 만화, 게시판, 납부일, 계약 해지, 권리증뿐이다. 화면에서는 납부를 '도장' 하나로 부른다(첫 도장, 두 번째 도장, 마지막 도장). 계약금·중도금·잔금은 구 실장의 대사 안에서만 나온다. 나머지는 화면 구석에 떴다가 사라진다. 한 번 본 낙서는 수첩(메뉴)에 모인다.

### 5.2 광산 등급별로 드러나는 것

등급은 6단계 + 예비 1이다(2차 결정). 첫 판에는 '광산 등급' 표기를 화면에 보이지 않는다.

| 등급 | 매물명 | 권리증 뒷면의 부위 | 이 등급에서 드러나는 것 |
|---|---|---|---|
| 1 | 달못 1호 갱 | 새끼발가락 | 광산이 한숨을 쉬고 뒤척인다. 큰 덩이를 캘 때 벽이 움찔한다 |

보물 값은 아이템·경제 설계서의 표에서 가져온다. 캘 때 뜨는 "30 ×2 = 60"의 앞 숫자가 시세가 붙은 값이다. '시세'라는 말은 구 실장 대사와 도움말에만 쓰고, 화면 표기는 "캔 값 ×1.5"로 쓴다.

### 6.2 계약 해지 화면

화면 제목은 "계약 해지". 그 아래 본문이 다음 셋 중 하나로 뜬다.

| 번호 | 본문 |
|---|---|
| 1 | {n}일째 밤, {부족액} 모자랐어요. 갱구는 잠겼고 다음 보름에 다시 열려요 |
| 2 | 권리증에 도장 {n}개를 찍었어요. 셋을 다 찍어야 광산이 넘어와요 |
| 3 | 도구는 갱 안에 두고 나왔어요. 다음 판은 1일째, 첫 도장부터예요 |

버튼: "다시 계약하기", "이번 판 기록 보기". 도장이 0개인 판은 2번을 쓰지 않는다.

본문 아래에 비교 한 줄이 붙는다. 다음 판에 무엇을 바꿀지 떠올리게 하는 용도다. 숫자 뒤에 조사를 붙이지 않는다.

| 못 찍은 도장 | 비교 한 줄 |
|---|---|
| 첫 도장 | 1~3일째 수입 {n} · 첫 도장을 찍은 판의 평균 {n} |
| 두 번째 도장 | 4~8일째 수입 {n} · 두 번째 도장을 찍은 판의 평균 {n} · 산 도구 {n}개 |
| 마지막 도장 | 9~15일째 수입 {n} · 마지막 도장을 찍은 판의 평균 {n} · 큰 덩이 {n}개 |

평균값은 경제 설계서 3.4의 값을 고정 숫자로 넣는다(등급 1: 계약금 1,000, 중도금 4,500, 잔금 15,600).

### 6.3 게시판: 갱 상태 13종

게시판 표기는 "오늘 갱 상태: (이름) · (설명)"이다. 설명은 실제로 바뀌는 규칙만 해요체로 적는다. 효과는 시스템 설계서 11.2의 확정안이다. 첫 판은 Day 2 '벽이 얇은 날', Day 3 '달빛이 고인 날'로 고정이다.

| 번호 | 이름 | 한 줄 설명 |
|---|---|---|
| 1 | 냄새가 진한 날 | 모든 층에 지뢰가 2개, 보물이 2개 더 묻혀 있어요 |
| 2 | 조용한 날 | 모든 층에 지뢰가 2개, 보물이 1개 덜 묻혀 있어요 |
| 3 | 숨이 고른 날 | 촛불 90으로 시작해요(평소 80) |
| 4 | 숨이 거친 날 | 촛불 70으로 시작해요. 대신 보물 값이 20% 올라요(자갈과 큰 덩이는 빼고요) |
| 5 | 깊이 잠든 날 | 계단 촛불이 1 + 도착 층이에요(평소 2 + 도착 층) |
| 6 | 마른 갱 | 발파에 촛불이 3만 들어요(평소 4) |
| 7 | 달빛이 고인 날 | 노다지 줄이 ×1.5에서 시작해요. 끊기면 ×1로 가요 |
| 8 | 불씨가 오래가는 날 | 촛불이 꺼진 뒤 불씨가 일곱 번이에요(평소 다섯 번) |
| 9 | 자갈이 굵은 날 | 자갈 값이 두 배예요 |
| 10 | 벽이 얇은 날 | 두드려 보기를 4번 쓸 수 있어요(평소 2번). 촛불은 그대로 2씩 들어요 |
| 11 | 곽 씨가 한가한 날 | 쓰러져도 주머니의 4분의 1만 잃어요 |
| 12 | 밤새 뒤척인 날 | 지하 2층에서 시작해요. 내려가는 촛불은 안 들어요 |
| 13 | 쌍둥이 지뢰 | 모든 층에서 지뢰가 위아래나 옆으로 둘씩 붙어 있어요. 하나를 찾으면 짝이 바로 옆이에요 |

- 이름도 '~음', '~함'으로 끝나지 않게 "~ 날" 꼴로 바꿨다(예: '냄새가 진함' → '냄새가 진한 날', '숨이 고름' → '숨이 고른 날'). 다른 문서와 프로토타입의 이름도 함께 바꿔야 한다.
- 13번은 광산 변덕에서 옮겨 왔다. 단서를 주는 좋은 날이라 변덕 자리에 맞지 않았다. 한 판에 한 번, 도장 찍는 날이 아닌 날에 나온다. 이날 갈림길에는 지뢰 짝 광맥이 나오지 않는다.

### 6.4 게시판: 주문서 16종

심지가 붙인다. 두 장 중 한 장을 떼어 간다. 카드 제목은 "주문서"뿐이고, 표기는 "(할 일) → (받는 것)"이다. 시스템 설계서의 묶음 이름(발파, 줄, 분필, 깊이)은 하루 두 장을 서로 다르게 뽑기 위한 분류라 화면에 내지 않는다. 조건을 채우는 순간 받는다(6번은 하루 끝, 15번은 올라가는 순간). 조건은 시스템 설계서 11.3의 확정안이고 보상 수치는 시세 ×1 기준이며 아이템·경제 설계서 8.9와 같다. 주머니 보상에는 시세가 붙고 노다지 줄 배율은 붙지 않는다. 카드에는 시세가 붙은 값을 적는다.

| 번호 | 주문서 문구 |
|---|---|
| 1 | 발파로 지뢰 4개를 터뜨려 주세요 → 화약 2개 |
| 2 | 발파 한 번에 지뢰 3개 이상을 터뜨려 주세요(처음 것도 세요) → 주머니 +60 |
| 3 | 보물을 그을리지 않고 발파를 3번 해 주세요(불발은 안 세요) → 화약 2개 |
| 4 | 노다지 줄 ×3을 한 번 찍어 주세요 → 촛불 +8 |
| 5 | 노다지 줄 ×2 이상인 채로 지하 4층에 도착해 주세요 → 주머니 +80 |
| 6 | 지뢰를 한 번도 터뜨리지 않고 보물 4개 이상을 캐서 하루를 마쳐 주세요 → 주머니 +100 |
| 7 | 직접 그은 X 6칸을 맞혀 주세요. 틀린 X가 나오면 실패예요 → 촛불 +6 |
| 8 | O를 그은 칸에서 보물 5개를 캐 주세요. O 칸에서 지뢰가 나오면 실패예요 → 주머니 +50 |
| 9 | 4 이상인 숫자와 닿은 칸에서 보물 3개를 캐 주세요 → 주머니 +80 |
| 10 | 한 번에 21칸 이상을 열어 주세요(층에 도착할 때 열리는 것은 안 세요) → 촛불 +5 |
| 11 | 한 층에서 보물 5개를 캐 주세요 → 촛불 +6 |
| 12 | 지하 5층에 도착해 주세요 → 주머니 +60 |
| 13 | 두드려 보기를 한 번도 쓰지 않고 보물 8개를 캐 주세요 → 주머니 +60 |
| 14 | 불씨로 보물 2개를 캐 주세요 → 주머니 +80 |
| 15 | 지하 4층 이하에서 촛불 21 이상을 남기고 올라가 주세요 → 주머니 +50 |
| 16 | 청록 보석 2개를 캐 주세요 → 주머니 +80 |

### 6.5 광맥 규칙 표지판 7종

표지판 문구는 층에 있는 동안 화면 위에 계속 떠 있다. 표지판을 누르면 보조 한 줄이 뜬다. 모두 해요체다.

| 이름 | 표지판 문구 | 눌렀을 때 보조 한 줄 |
|---|---|---|
| 맨땅 | 규칙이 없어요. 숫자만 보면 돼요 | 보물과 지뢰가 아무 데나 묻혀 있어요 |
| 짝 광맥 | 보물 바로 옆에 보물이 하나 더 있어요 | 위·아래·왼쪽·오른쪽 중 한 칸이에요. 대각선은 아니에요 |
| 외톨이 광맥 | 보물 둘레 8칸에는 다른 보물이 없어요 | 보물을 캤다면 그 둘레에 묻힌 것은 전부 지뢰예요 |
| 가로줄 광맥 | 보물은 가로 세 줄에만 있어요 | 세 줄은 서로 붙어 있지 않아요. 그 밖의 줄에 묻힌 것은 전부 지뢰예요 |
| 눈금 광맥 | 왼쪽 벽 눈금이 그 줄에 남은 보물 수예요 | 눈금이 0인 줄에 묻힌 것은 전부 지뢰예요 |
| 지뢰 짝 광맥 | 지뢰가 둘씩 붙어 있어요. 보물 값은 한 등급 높아요 | 위·아래·왼쪽·오른쪽으로 붙어요. 대각선은 아니에요. 혼자 떨어져 묻힌 것은 보물이에요 |
| 테두리 광맥 | 보물은 바깥 두 줄에만 있어요 | 안쪽에 묻힌 것은 전부 지뢰예요 |

갈림길 카드는 네 줄이다. 이름, 표지판 문구, 묻힌 양, 덤.

| 줄 | 예 |
|---|---|
| 이름 | 짝 광맥 |
| 표지판 문구 | 보물 바로 옆에 보물이 하나 더 있어요 |
| 묻힌 양 | 보물 8개쯤 · 지뢰 10개쯤 |
| 덤 | 덤: 도착하면 촛불 +4 |

덤 6종의 카드 표기

| 덤 | 카드 표기 |
|---|---|
| 보물 값 ×1.2 | 덤: 이 층 보물 값 ×1.2 |
| 촛불 +4 | 덤: 도착하면 촛불 +4 |
| 줄 한 단계 | 덤: 노다지 줄을 한 단계 올리고 시작해요 |
| 지뢰 +3·보물 +2 | 덤: 더 묻힌 층 · 지뢰 +3, 보물 +2 |
| 상인 방 | 덤: 가는 길에 상인 방이 있어요 |
| 샘 | 덤: 가는 길에 샘이 있어요 |

"더 묻힌 층"의 +3, +2는 묻힌 양 줄에 이미 더해서 보여 준다.

### 6.6 광산 변덕 4종 공지

등급 1의 변덕은 아래 네 가지다. Day 8에 하나, Day 15에 서로 다른 둘이 나온다. 첫 판 Day 8은 '뭉개진 숫자'로 고정이다. 예고는 앞 도장을 찍을 때 구 실장이 말한다(인물 대사). 당일 문구는 그날 게시판 맨 위에 붉은 줄로 뜬다(해요체).

| 이름 | 예고(구 실장) | 당일 게시판 |
|---|---|---|
| 뭉개진 숫자 | 그날은 큰 숫자가 뭉개집니다. 4와 5가 똑같이 "4+"로 보입니다. | 오늘 변덕: 뭉개진 숫자 · 4와 5가 모두 4+로 보여요 |
| 잠든 계단 | 그날은 계단이 빛을 내지 않습니다. 0 옆에 혼자 남은 바위를 찾으세요. | 오늘 변덕: 잠든 계단 · 밑줄도 새는 빛도 없어요. 계단은 0 옆에 남은 바위 밑에 있어요 |
| 마른 손 | 그날은 벽을 두드려도 소리가 안 납니다. 두드려 보기는 못 쓰십니다. | 오늘 변덕: 마른 손 · 두드려 보기를 쓸 수 없어요 |
| 선잠 | 그날은 광산이 덩이 근처에서 이미 깨어 있습니다. 촛불을 넉넉히 남겨 가세요. | 오늘 변덕: 선잠 · 큰 덩이 층에 도착하면 바로 한 번 캘 때 촛불이 2 들어요 |

- 여진은 등급 4 이상에서 나온다. 예고: "그날은 지뢰 하나가 터지면 닿아 있는 지뢰도 터집니다. 다치는 건 한 번입니다." 당일: "오늘 변덕: 여진 · 지뢰를 터뜨리면 둘레 8칸으로 닿은 지뢰도 터져요. 체력은 1만 줄어요".
- 선잠인 날 덩이 층에 도착하면 기록 창에 "벽이 이미 울리고 있어요. 광산은 깨어 있어요"가 뜬다.

### 6.10.3 화면 용어 정리(v2.2 시험)

게임 안 개념어가 설명 없이 쓰이던 문제를 세 가지로 다뤄요(결정 기록 83~86번). 기획 문서의 용어는 그대로이고, 화면 문구만 바뀌어요.

쉬운 말로 바꾼 화면 용어

| 전 | 지금 |
|---|---|
| 둘레 8칸, 둘레 한꺼번에 열기 | 주변 8칸, 주변 한꺼번에 열기 |
| 누르면 옆으로 가서 조준해요 | 누르면 옆으로 가요. 한 번 더 누르면 캐요 |
| 진열 바꾸기 | 다른 물건 보기(도구 세 자리만 바뀌어요) |
| 소모품 | 한 번 쓰는 물건 |
| 장착 도구 | 가진 도구 |
| 쓰는 칸 | 버튼으로 쓰는 것 |
| 화약: 조준한 X 칸에 촛불 없이 불을 붙여요 | 고른 X 칸에 촛불 없이 불을 붙여요 |
| 장착 도구 칸이 가득이에요 | 도구는 다섯 개까지 가질 수 있어요 |

효과를 같이 보여 주는 문구

| 자리 | 문구 |
|---|---|
| 노다지 줄 칸(줄 없음) | 연달아 캐면 값이 올라요 |
| 노다지 줄 칸(줄 있음) | 다음 보물 ×{n} · 지뢰면 ×1 |
| 오늘 주머니 옆 | 올라가면 금고로 |
| 갈림길 창 | 깊을수록 보물이 많고 비싼 보물이 잘 나와요. 지뢰도 늘고, 내려가는 촛불도 늘어요 |
| 갈림길 카드 | 금 알갱이 {a}% · 청록 보석 {b}% · 유물 {c}%(지뢰 짝 광맥은 앞에 "보물이 한 등급 높아요") |
| 계단 위 안내 | 계단을 한 번 더 클릭하면 내려가요 · 깊을수록 보물이 많고 비싸요 |

용어 설명(마우스를 올리면 뜨는 말풍선)

| 용어 | 설명 |
|---|---|
| 노다지 줄 | 지뢰를 치지 않고 보물을 연달아 캐면 보물 값의 배수가 올라요(×1 → ×1.5 → ×2 … ×3). 지뢰를 치면 ×1로 돌아가요 |
| 오늘 주머니 | 오늘 캔 돈이에요. 올라가면 금고로 옮겨요. 쓰러지면 절반을 잃어요 |
| 금고 | 모아 둔 돈이에요. 도장 값을 내고 도구를 사요. 쓰러져도 줄지 않아요 |
| 도장 | 광산 값을 나눠 낼 때마다 권리증에 도장을 찍어요. 도장 찍는 날 밤에 금고가 모자라면 계약이 끝나요 |
| 촛불 | 하루에 쓸 수 있는 힘이에요. 캐기 1, 발파 4, 계단은 2 + 내려갈 층. 다 타면 그날은 끝나요 |
| 체력 | 지뢰를 치면 1 줄어요. 0이 되면 쓰러져서 오늘 주머니의 절반을 잃어요. 다음 날 다시 차요 |
| 광맥 | 그 층에 보물이 묻힌 규칙이에요. 규칙을 알면 숫자만으로는 모르는 칸이 보물인지 지뢰인지 가릴 수 있어요 |
| 발파 | X를 그은 칸에 불을 붙여요(촛불 4). 지뢰면 다치지 않고 터져서 주변이 열려요. 보물이면 녹아 없어져요 |
| 두드려 보기 | 옆 칸 하나가 지뢰인지 아닌지 알려 줘요. 촛불이 2 들어요 |
| 가진 도구 | 갖고만 있어도 효과가 나는 도구예요. 다섯 개까지 가질 수 있어요 |
| 버튼으로 쓰는 것 | 버튼을 누르고 판에서 칸을 골라 써요. 화약 같은 물건은 한 번 쓰면 없어져요 |
| 남은 보물·지뢰 | 이 층에 아직 묻혀 있는 보물과 지뢰의 수예요. 다 세면 마지막 칸도 알 수 있어요 |
| 큰 덩이 | 도장 찍는 날 묻히는 큰 보물이에요. 금빛 테두리 안 칸을 다 캐야 값을 받아요 |
| 지하 층 | 깊을수록 보물이 많고 비싼 보물이 잘 나와요. 지뢰도 늘고, 내려가는 촛불도 늘어요 |
| 시세 | 도장을 찍으면 다음 날부터 캔 값이 오르거나 갱이 깊어져요 |

### 6.11 중개소 선물(판 시작, 구 실장)

권리증 화면 다음에 나온다. 일반 도구 셋 가운데 하나를 값 없이 받는다. 첫 판은 내기 분필, 연쇄 장부, 긴 도화선으로 고정이다.

v2.2 시험에서는 판 시작 선물이 없고, 도장을 찍을 때마다 '도장 선물'이 나온다. 문구는 6.10.2.

| 자리 | 문구 |
|---|---|
| 화면 제목 | 중개소 선물 |
| 구 실장(입장) | 계약 기념입니다. 셋 중 하나 가져가세요. |
| 구 실장(둘째 판부터, 번갈아) | 고르신 건 그믐까지 손님 겁니다. 그 뒤엔 갱에 두고 나오셔야 합니다. |
| 버튼 | 이걸로 받기 |
| 구 실장(고른 뒤) | 나머지 둘은 심지 가게에 나올 수도 있습니다. 그땐 제값입니다. |

도구 카드의 분류 표기는 "분필 도구", "발파 도구", "줄 도구", "와르르 도구", "두루 쓰는 도구"다. '축'이라는 말은 화면에 쓰지 않는다. 상점 카드도 같다.

### 6.12 오프닝 3컷 만화

새 판을 처음 시작할 때 나온다. 첫 판만 자동으로 나오고 건너뛸 수 있다. 규칙은 만화에서 가르치지 않는다. 컷마다 그림 설명 한 줄과 글 두 줄 이내다.

| 컷 | 그림 | 글 |
|---|---|---|
| 1 | 비 오는 골목의 게시판. 매물 전단 사이에 한 장만 값이 한 자리 적다. 주인공이 그 앞에 서 있다 | 자막: 마법 광산을 판대요. 값은 헐값이고, 보름달에만 열린대요. |
| 2 | 달못 중개소 책상. 구 실장이 권리증을 내민다. 도장 칸 셋이 비어 있다 | 구 실장: "15일 안에 세 번 나눠 내세요. 낼 때마다 도장을 찍어 드려요. 도장 세 개면 광산은 당신 거예요." |
| 3 | 보름달 아래 갱구. 주인공이 촛불 하나를 들고 들어간다. 옆 갱구 앞에 곽 씨가 앉아 있다 | 자막: 가진 건 촛불 하나와 곡괭이 한 자루예요. |

- 2컷의 대사는 2차 결정의 문구 그대로다. 이 컷에서만 구 실장이 해요체로 말한다. 계약 전의 영업 말투이고, 도장을 찍은 뒤에는 합니다체로 바뀐다.
- 건너뛰기 버튼 문구는 "건너뛰기"다. 설정에서 다시 볼 수 있다("오프닝 만화 다시 보기").
- v2.2 시험의 2컷 대사는 "15일 안에 다섯 번 나눠 내세요. 사흘마다 도장을 찍어 드려요. 도장 다섯 개면 광산은 당신 거예요."이고, 그림의 빈 도장 칸은 다섯 개다(6.10.2).

## 7. 화면 용어 정리표

이 장에서 정하는 것: 화면에 보이는 용어 56개와 한 줄 설명. 다른 문서와 게임 내 도움말이 이 표를 기준으로 삼는다.

설명 칸은 게임 내 도움말에 그대로 들어가므로 해요체로 썼다. 수치는 임시값이며 바뀌면 이 표를 함께 고친다.

### 7.1 기본

| 용어 | 한 줄 설명 |
|---|---|
| n일째 | 한 판은 1일째부터 15일째까지예요. 하루에 한 번 광산에 들어가요 |
| 촛불 | 하루 동안 쓸 수 있는 행동량이에요. 바위를 한 번 캐면 1 줄고, 0이 되면 불씨만 남아요. 걷는 데는 안 들어요 |
| 체력 | 지뢰를 터뜨리면 1 줄어요. 0이 되면 쓰러져요. 아침마다 가득 차요 |
| 바위 | 아직 캐지 않은 칸이에요. 한 번 캐면 깨져요 |
| 조준 | 바위를 클릭하면 그 옆으로 걸어가 그 바위에 테두리가 생겨요. 같은 바위를 한 번 더 클릭하면 캐요 |
| 바로 캐기 | 설정에서 켜면 옆에 있는 바위는 한 번 클릭으로 캐요. X를 그은 칸은 이때도 캐지지 않아요 |
| 숫자 | 그 칸 둘레 8칸에 묻힌 지뢰와 보물을 합친 개수예요 |
| 지뢰 | 캐면 터져서 체력이 1 줄고 노다지 줄이 끊겨요. 광부들은 "설익이"라고 불러요 |
| 보물 | 캐면 값이 오늘 주머니에 들어가요. 금 알갱이, 청록 보석, 유물이 있어요 |
| 자갈 | 부서진 바위에서 나오는 잔돈이에요. 한 번에 열린 만큼 묶어서 "자갈 +24"처럼 주머니에 들어가요 |
| 와르르 | 숫자가 0인 칸이 열리면 둘레 칸이 저절로 이어서 열려요 |
| 계단 | 다음 층으로 내려가는 길이에요. 층마다 하나씩 바위 밑에 숨어 있어요. 내려갈 때 촛불이 들어요(2 + 도착하는 층 번호) |
| 밑줄 숫자 | 밑줄이 그어진 숫자의 둘레 8칸 중 한 칸에 계단이 있어요 |
| 계단 빛 번짐 | 계단 바위에서 새는 빛이 둘레 두 칸까지 은은하게 번져요. 계단은 빛이 번진 곳 안쪽, 가장 밝은 곳 근처에 있어요 |
| 빛 새는 바위 | 틈으로 빛이 새는 바위 밑에 계단이 있어요. 캐면 계단이 드러나요 |
| 올라가기 | 언제든 하루를 끝내고 나올 수 있어요. 주머니는 전부 금고로 들어가고 남은 촛불은 버려요 |

### 7.2 돈과 도장

| 용어 | 한 줄 설명 |
|---|---|
| 오늘 주머니 | 오늘 캔 값이에요(가죽 주머니 그림). 무사히 올라오면 전부 금고로 들어가고, 쓰러지면 절반을 잃어요 |
| 금고 | 모아 둔 돈이에요(동전 꾸러미 그림). 상점에서 쓰고, 도장 찍는 날 여기서 내요. 쓰러져도 줄지 않아요 |
| 노다지 줄 | 지뢰를 터뜨리지 않고 보물을 연달아 캐면 보물 값이 ×1.5, ×2, ×2.5, ×3으로 올라요. 지뢰가 터지면 ×1로 돌아가고, 하루가 끝나면 사라져요 |
| 도장 | 광산 값을 세 번에 나눠 낼 때마다 권리증에 하나씩 찍혀요. 셋이 찍히면 광산이 내 것이 돼요 |
| 첫 도장·두 번째 도장·마지막 도장 | 3일째, 8일째, 15일째 밤에 금고에서 돈이 빠지고 도장이 찍혀요. 이자는 없어요. 구 실장은 계약금, 중도금, 잔금이라고 불러요 |
| 도장 다섯 번(v2.2 시험) | 광산 값을 사흘마다 다섯 번 나눠 내요. 3·6·9·12·15일째 밤에 첫·두 번째·세 번째·네 번째·마지막 도장을 찍어요. 구 실장은 계약금, 1차·2차·3차 중도금, 잔금이라고 불러요 |
| 도장 선물(v2.2 시험) | 도장을 찍을 때마다(마지막 도장 빼고) 도구 셋 중 하나를 그냥 받거나, 대신 금고 돈을 받아요. 도장이 늘수록 좋은 도구가 잘 나와요 |
| 다음 도장까지 | 다음 도장을 찍으려면 금고에 더 모아야 하는 돈이에요. 화면 위에 "다음 도장까지 120 · 3일째"처럼 떠 있어요 |
| 캔 값(시세) | 도장을 찍을수록 캔 것의 값이 올라요. 도장 0개 ×1, 1개 ×1.5, 2개 ×3이에요. 도구 값은 오르지 않아요 |
| 갱이 깊어져요(v2.2 시험) | 캔 값은 도장 1개부터 ×1.5에서 멈추고, 도장 2·3·4개째에는 다음 날부터 갱이 한 층씩 깊어져요. 같은 층에도 지뢰와 보물이 더 묻히고 좋은 보물이 잘 나와요 |
| 권리증 | 광산 계약 문서예요. 도장 칸이 셋 있어요 |
| 계약 해지 | 도장 찍는 날 밤에 금고가 모자라면 그 판이 끝나요. 낸 돈은 돌려받지 못해요 |
| 남긴 돈 | 마지막 도장을 찍고 금고에 남은 돈이에요. 그 판의 점수예요 |

### 7.3 추리와 표시

| 용어 | 한 줄 설명 |
|---|---|
| 분필 X | 지뢰라고 생각하는 칸에 긋는 표시예요. 오른쪽 클릭으로 그어요. X 칸은 클릭해도 캐지지 않아요 |
| 분필 O | 보물이라고 생각하는 칸에 긋는 표시예요. 오른쪽 클릭을 한 번 더 하면 O가 돼요. 촛불이 꺼진 뒤에도 보여요 |
| 두드려 보기 | 버튼을 누르고 옆 칸을 클릭하면 그 칸이 지뢰인지 아닌지 알려 줘요. 하루 2번, 한 번에 촛불이 2 들어요 |
| 발파 | 발파 버튼을 누르고 X 칸을 클릭하면 불을 붙여요(촛불 4). 지뢰였으면 다치지 않고 터져서 둘레 8칸이 열려요 |
| 불발 | 불을 붙인 칸이 지뢰가 아니었을 때예요. 촛불 4만 잃고, 그 칸이 보물이었으면 보물이 녹아 없어져요 |
| 그을린 보물 | 발파 범위에 있던 보물이에요. 값이 절반이 돼요 |
| 화약 | 촛불 대신 써서 발파를 한 번 하는 소모품이에요. 화약 버튼을 누르고 X 칸을 클릭해요. 날이 바뀌어도 남아요 |
| 남은 보물·지뢰(v2.2 시험) | 이 층에 아직 묻힌 보물과 지뢰의 수예요. 화면 위쪽에 보여요 |
| 둘레 한꺼번에 열기(v2.2 시험) | 숫자 칸 위에 서서 그 숫자를 한 번 더 누르면, 둘레에 그은 X·O 수가 숫자와 같을 때 나머지 덮인 칸을 촛불 1에 한꺼번에 열어요. 표시가 틀렸으면 지뢰가 터져요 |
| 완벽한 층(v2.2 시험) | 그 층의 보물을 녹이지 않고 다 캐고, 캐다가 지뢰를 한 번도 터뜨리지 않은 층이에요. 값이 오르지는 않고 기록에 남아요 |

### 7.4 층과 길

| 용어 | 한 줄 설명 |
|---|---|
| 광맥 | 그 층에 보물이나 지뢰가 묻힌 규칙이에요. 층마다 하나이고 일곱 가지가 있어요(맨땅, 짝, 외톨이, 가로줄, 눈금, 지뢰 짝, 테두리) |
| 표지판 | 그 층의 광맥 규칙을 한 줄로 알려 줘요. 층에 있는 동안 화면 위에 떠 있어요 |
| 갈림길 | 계단 앞에서 다음 층을 둘 중 하나로 골라요. 고르기 전에 각 층의 광맥, 묻힌 양, 덤이 보여요 |
| 덤 | 갈림길 카드마다 하나씩 붙는 작은 이득이에요 |
| 샘 | 갈림길에 가끔 나오는 방이에요. 체력 +1과 촛불 +15 가운데 하나를 골라요 |
| 상인 방 | 갈림길에 가끔 나오는 방이에요. 광산 안에서 금고 돈으로 도구를 사요 |

### 7.5 하루의 시작과 끝

| 용어 | 한 줄 설명 |
|---|---|
| 게시판 | 아침에 보는 판이에요. 오늘의 갱 상태, 주문, 지금 캔 값, 다음 도장까지 남은 돈이 적혀 있어요 |
| 갱 상태 | 오늘 하루만 적용되는 규칙 변화예요. 매일 하나씩 나와요 |
| 주문 | 오늘 안에 조건을 채우면 보상을 받는 쪽지예요. 두 장 중 한 장을 골라요 |
| 어두워짐 | 촛불이 15 이하로 줄면 주변만 밝게 보여요. 먼 곳의 숫자는 흐리게 보이지만 값은 지금 값 그대로예요 |
| 불씨 | 촛불이 0이 된 뒤 남는 다섯 번의 기회예요. 숫자가 가려지고 분필 표시만 보여요. 이때 지뢰를 터뜨리면 바로 쓰러져요 |
| 쓰러짐 | 체력이 0이 되거나 불씨 중에 지뢰를 터뜨리면 쓰러져요. 그날이 끝나고 주머니 절반을 잃어요 |
| 수고비 | 쓰러졌을 때 곽 씨가 끌어내 준 값으로 가져가는 주머니 절반이에요 |
| 오늘의 광산(v2.2 시험) | 권리증 화면에서 고르는 그날의 광산이에요. 같은 날에는 모두 같은 판을 받아요. 날짜마다 최고 점수가 남아요 |

### 7.6 도장 찍는 날

| 용어 | 한 줄 설명 |
|---|---|
| 도장 찍는 날 | 3일째, 8일째, 15일째예요. 밤에 돈을 내고, 낮에는 큰 덩이가 묻혀 있어요 |
| 큰 덩이 | 도장 찍는 날 정해진 층에 묻히는 여러 칸짜리 보물이에요. 숫자는 칸마다 따로 세요. 전부 캐야 값을 받고 노다지 줄 배율이 붙어요. 발파로는 안 열려요. 덩이에 닿은 숫자에는 작은 금빛 점이 찍혀요 |
| 광산 깨어남 | 큰 덩이의 첫 칸을 캐면 그 층을 떠날 때까지 한 번 캘 때 촛불이 2씩 들어요 |
| 광산 변덕 | 두 번째 도장 날(1개)과 마지막 도장 날(2개) 하루 종일 적용되는 까다로운 규칙이에요. 앞 도장을 찍을 때 미리 알려 줘요 |

### 7.7 상점

| 용어 | 한 줄 설명 |
|---|---|
| 중개소 선물 | 판을 시작할 때 도구 셋 중 하나를 그냥 받아요 |
| 상점 | 하루가 끝나면 열려요. 금고 돈으로 도구를 사요 |
| 도구 | 갖고 있으면 조건이 맞을 때 저절로 발동하거나, 버튼을 눌러서 써요. 판이 끝나면 사라져요 |
| 분필 도구·발파 도구·줄 도구·와르르 도구 | 도구가 무엇에 반응하는지 알려 주는 분류예요. 분필 표시, 발파, 노다지 줄, 와르르 가운데 하나예요. 어디에도 안 속하면 "두루 쓰는 도구"예요 |
| 되팔기 | 가진 도구를 산 값의 절반에 팔아요 |
| 새로고침 | 정해진 값을 내고 진열을 바꿔요 |

용어 56개와 v2.2 시험 용어 7개. 도구 이름과 도구별 설명은 아이템 파트 문서에 둔다. 도구 설명도 해요체로 쓴다.

v2.2 시험에서는 덤, 샘, 상인 방, 갱 상태, 주문, 어두워짐, 불씨, 광산 깨어남, 광산 변덕, 중개소 선물, 되팔기를 쓰지 않는다. 두드려 보기는 청진 망치가 있을 때만 쓴다. 촛불이 0이 되면 하루가 끝난다. 그래서 이 용어들은 v2.2 시험 도움말에서 빼고, '촛불'은 "0이 되면 그날은 끝나요"로, '광맥'은 "층마다 하나이고 짝, 테두리, 외톨이가 나와요"로, '갈림길'은 "각 층의 광맥과 묻힌 보물·지뢰 수가 보여요"로 바꿔 보여 준다. 화면 이름은 첫 도장부터 마지막 도장까지 '도장'이다.

### 8.2 현지화 메모(영어 우선 출시)

| 항목 | 메모 |
|---|---|
| 원문 언어 | 한국어로 쓰고 영어로 옮긴다. 원문 길이는 영어 문장이 한 줄에 들어가는지를 기준으로 정한다 |
| 길이 상한 | 대사·낙서는 한글 45자, 영문 80자. 표지판 문구는 한글 24자, 영문 40자(화면 위에 계속 떠 있다). 갱 상태 이름은 한글 10자, 영문 16자. 해요체로 바꾸면서 한글 상한을 조금 늘렸다 |
| mine 중의성 | 영어에서 광산과 지뢰가 같은 단어다. 지뢰는 "raw"(복수 raws), 광산은 "the mine". 첫 강조 말풍선에서 한 번만 "raws (mines)"로 풀어 준다. 한국어 화면은 "지뢰"로 쓰고 설정 문구에서만 "설익이"를 함께 쓴다. 스토어 소개문은 장르어 mines를 그대로 쓴다 |
| 도장 | 화면 표기는 First Stamp / Second Stamp / Final Stamp, "Next stamp: 120 to go · Day 3". 구 실장 대사의 계약금·중도금·잔금은 down payment / second payment / final payment로 옮긴다. deposit은 돌려받는 돈으로 읽힐 수 있어 피한다 |
| 해요체 | 영어에는 해요체에 해당하는 구분이 없다. 설명 문구는 짧은 평서문과 you로 옮긴다("No rule here. Just read the numbers."). 낙서는 곽 씨의 공손한 메모이므로 명령형보다 권유형을 쓴다 |
| 날짜 표기 | 한국어 화면은 "3일째", 영어 화면은 "Day 3" |
| 보름·그믐 | full moon / new moon. 그믐의 어감은 "when the moon goes dark"로 푼다 |
| 줄이 두 번 나옴 | "줄 광맥"은 노다지 줄과 헷갈려 "가로줄 광맥"으로 바꿨다(2차 결정). 영어는 Streak / Row Vein |
| 주요 용어 영문안 | 금 알갱이 Gold Grain, 시세 Moon Rate, 불발 Dud, 촛불 Candle, 오늘 주머니 Today's Pouch, 금고 Safe, 노다지 줄 Lode Streak, 광맥 Vein, 표지판 Sign, 갈림길 Fork, 발파 Blast, 불씨 Embers, 큰 덩이 The Lump, 광산 깨어남 The Mine Stirs, 계단 빛 번짐 Stair Glow, 바로 캐기 Quick Dig, 덤 Bonus, 광산 변덕 Mood(마른 손 Dry Hands, 선잠 Light Sleep), 게시판 Board, 갱 상태 Today's Shaft, 주문 Order, 계약 해지 Contract Void, 도장 Stamp, 수고비 Hauling Fee |
| 광맥 이름 영문안 | 맨땅 Bare, 짝 Paired, 외톨이 Loner, 가로줄 Row, 눈금 Notched, 지뢰 짝 Twin Raws, 테두리 Rim |
| 표기 그대로 쓰는 것 | "4+", "×1.5", "40 ×2 = 80", 분필 X·O. 번역하지 않는다. 문구에 키 이름을 쓰지 않는다. 조작은 클릭, 오른쪽 클릭, 버튼 이름으로만 말한다(게임패드판을 만들면 이 문구들만 따로 둔다) |
| 숫자 뒤 조사 금지 | 숫자 변수 바로 뒤에 은/는, 이/가, 을/를, 으로/로를 붙이지 않는다("64은" 같은 오류가 난다). "버리는 촛불 64", "금고 +310"처럼 숫자로 끝내거나 "{n}개", "{n}칸"처럼 단위를 붙인다. 구 실장 대사의 "{부족액} 모자랍니다"처럼 조사 없이 이어지는 꼴은 쓴다 |
| 변수 | 숫자 변수만 쓴다. 변덕 이름·광맥 이름 같은 명사는 변수로 넣지 않고 종류별 문장을 따로 둔다(한국어 조사와 영어 복수형 때문). `{n}개`는 영어에서 단수·복수가 갈리므로 n이 1인 문장을 따로 둔다 |
| 말투 구분 | 존댓말·반말·하게체 차이는 영어에서 사라진다. 구 실장은 문서 투("per clause 5"), 심지는 축약형, 곽 씨는 주어를 뺀 단문 |
| 인명 | 구 실장 = Mr. Goo 또는 the Agent, 심지 = Wick, 곽 씨 = Old Gwak |
| 플레이어 호칭 | 성별·이름을 부르지 않는다. "자네", "손님", 영어는 "you" |
| 금지 | 말장난, 속담, 한국 문화 지식이 필요한 농담. 설명 문구를 '~음', '~함', '~다'로 끝내는 것 |
| 관리 | 문구는 표 파일 한 장(칸을 쉼표로 나눈 CSV 형식)으로 관리한다. 열: 번호, 위치, 화자, 조건, 한국어, 영어. 7장 용어표의 용어는 번역 전에 영문을 먼저 확정하고 모든 문구에서 같은 말을 쓴다 |

## 9. 다른 파트에 넘기는 요청

이 장에서 정하는 것: 이 문서의 문구를 쓰려면 시스템·UI·아트·아이템·시장 담당이 맞춰 줘야 하는 것.

| 대상 | 요청 |
|---|---|
| 시스템 | 납부 실패 문구에 쓰는 부족액, 도장 수, 쓰러진 횟수를 판 종료 화면에 넘겨 줄 것. 강조 말풍선 5번 문구를 6.9의 것으로 교체(시스템 설계서 16.4) |
