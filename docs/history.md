# 작업 기록

대화 중에 나온 중요한 방향과 결정만 한 줄씩 남겨요. 규칙과 수치의 자세한 결정은 decisions.md에, 바뀐 파일은 git 기록에 있어요. 길어지지 않게 한 날에 몇 줄만 써요.

## 2026-11-23

- 기획 2차(v2.1) 문서와 웹 프로토타입을 저장소로 가져왔어요. 프로토타입을 Vite + TypeScript로 옮기고, 인수인계 문서와 CI를 붙여 GitHub 공개 저장소에 올렸어요.
- 이름은 옛 가제 「초 한 자루」 대신 원 캔들 딥으로 불러요.
- 재미 증진 보고서(reviews/12_fun_report.html)를 썼어요. 비교 게임과 봇 측정을 근거로 삼았어요.
- 보고서 1~4주차를 'v2.2 시험' 규칙 묶음으로 구현했어요. 기본 규칙이 v2.2 시험이고, v2.1은 주소 뒤 `?preset=v21`로 남겨요. 사람 5명 플레이테스트는 안내서(playtest_kit.md)만 있고 아직 하지 않았어요.
- 작업 방식: 작업이 끝나면 묻지 않고 커밋해요. 푸시는 요청할 때만 해요.
- 게임 용어가 설명 없이 쓰인다는 지적이 있었어요. 화면 말은 쉬운 말로 바꾸고, 개념어에는 효과 한 줄과 마우스를 올리면 뜨는 설명을 붙였어요. 화면에 없던 "지하로 내려가면 좋은 점"도 갈림길 창에 넣었어요.
- 설정 스위치를 줄였어요.
  - 끌 이유가 없는 것(키보드 단축키, 판 아래 범례, 강조 말풍선)은 없앴어요.
  - 난이도를 바꾸는 것(주변 한꺼번에 열기)도 없앴어요.
  - 남은 것은 바로 캐기, 화면 흔들림, 지뢰 플래시예요.
- 방향: Windows 기본 지뢰찾기에 있는 기능은 모두 갖춰야 해요. 빠진 기능을 검토하기 시작했어요.
- 이 기록을 시작했어요.
