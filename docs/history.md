# 작업 기록

대화 중에 나온 중요한 방향과 결정만 한 줄씩 남겨요. 규칙과 수치의 자세한 결정은 decisions.md에, 바뀐 파일은 git 기록에 있어요. 길어지지 않게 한 날에 몇 줄만 써요. 이 파일이 길어지면 docs/history/ 아래에 기간별 파일로 나누고 이 파일은 목차로 남겨요. 다른 문서도 커지면 하위 폴더나 번호를 더해 나눠요.

## 2026-11-23

- 기획 2차(v2.1) 문서와 웹 프로토타입을 저장소로 가져왔어요. 프로토타입을 Vite + TypeScript로 옮기고, 인수인계 문서와 CI를 붙여 GitHub 공개 저장소에 올렸어요.
- 이름은 옛 가제 「초 한 자루」 대신 원 캔들 딥으로 불러요.
- 재미 증진 보고서(reviews/12_fun_report.html)를 썼어요. 비교 게임과 봇 측정을 근거로 삼았어요.
- 보고서 1~4주차를 'v2.2 시험' 규칙 묶음으로 구현했어요. 기본 규칙이 v2.2 시험이고, v2.1은 주소 뒤 `?preset=v21`로 남겨요. 사람 5명 플레이테스트는 안내서(playtest_kit.md)만 있고 아직 하지 않았어요.
- 작업 방식: 작업이 끝나면 묻지 않고 커밋해요. 푸시는 요청할 때만 해요.
- 게임 용어가 설명 없이 쓰인다는 지적이 있었어요. 화면 말은 쉬운 말로 바꾸고, 개념어에는 효과 한 줄과 마우스를 올리면 뜨는 설명을 붙였어요. 화면에 없던 "지하로 내려가면 좋은 점"도 갈림길 창에 넣었어요.
- 설정 스위치를 줄였어요.
  - 끌 이유가 없는 것(키보드 단축키, 판 아래 범례, 강조 말풍선)은 없앴어요.
  - 난이도를 바꾸는 것(주변 한꺼번에 열기)도 없앴어요.
  - 남은 것은 바로 캐기(뒤에 '조준'으로 바뀜), 화면 흔들림, 지뢰 플래시예요.
- 방향: Windows 기본 지뢰찾기에 있는 기능은 모두 갖춰야 해요. 빠진 기능을 검토하기 시작했어요.
- 이 기록을 시작했어요.
- 문서가 커지면 하위 폴더나 번호로 나눠요.
- Windows 지뢰찾기에 맞춰 세 가지를 더했어요. 숫자 눌러 한꺼번에 열기는 안 되면 말 없이 흔들리기만 하고, 층을 떠날 때 왼쪽부터 답을 공개하고, 통계를 넣었어요. 설명을 덧붙이기보다 손으로 느끼는 반응을 쓰는 쪽이 의뢰인 방향이에요.
- X 칸은 누르면 바로 발파돼요. 실수는 막기보다 겪으며 조심하게 두고, 조심하고 싶은 사람은 설정 '조준'을 켜요(바위와 X 모두 두 번 클릭).
- 아이디어(정하지 않음): 나중에 X·O 칸 왼쪽 클릭을 캐릭터마다 다른 스킬로 만들기.
- 조준을 끄면 클릭 한 번에 걸어가서 캐거나 터뜨려요(먼 칸도). 판 위 키보드 조작(이동, 캐기, 분필 등)은 없앴어요. 마우스로 칸을 바로 누르니 필요 없었어요.
- 쓸모없어진 것을 걷어냈어요: 발파 버튼, 내려가기 버튼, 계단과 숫자의 두 번 클릭, 옛 측정 스크립트 묶음. v2.1 전용 장치와 문서 다시 쓰기는 플레이테스트로 v2.2가 정해진 뒤에 해요.
- 한글 이름도 영어 그대로 읽은 원 캔들 딥으로 정했어요. 「초 한 자루」는 쓰지 않아요.
- 캔 보물이 작아서 뭘 캤는지 모르겠다는 지적으로, 캔 칸에서 보물이 크게 솟고 이름이 같이 뜨게 했어요.
- '노다지 줄'을 '콤보'로 바꿨어요. 동작이 이름만 보고 읽히는 쪽을 골랐고, 광산 말맛은 인물 대사에 남겨요.
- 오른쪽 정보창을 다시 짰어요. 칸마다 있는 이유가 있게 하고, 달 그림 대신 달력 단추를 넣었어요.
- 나머지 화면도 같은 기준(칸마다 있는 이유, 되풀이와 빈자리 없애기)으로 점검해 고쳤어요.
- 상인 이름을 '심지'에서 '심 씨'로 바꿨어요. 초 심지와 헷갈리지 않게, 다른 두 인물처럼 성으로 불러요.
- 캐릭터 다섯 명과 스킬을 넣었어요. 스킬은 X·O 칸 클릭에 붙이고, 오른쪽 정보창 설명 칸 위에 캐릭터 칸을 두었어요. 플레이테스트 전까지는 다섯 명 모두 열어 둬요.

## 2026-11-24

- 다른 게임(지뢰찾기 로그라이트, 유물 시스템, 채굴·빚 게임)을 조사해 새 도구 후보와 도구 장치를 정리했어요(reviews/13_tool_ideas.md). 제안만 하고 아직 넣지 않았어요.
- 도구를 사는 것 말고 줍기, 감정, 팔기, 겹치기, 짝을 히트 게임에서 찾아 정리했어요(reviews/14_tool_experience.md). 지뢰찾기 계열보다 많이 팔린 게임을 기준으로 삼으라는 방향이에요. 아직 넣지 않았어요.
- 도구 방향: 겹치기(★)와 깨지는 도구는 빼고, 합쳐지는 도구는 센 것으로 2~3쌍만 둬요. 도감은 Balatro처럼 얻을 때마다 이름이 열리게 해요. 기준은 "덜어낼 게 없는 상태"예요.
- 연장함은 캔 자리에서 바로 골라요. 칸이 없으면 곽 씨에게 싸게, 상점에서는 심 씨에게 더 받고 팔아요. 도구 칸 8칸과 칸을 늘리는 도구를 검토해요.
- 의뢰인 플레이는 정석보다 중간중간 거는 편이라, 봇 숫자는 위쪽 기준으로만 참고해요.
- 도구 경험을 구현했어요: 도구 칸 8, 옛 연장함, 팔기, 합친 도구 셋, 심 씨 외상, 도구 도감. 봇으로 재 보니 통과율과 점수가 크게 올라 균형은 의뢰인과 정하기로 했어요.
- 균형은 합치기부터 손봤어요. 재료 하나를 연장함에서 얻어야 합칠 수 있게 해서, 합친 도구는 세 판에 한 번꼴로 줄였어요.
- 처음 보는 도구는 '처음' 표시 대신 이름을 가려요. 효과는 보이고, 얻을 때 이름이 열려요.
- 납부액은 마지막 도장 5,500 곡선으로 올렸어요. 봇 숫자는 위쪽 기준이라, 신중 봇이 목표보다 조금 높은 쪽을 골랐어요.
- 정답을 조금 주는 바랜 분필 자국을 넣었어요. 자리는 '추리로 안 풀리는 칸'이 아니라 진짜 무작위로 하기로 했어요.
- 바랜 O가 판을 크게 쉽게 만들지만 확률은 그대로 두기로 했어요. 화면 설명은 확률 숫자 대신 '가끔', '자주' 같은 사람 말로 쓰기로 했어요.
- 연장함에서 가끔 유품(판 끝까지 남는 영구 효과)이 나오게 했어요. 촛불·체력 같은 능력치는 유품에만 둬요.
- 캐릭터를 옷 색이 아니라 머리에 쓴 것과 손에 든 것으로 구분하게 다시 그렸어요. 시드 방식과 끝없는 갱 설계안(reviews/15)을 썼어요. 엔딩은 나중에 해요.
- 엔딩 대신 끝없는 갱을 넣고, 시드를 코드로 넣고 나눌 수 있게 했어요. 옛 규칙이 남은 문구(두드려 보기 '옆 칸' 등)를 정리했어요.
- 처음 켰을 때의 첫 판 경험을 히트 게임(Balatro, Slay the Spire, Luck be a Landlord, Into the Breach, Hades 등)과 비교해 고찰했어요(reviews/16). 제안은 아직 적용 전이에요.
- 첫 판 경험 제안 여덟 가지를 다 적용했어요. 첫 판은 덜어내고(바로 판으로, 얇은 광산), 지더라도 무언가 열리게 했어요.
- 스플래시·타이틀·오프닝·튜토리얼이 우리에게 무엇이 필요한지 고찰했어요(reviews/17). 스플래시는 빼고, 작은 타이틀과 이어하기를 만들었어요.
- 판 준비 화면이 평평하다는 지적에 깊이와 무게를 다시 짰어요(reviews/18). 사람을 주인공으로, 권리증은 광산 고르기로, 나머지는 접거나 다른 화면으로 옮겼어요.
- 화면 말투를 합니다체로, '유품'을 '유물'로(보물 등급은 금잔) 바꾸고, 기준 여덟을 세워 모든 화면을 점검해 덜어냈어요(reviews/19). 설정은 일시 정지와 탭 창으로 나누고 소리 설정을 만들었어요.
