# 07. 용어집

이 장에서 정하는 것: 새로 정하는 것은 없다. 기획서에 나오는 말을 한곳에 모아 한 줄로 풀었다. 화면에 보이는 말은 02 문서 7장 '화면 용어 정리표'(56개)가 기준이고, 이 용어집은 거기에 화면에 이름이 나오는 그 밖의 말과 문서에서만 쓰는 기획 용어를 더한 것이다.

| 항목 | 내용 |
|---|---|
| 순서 | 가나다순. 영문·기호로 시작하는 말은 맨 뒤에 따로 모았다 |
| 구분 | '화면'은 게임 화면에 글자로 나오는 말이다. 설명은 게임 내 도움말에 그대로 쓸 수 있게 해요체로 적었다. '기획'은 문서에만 나오는 말이고 설명은 평서체다 |
| 처음 나오는 장 | 그 말을 정의하거나 처음 풀어 쓴 곳. "01 3.4"는 01 문서 3장 4절. 01 시스템, 02 세계관·문구, 03 아트·UI, 04 시장·계획, 05 아이템·경제 |
| 수치 | 01·05 문서의 최종값. 바뀌면 이 표도 함께 고친다 |

모두 160개다(화면 92, 기획 68).

| 갱 상태 / 광산 변덕 | 갱 상태는 매일 하나씩 오는 그날의 조건이고 대부분 중립이거나 이롭다. 광산 변덕은 두 번째·마지막 도장 날에만 오는 까다로운 조건이고 미리 예고된다 |
| 광맥 규칙 / 갱 상태 | 광맥 규칙은 층 하나에 붙고, 갱 상태는 그날의 모든 층에 붙는다 |
| 지뢰 짝 광맥 / 쌍둥이 지뢰 | 지뢰가 둘씩 붙는 것은 같다. 지뢰 짝 광맥은 층 하나의 규칙이고 보물이 한 등급 높다. 쌍둥이 지뢰는 하루 전체의 갱 상태이고 보물 등급은 그대로다 |
| 캔 값(시세) / 등급 배수 | 캔 값 배율은 판 안에서 도장을 찍을 때마다 오른다. 등급 배수는 광산 등급에 따라 납부액과 큰 덩이 값에 붙는다 |
| 첫 판 / v0.3 초판 | 첫 판은 플레이어가 처음 하는 판이다. v0.3 초판은 05 문서의 이전 판본을 가리키는 말이다 |
| 위험 칸 / 덮인 칸 | 덮인 칸은 아직 깨지 않은 모든 바위다. 위험 칸은 그중 숫자로 보아 지뢰나 보물이 묻힌 것이 확실한 칸이다 |
| 도장 / 계약금·중도금·잔금 | 같은 것을 가리킨다. 화면은 '첫 도장, 두 번째 도장, 마지막 도장'으로 적고, 구 실장만 대사에서 계약금, 중도금, 잔금이라고 부른다 |
| 조준 / 바로 캐기 | 평소에는 바위를 한 번 클릭하면 조준, 같은 바위를 다시 클릭하면 캔다. 설정에서 바로 캐기를 켜면 옆 바위는 한 번 클릭에 캔다. X 칸은 어느 쪽에서도 캐지지 않는다 |
| 계단 빛 번짐 / 빛 새는 바위 | 빛 번짐은 계단 근처 두 칸에 퍼진 은은한 빛이고 중심이 계단에서 0~1칸 어긋난다. 빛 새는 바위는 계단이 든 바로 그 바위다 |
