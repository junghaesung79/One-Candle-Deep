# 07. 용어집

이 장에서 정하는 것: 새로 정하는 것은 없다. 기획서에 나오는 말을 한곳에 모아 한 줄로 풀었다. 화면에 보이는 말은 02 문서 7장 '화면 용어 정리표'(56개)가 기준이고, 이 용어집은 거기에 화면에 이름이 나오는 그 밖의 말과 문서에서만 쓰는 기획 용어를 더한 것이다.

| 항목 | 내용 |
|---|---|
| 순서 | 가나다순. 영문·기호로 시작하는 말은 맨 뒤에 따로 모았다 |
| 구분 | '화면'은 게임 화면에 글자로 나오는 말이다. 설명은 게임 내 도움말에 그대로 쓸 수 있게 합니다체로 적었다(2026-11-24 해요체에서 바꿈). '기획'은 문서에만 나오는 말이고 설명은 평서체다 |
| 처음 나오는 장 | 그 말을 정의하거나 처음 풀어 쓴 곳. "01 3.4"는 01 문서 3장 4절. 01 시스템, 02 세계관·문구, 03 아트·UI, 04 시장·계획, 05 아이템·경제 |
| 수치 | 01·05 문서의 최종값. 바뀌면 이 표도 함께 고친다 |

모두 170개다(화면 99, 기획 71). v2.2 시험에서 새로 쓰는 말 10개를 더했고, v2.2 시험에서 쓰지 않거나 달라지는 말에는 그렇게 적었다.

| 도장 / 계약금·중도금·잔금 | 같은 것을 가리킨다. 화면은 '첫 도장, 두 번째 도장, 마지막 도장'으로 적고, 구 실장만 대사에서 계약금, 중도금, 잔금이라고 부른다. v2.2 시험에서는 다섯 번이고, 구 실장은 계약금, 1차·2차·3차 중도금, 잔금이라고 부른다 |
| 도장 선물 / 중개소 선물 | 같은 고르기(도구 셋 중 하나)다. 중개소 선물은 v2.1에서 판을 시작할 때 한 번 받는다. 도장 선물은 v2.2 시험에서 도장을 찍을 때마다 받고, 대신 금고 돈을 고를 수도 있다 |
| 둘레 한꺼번에 열기 / 와르르 | 와르르는 숫자 0 둘레가 저절로 열리는 것이고 촛불이 들지 않는다. 둘레 한꺼번에 열기는 플레이어가 표시를 다 그은 숫자를 눌러 촛불 1에 여는 것이고, 표시가 틀리면 지뢰가 터진다 |
| 조준 / 바로 캐기 | 옛 설정 '바로 캐기'는 '조준'으로 바뀌었다. 조준이 꺼져 있으면(기본) 한 번 클릭에 걸어가서 캐거나 터뜨리고, 켜면 한 번 조준한 뒤 다시 눌러야 한다 |
| 계단 빛 번짐 / 빛 새는 바위 | 빛 번짐은 계단 근처 두 칸에 퍼진 은은한 빛이고 중심이 계단에서 0~1칸 어긋난다. 빛 새는 바위는 계단이 든 바로 그 바위다 |
