# 부록 C. 2차 프로토타입 안내

> Word 기획서(`docs/export/기획서_2차_v2.1.docx`)의 부록 C를 마크다운으로 옮기고, 이 저장소에서 프로토타입을 실행하는 방법(C.0)을 더한 문서예요.

## C.0 이 저장소에서 실행하기

프로토타입은 `prototype/` 폴더의 Vite + TypeScript 프로젝트예요. Node.js 20 이상이 필요해요.

```bash
cd prototype
npm install      # 처음 한 번
npm run dev      # http://localhost:5173 에서 열려요. 코드를 고치면 바로 반영돼요
```

| 명령 | 하는 일 |
|---|---|
| `npm test` | 광맥 생성기 7종 × 1,000층, 규칙 단위 검사, 봇 연기 검사(30초 안팎) |
| `npm run typecheck` | TypeScript 타입 검사 |
| `npm run bot` | 경제 측정 보고서(보통 정책 100판 + 신중·욕심 각 50판, 1~2분). `npm run bot -- 300`처럼 판 수를 줄 수 있어요 |
| `npm run build` | `dist/index.html` 파일 하나로 빌드해요. 더블클릭으로 열거나 정적 호스팅에 그대로 올리면 돼요 |

코드 구조와 작업 규칙은 [handoff.md](handoff.md)에 있어요.

## C.2 조작(마우스 중심)

| 행동 | 마우스 |
|---|---|
| 이동 | 열린 칸 왼쪽 클릭 |
| 캐기 | 바위를 클릭하면 옆으로 걸어가 조준, 같은 바위를 한 번 더 클릭하면 캐요. 설정에서 '바로 캐기'를 켜면 한 번 클릭으로 캐요 |
| 분필(X → O → 지움) | 오른쪽 클릭. X 칸은 클릭해도 캐지지 않아요 |
| 두드려 보기, 발파, 소모품 | 버튼을 누른 뒤 칸을 클릭. 오른쪽 클릭이나 버튼을 다시 누르면 취소 |
| 계단 | 계단 위에서 계단 칸 클릭 → 갈림길 카드 클릭 |
| 올라가기 | 올라가기 버튼 → 확인 창 |
| 설정 | Esc 또는 톱니 버튼: 바로 캐기, 키보드 단축키, 화면 흔들림, 오프닝 다시 보기 |
| 디버그 | F2 판 공개, F3 촛불 가득, F4 금고 +500, F8 오늘 끝, F9 하루 넘김 |
