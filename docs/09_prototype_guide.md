# 부록 C. 2차 프로토타입 안내

> Word 기획서(`docs/export/기획서_2차_v2.1.docx`)의 부록 C를 마크다운으로 옮기고, 이 저장소에서 프로토타입을 실행하는 방법(C.0)을 더한 문서예요.

## C.0 이 저장소에서 실행하기

프로토타입은 `prototype/` 폴더의 Vite + TypeScript 프로젝트예요. Node.js 20 이상이 필요해요.

```bash
cd prototype
npm install      # 처음 한 번
npm run dev      # http://localhost:5173 에서 열려요. 코드를 고치면 바로 반영돼요
```

| 명령 | 하는 일 |
|---|---|
| `npm test` | 광맥 생성기 7종 × 1,000층, 규칙 단위 검사, 봇 연기 검사(30초 안팎) |
| `npm run typecheck` | TypeScript 타입 검사 |
| `npm run bot` | 경제 측정 보고서(보통 정책 100판 + 신중·욕심 각 50판, 1~2분). `npm run bot -- 300`처럼 판 수를 줄 수 있어요. v2.1 규칙으로 재려면 `npm run bot -- 200 v21` |
| `npm run build` | `dist/index.html` 파일 하나로 빌드해요. 더블클릭으로 열거나 정적 호스팅에 그대로 올리면 돼요 |

코드 구조와 작업 규칙은 [handoff.md](handoff.md)에 있어요.

## C.2 조작(마우스 중심)

| 행동 | 마우스 |
|---|---|
| 이동 | 열린 칸 왼쪽 클릭 |
| 캐기 | 바위를 클릭하면 (떨어져 있으면 옆까지 걸어가서) 바로 캐요. 설정에서 '조준'을 켜면 한 번 조준하고 한 번 더 클릭해야 캐요 |
| 분필(X → O → 지움) | 오른쪽 클릭. X 칸을 클릭하면 캐지 않고 터뜨려요(촛불 4, 캐기와 같은 조준 규칙). 판 위 조작에는 키보드가 없어요 |
| 두드려 보기, 발파, 소모품 | 버튼을 누른 뒤 칸을 클릭. 오른쪽 클릭이나 버튼을 다시 누르면 취소. v2.2 시험에서 두드려 보기는 청진 망치가 있을 때만 |
| 둘레 한꺼번에 열기(v2.2 시험) | 숫자 칸 위에 서서 그 숫자를 한 번 더 클릭. 둘레의 X·O 수가 숫자와 같으면 나머지 덮인 칸이 촛불 1에 열려요. 떨어진 숫자를 클릭하면 먼저 걸어가요 |
| 계단 | 계단 위에서 계단 칸 클릭 → 갈림길 카드 클릭 |
| 올라가기 | 올라가기 버튼 → 확인 창 |
| 설정 | Esc 또는 톱니 버튼: 조준, 화면 흔들림, 지뢰 플래시, 키보드 키 목록, 통계, 오프닝 다시 보기, 플레이 기록 내려받기·지우기. 맨 아래에 씨앗과 지금 규칙 |
| 도장 선물(v2.2 시험) | 도장이 찍힌 뒤 카드 하나를 클릭하고 '이걸로 받기', 또는 '금고에 n 받기' |
| 오늘의 광산(v2.2 시험) | 판을 시작하는 권리증 화면의 '오늘의 광산' 버튼. 그날 모두 같은 판(등급 1)이고, 최고 점수는 날짜마다 이 브라우저에 남아요. '보통 광산으로'로 돌아가요 |
| 광산 등급(v2.2 시험) | 마지막 도장을 찍으면 다음 등급이 열려요. 권리증 화면의 '광산 고르기'에서 달못 1호 / 4호 / 9호 갱을 골라요 |
| 규칙 바꾸기 | 주소 뒤에 `?preset=v21`(2차 기획 v2.1). 없으면 v2.2 시험 |
| 디버그 | F2 판 공개, F3 촛불 가득, F4 금고 +500, F8 오늘 끝, F9 하루 넘김 |

## C.3 봇 측정

v2.2 시험(기본 규칙, 등급 1, 신중·욕심 100판, 보통 200판, 05 8.12)

| 지표 | 신중 | 보통 | 욕심 |
|---|---|---|---|
| 도장 1 / 2 / 3 / 4 / 5 통과 | 100 / 96 / 58 / 20 / 9% | 99 / 99 / 98 / 87 / 74% | 100 / 100 / 99 / 87 / 69% |
| 하루 수입 Day 1 · 6 · 15 | 129 · 596 · 1,192 | 274 · 1,070 · 1,228 | 270 · 1,103 · 1,192 |
| 하루 깨는 칸 | 87.1 | 35.2 | 38.5 |
| 둘레 한꺼번에 열기(하루) | 26.5번 | 8.6번 | 9.4번 |
| 쓰러진 날 | 5.3% | 6.7% | 15.2% |

- 둘레 한꺼번에 열기를 끄면 보통 마지막 도장이 75.6%에서 61.3%로 내려가요. 등급 2는 61%, 등급 3은 53%예요(보통). 첫 판 할인(꺼져 있어요)을 ×0.85로 켜면 신중 마지막 도장이 25%예요(05 8.13).

v2.1(`?preset=v21`, 세 정책 × 200판, 등급 1 확정값, 계단 숨김)

| 지표 | 신중 | 보통 | 욕심 |
|---|---|---|---|
| 계약금 / 중도금 / 잔금 통과 | 97.5 / 49.5 / 7.5% | 100 / 93 / 80% | 95 / 84.5 / 58.5% |
| 하루 수입 Day 1 · 8 · 15 | 148 · 556 · 570 | 385 · 862 · 1,161 | 357 · 751 · 1,051 |
| 위험 칸 도전 비율 | 6% | 31% | 27% |
| 평소 2배 버는 날 | 14% | 15% | 17% |

- 위 수치는 계단을 숨기던 v2.1 조건의 측정이에요. 계단 공개만 넣었을 때는 보통 마지막 도장 86.5%, 신중 8%, 욕심 69%로 올랐어요(05 8.11). 지금 v2.1 규칙은 계단을 숨긴 이 조건을 그대로 재현해요(보통 100 / 93 / 80%).

## C.3.1 기록 장치(플레이테스트용)

| 항목 | 내용 |
|---|---|
| 쌓는 때 | 하루가 끝나 하루 끝 화면이 뜰 때 한 줄. 브라우저 저장소(이 브라우저에만)에 최근 600일까지 |
| 한 줄에 든 것 | 날짜·시각, 씨앗, 첫 판 여부, 며칠째, 걸린 시간(밀리초), 판 클릭 수, 하루가 끝난 이유(올라가기 / 쓰러짐 / 촛불), 수입, 도달 깊이, 남은 촛불, 남은 체력, 도장 수, 결과를 모르고 고른 수, 치기·발파 갈래 |
| 치기 갈래 | 안전한 칸 / 보물이 확실한 칸 / 지뢰가 확실한 칸 / 보물 아니면 지뢰인 칸 / 모르는 칸. 발파는 지뢰가 확실한 칸 / 그 밖 |
| 결과를 모르고 고른 수 | 보물 아니면 지뢰인 칸 치기 + 모르는 칸 치기 + 지뢰가 확실하지 않은 칸 발파 |
| 보는 법 | 설정 창의 요약 한 줄(하루 중앙값, 1분에 결과를 모르고 고른 수). 자세한 것은 '플레이 기록 내려받기'로 JSON 파일을 받아요 |
| 판정 기준 | 재미 보고서 7장: 하루 중앙값 3~5분, 1분에 결과를 모르고 고른 수 1회 이상이면 통과. 하루 7분 초과나 1분에 0.5회 미만이면 실패 |
| 한계 | 설정 창을 열어 둔 시간도 하루 시간에 들어가요. 갈래는 프로토타입의 풀이 프로그램 기준이라 사람이 더 깊이 추리한 칸도 '모르는 칸'으로 셀 수 있어요 |

- 봇은 사람보다 실수가 적고 계단 단서를 놓치지 않아요. 사람 기록으로 다시 맞춰야 해요(4장 플레이테스트 계획).
- v2.2 시험에서 하루가 끝난 이유의 '촛불'은 촛불이 0이 되어 끝난 날이에요(불씨가 없어요). 기록 한 줄에 둘레 한꺼번에 열기 횟수도 들어가요.
- 사람 5명 플레이테스트의 진행, 질문, 판정은 [playtest_kit.md](playtest_kit.md)에 있어요.
