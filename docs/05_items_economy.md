## 2. 값과 시세

이 장에서 정하는 것: 보물·자갈·큰 덩이·주문 보상의 값, 날이 갈수록 수입이 오르게 하는 장치(시세), 그 결과의 하루 수입 곡선.

### 2.1 01이 남긴 문제

01 v0.3의 22장 7번: 재설계안의 목표 수입은 Day 1에 300, Day 8에 900, Day 15에 2,000인데, 규칙 안에 날짜에 따라 보물이 늘거나 비싸지는 장치가 없다.

후보를 같은 봇(보통, 도구 없음)으로 재 보았다. 맨 아래 줄 '도구'만 구매를 켰다.

| 후보 | 하는 일 | Day 14 수입 ÷ Day 1 수입 | 판정 |
|---|---|---|---|
| 아무 장치 없음 | - | ×1.15 | 30일이 같은 하루였던 1차 문제가 그대로 남는다 |
| 깊이별 보물 값(이미 있음) | 깊을수록 비싼 보물이 나온다 | ×1.15에 포함 | 하루에 내려가는 깊이가 날마다 같아서(평균 지하 3.9층) 오르지 않는다 |
| 콤보 상한 도구(마지막 패) | 체력 1이면 콤보 상한 ×5 | -1%(도구 하나의 효과) | 체력 1에서 거는 것이 손해라 봇이 쓰지 못한다(8.4) |
| 큰 덩이 값 | 납부일에만 | 해당 없음 | 사흘뿐이고 다 캐는 판이 7~47%다 |
| 두레박(도장마다 시작 층 +1) | 지하 2층, 3층에서 하루를 시작 | ×1.7 | 쓰러지는 날이 11% → 14%. 얕은 층의 갈림길 선택이 사라진다 |
| 층 표 당기기(도장마다 지뢰·보물 표를 2층 깊게) | 같은 층이 더 깊은 층처럼 된다 | ×0.94 | 지뢰가 같이 늘어 수입이 오르지 않는다 |
| 도구 축 성장 | 상점에서 도구를 산다 | ×1.8(Day 14: 구매 안 함 841 → 구매 1,542) | 필요하다. 혼자로는 모자라고, 처음 하는 사람은 도구를 잘 사지 못한다 |
| 시세(채택) | 도장 하나마다 값이 오른다 | ×2.3(×1 / 1.6 / 2.4로 잰 값) | 누구에게나 같은 폭으로 오르고 화면에 숫자로 보인다 |

- 앞 여섯 줄은 계산을 맞추기 전의 초기 비교다(30판, 지금과 다른 보물 값). 비율만 본다.
- 결정됨: 시세 ×1 / 1.5 / 3.
- 채택: 시세 + 도구 축 성장 + 큰 덩이. 시세로 모든 플레이어의 수입을 같은 폭으로 올리고, 그 위의 차이는 도구 구매와 걸기 판단에 맡긴다.

### 2.2 기본값(시세 ×1)

| 품목 | 값 | 비고 |
|---|---|---|
| 금 알갱이 | 20 | |
| 청록 보석 | 50 | |
| 유물 | 120 | 지하 3층부터 드물게 |
| 체력 수정 | 체력 +1. 체력이 가득이면 20(금 알갱이 값) | |
| 자갈 | 1개에 1 | 깊이와 상관없이 같다. 한 번에 열린 만큼 묶어 한 번 표시 |
| 큰 덩이 | Day 3: 60, Day 8: 160, Day 15: 260 | 콤보 배율도 받는다 |
| 주문 주머니 보상 | 50~100(주문마다 다름, 8.9) | 콤보 배율은 받지 않는다 |
| 그을린 보물 | 위 값의 절반. 콤보를 올리지 않는다(01 6장) | |

1차 값(40 / 100 / 240)의 절반이다. 보물끼리의 비율(1 : 2.5 : 6)은 그대로 두었다.

### 2.3 시세

장면: 계약금 도장이 찍힌 다음 날 아침. 게시판 왼쪽에 "달빛 시세 ×1.5 · 금 알갱이 30 · 청록 보석 75 · 유물 180, 도장을 하나 더 찍으면 ×3"이 적혀 있다.

| 도장 | 날 | 시세 | 금 알갱이 | 청록 보석 | 유물 | 큰 덩이(그날) |
|---|---|---|---|---|---|---|
| 0개 | Day 1~3 | ×1 | 20 | 50 | 120 | 60(Day 3) |
| 1개 | Day 4~8 | ×1.5 | 30 | 75 | 180 | 240(Day 8) |
| 2개 | Day 9~15 | ×3 | 60 | 150 | 360 | 780(Day 15, 지하 5층) |

| 규칙 | 내용 |
|---|---|
| 붙는 것 | 오늘 주머니에 들어가는 값 전부: 보물, 그을린 보물, 자갈 묶음, 큰 덩이, 주문 주머니 보상, 도구가 만든 보물 |
| 붙지 않는 것 | 도구·소모품 값, 새로고침, 촛불 손질, 납부액, 되팔기 |
| 계산 | 기본값 × 시세 × 그 밖의 배율(콤보, 도구, 갱 상태) → 소수점 버림. 자갈은 묶음 합에 곱하고 반올림 |
| 표시 | 게시판 권리증 칸에 지금 시세와 보물 셋의 값, 다음 도장의 시세. 보물을 캘 때 뜨는 "30 ×2 = 60"의 앞 숫자가 시세가 붙은 값이다 |
| 세계관 문구(02에 요청) | 그믐이 가까울수록 굳은 달빛이 단단해져 중개소가 더 쳐 준다. 구 실장: "도장 찍은 손님 물건은 시세를 더 쳐 드립니다." |

- 시세는 판 안에서만 바뀐다. 광산 등급마다 다른 시세는 두지 않는다(3.3).
- 도구 값에 시세를 붙이면 Day 9 이후 도구를 거의 사지 않아(Day 8 보유 1.8개) 수입 곡선이 낮아졌다. 그래서 도구 값은 판 내내 같다. 늦게 살수록 상대적으로 싸진다.

| 날 | 목표 | 신중 | 보통 | 욕심 | 보통의 그날 |
|---|---|---|---|---|---|
| Day 1 | 약 300 | 148 | 385 | 357 | 시세 ×1, 선물 도구 1개, 지하 1층 맨땅 |
| Day 3(계약금) | - | 242 | 409 | 350 | 큰 덩이 60 |
| Day 5 | - | 427 | 1,046 | 836 | 시세 ×1.5 |
| Day 8(중도금) | 약 900 | 556 | 862 | 751 | 큰 덩이, 변덕 1개 |
| Day 12 | - | 976 | 2,254 | 1,718 | 시세 ×3, 도구 4~5개 |
| Day 15(잔금) | 약 2,000 | 570 | 1,161 | 1,051 | 큰 덩이, 변덕 2개 |

| 보통의 수입 출처(15일 합) | 비율 |
|---|---|
| 보물(그을린 것 포함) | 68% |
| 자갈 | 18% |
| 설익이 정제기가 만든 금 알갱이 | 10% |

### 3.3 광산 등급 배수

등급 배수는 계약금·중도금·잔금과 큰 덩이 값에 같이 곱한다. 도구 값과 시세에는 곱하지 않는다.

| 1 | 달못 1호 갱 | 맨땅, 테두리, 짝, 외톨이 | 1.00 | ×1.0 | 300 | 2,400 | 11,000 |

### 5.4 갈림길 덤

갈림길 카드마다 덤이 하나 붙는다(검수 결정). 이 문서는 덤의 크기를 정한다.

| 덤 | 효과 | 값 |
|---|---|---|
| 보물 값 | 그 층에서 캔 보물 값 × (큰 덩이 제외) | ×1.2(임시안 ×1.3에서 낮춤) |
| 촛불 | 도착하면 촛불 + | +4(임시안 +6에서 낮춤) |
| 콤보 | 콤보 한 단계 올리고 시작 | 1단계 |
| 더 묻힌 층 | 지뢰 +, 보물 + | 지뢰 +3, 보물 +2 |
| 상인 방 / 샘 | 그날 방이 붙는 갈림길에서 한 장의 덤이 방이 된다 | 5.2, 01 8.4 |

덤과 선물이 수입에 주는 몫(납부액 300 / 2,000 / 7,000, 100판, 덤 조정 전)

| 조건 | 신중 통과율 | 보통 통과율 | 욕심 통과율 | 보통 Day 9~14 평일 |
|---|---|---|---|---|
| 덤·선물 모두 있음 | 96 / 74 / 54% | 99 / 96 / 96% | 96 / 91 / 88% | 2,611 |
| 덤 없음 | 99 / 64 / 41% | 100 / 97 / 96% | 96 / 87 / 84% | 2,214(-15%) |
| 선물 없음 | 99 / 68 / 37% | 100 / 97 / 96% | 96 / 91 / 88% | 2,393(-8%) |
| 둘 다 없음 | 99 / 49 / 18% | 100 / 95 / 93% | 94 / 84 / 75% | 2,139(-18%) |
| 덤 조정(값 ×1.2, 촛불 +4) | 95 / 65 / 46% | 100 / 96 / 96% | 95 / 89 / 86% | 2,487(-5%) |
| 덤 조정 + 더 묻힌 층 보물 +1, 값 ×1.15 | 98 / 66 / 44% | 100 / 97 / 97% | 94 / 91 / 87% | 2,369 |

- 덤은 고를 때마다 붙으므로 사실상 늘 받는 보너스다. 봇은 두 장 가운데 좋은 덤을 고른다. 덤이 있으면 없을 때보다 보통의 평일 수입이 18% 많고, 신중의 잔금 통과율이 41 → 54%로 오른다.
- 지나치게 세다고 보지 않았다. 갈림길에서 광맥과 덤을 같이 저울질하는 선택이 생기는 값어치가 있다. 가장 자주 고르는 '보물 값'과 '촛불'만 조금 낮췄다. 남은 수입 상승은 납부액으로 맞췄다.
- 그 이상 낮춘 안(값 ×1.15, 보물 +1)은 차이가 측정 오차 안이라 쓰지 않았다.
- 계단 바람(검수 결정)은 계단 찾는 촛불을 줄인다. 덤·선물을 다 뺀 조건에서도 보통 잔금 통과율이 89%(덤·선물 이전 측정) → 93%로 오른 몫이 대부분 이것이다.

### 5.5 중개소 선물

판을 시작할 때 도구 3개 가운데 1개를 무료로 받는다(검수 결정).

| 항목 | 규칙 |
|---|---|
| 후보 | 그 판에 열린 일반 도구 가운데 무작위 3개(겹침 없음) |
| 첫 판 | 고정 3개: 내기 분필, 연쇄 장부, 긴 도화선 |
| 값 | 무료. 되팔면 0(산 값이 0이므로) |
| 상점 | 받지 않은 두 개는 이후 상점에 제값으로 나올 수 있다 |

- 선물이 있으면 없을 때보다 보통의 평일 수입이 9% 많고, 신중의 잔금 통과율이 37 → 54%로 오른다(5.4 표). 처음 하는 사람에게 효과가 더 크다. 빌드를 첫 15분 안에 맛보게 하는 목적에 맞는다.
- 희귀도를 일반으로 묶은 지금 규칙을 유지한다. 고급·희귀가 나오게 하면 설익이 정제기(단독 +78%) 같은 도구가 판 시작부터 공짜가 된다.
- 첫 판 고정 3개 가운데 연쇄 장부는 고급(230)이다. 첫 판 한정이라 그대로 둔다. 봇(신중)은 셋 중 연쇄 장부를 고른다.

v2.2 시험: 도장 선물. 판 시작 선물을 없애고 도장을 찍을 때마다(마지막 빼고) 셋 중 하나를 고른다(01 1.4.1).

| 항목 | 값 |
|---|---|
| 후보 | 12종 가운데 가진 것을 빼고 3개(겹침 없음) |
| 희귀도 가중치(일반 / 고급 / 희귀) | 도장 1개째 60 / 35 / 5, 2개째 45 / 40 / 15, 3개째 30 / 45 / 25, 4개째 20 / 45 / 35 |
| 대신 받는 금고 돈 | 60 / 150 / 300 / 500 |
| 첫 판 첫 도장 | 내기 분필, 배짱 장갑, 긴 도화선(가진 것은 뺀다) |

- 금고 돈의 크기와 가중치는 초안이다. 8.12의 봇은 장착 칸이 남아 있으면 선호 순서대로 도구를, 가득이면 돈을 고른다. 도구와 돈을 견주어 잰 측정은 없다.

## 7. 봇과 측정 방법

이 장에서 정하는 것: 측정에 쓴 봇 세 종류가 무엇을 하는지, 지표를 어떻게 셌는지.

### 7.1 봇이 보는 것

화면에 보이는 것만 본다: 열린 칸의 숫자, 분필, 두드려 보기 결과, 캔 자리, 표지판, 눈금, 밑줄. 덮인 칸의 정체는 읽지 않는다. 추리는 프로토타입의 추리 함수(숫자 + 표지판 규칙)를 쓴다. 남은 보물·지뢰 수는 깊이별 개수 표(01 10.1)와 갱 상태로 어림한다. 이 어림이 맞는지 확인했다: 봇이 보물일 확률을 0.5~0.6으로 본 칸의 실제 보물 비율은 0.55, 0.6~0.7로 본 칸은 0.59였다.

### 7.2 세 정책

| 항목 | 신중(처음 하는 사람) | 보통 | 욕심 |
|---|---|---|---|
| 첫 판 고정 층 | 쓴다(Day 1) | 안 쓴다 | 안 쓴다 |
| 표지판 규칙을 추리에 쓰는 층 | Day 1에 50% → Day 15에 100%(판 안에서 배움) | 100% | 100% |

### 8.13 첫 판 할인(처음 하는 사람 보정, 결정 대기)
